Двоичные векторы и системы нумерации

Двоичные векторы

B = {0, 1}

B^n — все двоичные векторы длины n.

∣Bn∣=2n

Характеристический вектор множества:

  • 1 — элемент входит в множество
  • 0 — не входит

Отсюда множество из n элементов имеет:

2n

подмножеств.

Нумерация кортежей

Пусть:

M=M1​×M2​×⋯×Mn​

и:

∣Mi​∣=mi​

Номер кортежа:

N=r1​+r2​m1​+r3​m1​m2​+…

Главная идея:

номер = пройденные блоки + позиция внутри блока

Обратно:

N=q1​m1​+r1​ q1​=q2​m2​+r2​

и так далее.

Остатки r_i — координаты кортежа.

Факториальная система

Количество вариантов по координатам:

1,2,3,…,n

Поэтому всего:

n!

Номер:

N=t1​⋅0!+t2​⋅1!+⋯+tn​⋅(n−1)!

Это та же идея блоков.

Код Лемера

c_i — количество элементов справа от текущего элемента, которые меньше него.

0≤ci​≤n−i

Номер перестановки:

rank=i=1∑n​ci​(n−i)!

Идея:

c_i = сколько блоков перестановок пропустили

Восстановление

Берём список:

L=[1,2,…,n]

На шаге i:

  1. берём элемент с индексом c_i
  2. записываем его в перестановку
  3. удаляем из списка

Перестановки

Лексикографический порядок

Сравниваем слева направо до первого различия.

Минимальная перестановка:

(1,2,…,n)

Максимальная:

(n,n−1,…,1)
Ссылка на оригинал

Следующая перестановка

  1. Найти справа убывающий хвост.
  2. Взять элемент перед ним.
  3. Найти справа минимальный элемент больше него.
  4. Поменять их.
  5. Хвост поставить по возрастанию.

Идея:

хвост уже максимален → увеличиваем элемент левее → хвост делаем минимальным

1. Лексикографический порядок перестановок

Перестановки сравниваются слева направо до первого различия.

Пример:
(1, 3, 4, 2) < (1, 4, 2, 3), т.к. первое различие: 3 < 4.

Минимальная перестановка:
(1, 2, …, n)

Максимальная:
(n, n-1, …, 1)

Следующая перестановка — алгоритм

  1. Найти максимальный убывающий суффикс.
  2. Взять элемент перед ним — pivot.
  3. В суффиксе найти минимальный элемент, больший pivot.
  4. Поменять их местами.
  5. Суффикс расположить по возрастанию.

2. Код Лемера

Для перестановки π:

t_i = количество элементов справа от π_i, меньших π_i.

Пример:

π = (3, 1, 4, 2)

  • для 3: справа меньше 1, 2 → t1 = 2
  • для 1: нет → t2 = 0
  • для 4: меньше 2 → t3 = 1
  • для 2: нет → t4 = 0

T = (2, 0, 1, 0)

Номер перестановки

N=i=1∑n​ti​(n−i)!

Для n = 4:

N=t1​3!+t2​2!+t3​1!+t4​0!

Пример:

N=2⋅3!+0⋅2!+1⋅1!+0⋅0!=13

Нумерация с 0.

Смысл через блоки:

ti​(n−i)!=пропущенные варианты×число перестановок оставшихся элементов

Каждый t_i считает, сколько целых блоков мы пропустили на своём уровне.

Восстановление перестановки по коду Лемера

  1. Выписать доступные числа по возрастанию.
  2. t_i использовать как индекс с 0.
  3. Выбранное число записать в перестановку и удалить.
  4. Повторять.

Пример:

T = (2, 0, 1, 0)

[1,2,3,4] → индекс 2 → 3
[1,2,4] → индекс 0 → 1
[2,4] → индекс 1 → 4
[2] → индекс 0 → 2

π = (3,1,4,2)

3. Факториальный счётчик

Разряды имеют разные диапазоны:

t1 = 0
t2 = 0..1
t3 = 0..2
t4 = 0..3

Пример счёта:

0000
0001

0010
0011
0012
0013

…

При переполнении разряда происходит перенос в следующий.

Важно: порядок записи разрядов может быть обратным — выбрать один вариант записи и не менять его.

4. Перестановки соседними транспозициями

Цель: перечислить все перестановки так, чтобы соседние отличались перестановкой ровно двух соседних элементов.

Обозначения:

  • T — факториальный счётчик
  • D_i — направление движения элемента i
  • g — элемент, который двигается
  • P — текущая перестановка

Начало для n = 4:

1234 → 1243 → 1423 → 4123 → 4132 → 1432 → 1342 → 1324 → …

Алгоритм через таблицу T, D, g, P

  1. Увеличить T на 1.
  2. Определить изменившийся разряд → это g.
  3. Для всех i > g поменять направление D_i.
  4. Найти сам элемент g в перестановке P.
  5. Поменять g с соседним элементом в направлении D_g.
  6. Получить новую перестановку.

Важно:

g — ЗНАЧЕНИЕ двигающегося элемента, а не его позиция.

Сочетания и биномиальные формулы

6. Сочетания

Сочетание — выбор k различных элементов из n без учёта порядка.

Cnk​=k!(n−k)!n!​

Удобная запись:

1≤a1​<a2​<...<ak​≤n

Пример:

(1,3,5)

означает: выбраны элементы №1, №3 и №5.

Ссылка на оригинал

7. Следующее сочетание

Алгоритм

  1. Идём справа налево.
  2. Находим первое a_i, которое ещё можно увеличить:
ai​<n−k+i
  1. Увеличиваем его на 1.
  2. Все элементы справа сбрасываем в минимально возможные последовательные значения.

То есть:

aj​=ai​+(j−i)

для j > i.

Пример

n = 8, k = 5

Текущее:

(1,2,3,4,8)

8 увеличить нельзя.

Идём левее: 4 увеличить можно.

4 → 5

Всё справа сбрасываем в минимум:

после 5 минимально возможно 6.

Получаем:

(1,2,3,5,6)

Коротко:

справа налево → первое возможное +1 → всё справа в минимум.

8. Решётчатые пути

Из (0,0) идём в:

(k,n−k)

Разрешены только:

→ вправо
↑ вверх

Нужно сделать:

  • k шагов вправо
  • n-k шагов вверх
  • всего n шагов

Выбираем k позиций из n, в которых будет →.

Остальные позиции автоматически будут ↑.

Поэтому:

Cnk​​

Пример:

n = 5, k = 2

Выбрали позиции 2 и 5:

↑ → ↑ ↑ →

Это один конкретный путь.

Количество путей:

C52​=10

Другой взгляд:
переставляем k одинаковых → и n-k одинаковых ↑:

k!(n−k)!n!​=Cnk​

11. Треугольник Паскаля

Строка n содержит:

Cn0​, Cn1​, ..., Cnn​

То есть:

n фиксирован строкой,
k идёт от 0 до n.

Первые строки:

n=0: 1
n=1: 1 1
n=2: 1 2 1
n=3: 1 3 3 1
n=4: 1 4 6 4 1
n=5: 1 5 10 10 5 1

Например строка n=4:

C40​, C41​, C42​, C43​, C44​ 1, 4, 6, 4, 1

Каждое внутреннее число равно сумме двух над ним благодаря формуле Паскаля.

Например:

C42​=C31​+C32​ 6=3+3

2. Рекурсивная нумерация сочетаний

Порядок:

  1. сначала все векторы с bn​=0;
  2. затем все векторы с bn​=1.

Если последние биты одинаковы → отбрасываем последний бит и повторяем.

Формула

Nn,k​(b1​…bn​)=⎩⎨⎧​Nn−1,k​(b1​…bn−1​),Cn−1k​+Nn−1,k−1​(b1​…bn−1​),​bn​=0,bn​=1.​
  • bn​=0: остаётся n−1 позиций и k единиц.
  • bn​=1: пропускаем блок размера Cn−1k​, затем остаётся k−1 единиц.

Пример:

N5,3​(10011)=C43​+N4,2​(1001)=C43​+C32​+N3,1​(100)=4+3=7.
