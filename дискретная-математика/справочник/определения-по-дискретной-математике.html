Перестановки и сочетания

Лексикографический порядок перестановок

1. Лексикографический порядок перестановок

Перестановки сравниваются слева направо до первого различия.

Пример:
(1, 3, 4, 2) < (1, 4, 2, 3), т.к. первое различие: 3 < 4.

Минимальная перестановка:
(1, 2, …, n)

Максимальная:
(n, n-1, …, 1)

Следующая перестановка — алгоритм

  1. Найти максимальный убывающий суффикс.
  2. Взять элемент перед ним — pivot.
  3. В суффиксе найти минимальный элемент, больший pivot.
  4. Поменять их местами.
  5. Суффикс расположить по возрастанию.

Код Лемера

2. Код Лемера

Для перестановки π:

t_i = количество элементов справа от π_i, меньших π_i.

Пример:

π = (3, 1, 4, 2)

  • для 3: справа меньше 1, 2 → t1 = 2
  • для 1: нет → t2 = 0
  • для 4: меньше 2 → t3 = 1
  • для 2: нет → t4 = 0

T = (2, 0, 1, 0)

Номер перестановки

N=i=1∑n​ti​(n−i)!

Для n = 4:

N=t1​3!+t2​2!+t3​1!+t4​0!

Пример:

N=2⋅3!+0⋅2!+1⋅1!+0⋅0!=13

Нумерация с 0.

Смысл через блоки:

ti​(n−i)!=пропущенные варианты×число перестановок оставшихся элементов

Каждый t_i считает, сколько целых блоков мы пропустили на своём уровне.

Восстановление перестановки по коду Лемера

  1. Выписать доступные числа по возрастанию.
  2. t_i использовать как индекс с 0.
  3. Выбранное число записать в перестановку и удалить.
  4. Повторять.

Пример:

T = (2, 0, 1, 0)

[1,2,3,4] → индекс 2 → 3
[1,2,4] → индекс 0 → 1
[2,4] → индекс 1 → 4
[2] → индекс 0 → 2

π = (3,1,4,2)

Перестановки соседними транспозициями

4. Перестановки соседними транспозициями

Цель: перечислить все перестановки так, чтобы соседние отличались перестановкой ровно двух соседних элементов.

Обозначения:

  • T — факториальный счётчик
  • D_i — направление движения элемента i
  • g — элемент, который двигается
  • P — текущая перестановка

Начало для n = 4:

1234 → 1243 → 1423 → 4123 → 4132 → 1432 → 1342 → 1324 → …

Алгоритм через таблицу T, D, g, P

  1. Увеличить T на 1.
  2. Определить изменившийся разряд → это g.
  3. Для всех i > g поменять направление D_i.
  4. Найти сам элемент g в перестановке P.
  5. Поменять g с соседним элементом в направлении D_g.
  6. Получить новую перестановку.

Важно:

g — ЗНАЧЕНИЕ двигающегося элемента, а не его позиция.

Сочетания

6. Сочетания

Сочетание — выбор k различных элементов из n без учёта порядка.

Cnk​=k!(n−k)!n!​

Удобная запись:

1≤a1​<a2​<...<ak​≤n

Пример:

(1,3,5)

означает: выбраны элементы №1, №3 и №5.

Следующее сочетание

7. Следующее сочетание

Алгоритм

  1. Идём справа налево.
  2. Находим первое a_i, которое ещё можно увеличить:
ai​<n−k+i
  1. Увеличиваем его на 1.
  2. Все элементы справа сбрасываем в минимально возможные последовательные значения.

То есть:

aj​=ai​+(j−i)

для j > i.

Пример

n = 8, k = 5

Текущее:

(1,2,3,4,8)

8 увеличить нельзя.

Идём левее: 4 увеличить можно.

4 → 5

Всё справа сбрасываем в минимум:

после 5 минимально возможно 6.

Получаем:

(1,2,3,5,6)

Коротко:

справа налево → первое возможное +1 → всё справа в минимум.

Решётчатые пути

8. Решётчатые пути

Из (0,0) идём в:

(k,n−k)

Разрешены только:

→ вправо
↑ вверх

Нужно сделать:

  • k шагов вправо
  • n-k шагов вверх
  • всего n шагов

Выбираем k позиций из n, в которых будет →.

Остальные позиции автоматически будут ↑.

Поэтому:

Cnk​​

Пример:

n = 5, k = 2

Выбрали позиции 2 и 5:

↑ → ↑ ↑ →

Это один конкретный путь.

Количество путей:

C52​=10

Другой взгляд:
переставляем k одинаковых → и n-k одинаковых ↑:

k!(n−k)!n!​=Cnk​

Вероятностная модель и условная вероятность

1. Базовые обозначения и условная вероятность

Вероятностная модель

Случайный опыт задаётся тройкой

(Ω,F,P),

где:

  • Ω — пространство элементарных исходов;
  • F — система событий;
  • P — вероятность.

Для конечного Ω достаточно считать события подмножествами Ω.

Вероятность удовлетворяет основным свойствам:

P(A)≥0, P(Ω)=1,

и аддитивности для несовместных событий.

Определение условной вероятности

Если

P(B)>0,

то вероятность события A при условии события B определяется как

P(A∣B)=P(B)P(A∩B)​​.

Смысл

После получения информации о том, что событие B произошло, пространство рассматриваемых исходов сужается с Ω до B.

Внутри нового пространства B нас интересует та часть исходов, где дополнительно выполняется A. Эта часть равна A∩B.

Поэтому условная вероятность — это доля события B, принадлежащая также A.

Важно: в записи P(A∣B) событие после вертикальной черты — это уже известное условие.

Пример

Бросается честный кубик.

A={выпало чётное}={2,4,6}, B={выпало больше 3}={4,5,6}.

Тогда

A∩B={4,6}.

После условия B возможны только исходы {4,5,6}, из которых событию A соответствуют два: {4,6}.

Поэтому

P(A∣B)=32​.

Без условия

P(A)=21​.

Формула умножения

Из определения условной вероятности:

P(A∣B)=P(B)P(A∩B)​

получаем

P(A∩B)=P(A∣B)P(B)​.

Аналогично:

P(A∩B)=P(B∣A)P(A)​.

Обе формулы вычисляют вероятность одного и того же пересечения, поскольку

A∩B=B∩A.

Следовательно,

P(A∣B)P(B)=P(B∣A)P(A).

Важно: сами условные вероятности обычно различны:

P(A∣B)=P(B∣A).

Симметрично именно пересечение, а не условные вероятности.

Независимость, попарная и совместная независимость

2. Независимость событий

Определение

События A и B называются независимыми, если

P(A∩B)=P(A)P(B)​.

При P(B)>0 это равносильно условию

P(A∣B)=P(A)​.

То есть знание о наступлении B не изменяет вероятность A.

Как проверять независимость

  1. Найти P(A).
  2. Найти P(B).
  3. Найти P(A∩B).
  4. Сравнить:
P(A∩B)=?P(A)P(B).

Если равенство выполняется — события независимы.

Пример независимых событий

Пусть

Ω={1,2,3,4},

и все исходы равновероятны.

A={1,2},B={1,3}.

Тогда

P(A)=P(B)=21​, A∩B={1}, P(A∩B)=41​=P(A)P(B).

Следовательно, A и B независимы.

Попарная и совместная независимость

Для событий A1​,…,An​ попарная независимость означает, что для любых i=j

P(Ai​∩Aj​)=P(Ai​)P(Aj​).

Совместная независимость требует, чтобы для любого набора индексов I, ∣I∣≥2,

P(i∈I⋂​Ai​)=i∈I∏​P(Ai​)​.

Попарная независимость не гарантирует совместную.

Контрпример

Пусть

Ω={1,2,3,4},

и все исходы равновероятны.

A={1,2},B={1,3},C={1,4}.

Тогда

P(A)=P(B)=P(C)=21​.

Любое попарное пересечение равно {1}, поэтому

P(A∩B)=P(A∩C)=P(B∩C)=41​,

и это равно произведению соответствующих вероятностей.

Но

P(A∩B∩C)=41​=81​=P(A)P(B)P(C).

Следовательно, события попарно независимы, но не независимы в совокупности.

Независимость и несовместность

Несовместность:

A∩B=∅​

— события не могут произойти одновременно.

Независимость:

P(A∩B)=P(A)P(B)​

— одно событие не влияет на вероятность другого.

Если A и B несовместны и обе вероятности положительны, то они зависимы:

P(A∩B)=0,

но

P(A)P(B)>0.

Полная группа событий

3. Разбиение пространства и формула полной вероятности

Разбиение пространства

События S1​,…,Sn​ образуют полную группу, если:

Si​∩Sj​=∅,i=j, i=1⋃n​Si​=Ω,

и

P(Si​)>0.

Условие P(Si​)>0 нужно потому, что далее используется

P(A∣Si​)=P(Si​)P(A∩Si​)​.

Разложение события по сценариям

Так как множества Si​ разбивают всё пространство Ω, событие A можно представить как объединение его частей внутри каждого сценария:

A=(A∩S1​)∪(A∩S2​)∪⋯∪(A∩Sn​)​.

Эти части несовместны, поскольку сами Si​ не пересекаются. Поэтому

P(A)=i=1∑n​P(A∩Si​).

По формуле умножения

P(A∩Si​)=P(A∣Si​)P(Si​).

Следовательно,

P(A)=i=1∑n​P(A∣Si​)P(Si​)​.

Это формула полной вероятности.

Смысл формулы

Каждый сценарий Si​ даёт свой вклад в событие A:

P(Si​)⋅P(A∣Si​).

Полная вероятность события A получается сложением вкладов всех несовместных сценариев.

Кратко:

вероятность результата=∑(вероятность сценария×вероятность результата внутри сценария)​.

Пример с урнами

Есть две урны.

S1​={выбрали урну I},S2​={выбрали урну II}. P(S1​)=32​,P(S2​)=31​.

В урне I 5 белых и 2 чёрных шара, поэтому

P(A∣S1​)=75​,

где A — событие «вынут белый шар».

В урне II 3 белых и 10 чёрных шаров:

P(A∣S2​)=133​.

Важно: P(A∣S1​)=75​ не включает вероятность выбора первой урны. Это вероятность белого шара при уже выбранной первой урне.

Полный путь через первую урну:

P(S1​∩A)=P(S1​)P(A∣S1​)=32​⋅75​=2110​.

Через вторую:

P(S2​∩A)=31​⋅133​=131​.

Так как пути несовместны,

P(A)=2110​+131​.

Дискретная случайная величина и её распределение

6. Дискретная случайная величина

Определение

Случайная величина ξ — функция

ξ:Ω→R​

которая каждому исходу ω∈Ω ставит в соответствие число ξ(ω).

То есть случайная величина превращает исход случайного опыта в числовое значение.

Закон распределения

Если ξ принимает значения a1​,…,ak​, то

pi​=P(ξ=ai​)

задают её распределение.

Запись

P(ξ=ai​)

означает вероятность события

{ω∈Ω:ξ(ω)=ai​}.

Необходимо:

pi​≥0, i∑​pi​=1.

Пример распределения

ξP​−121​​041​​141​​​

Проверка:

21​+41​+41​=1.

В этом примере вероятности заданы непосредственно.

Независимость случайных величин

Дискретные случайные величины ξ и η независимы, если для любых возможных значений ai​ и bj​

P(ξ=ai​,η=bj​)=P(ξ=ai​)P(η=bj​)​.

Запись P(ξ=ai​,η=bj​) означает вероятность того, что одновременно выполняются события ξ=ai​ и η=bj​.

Это обычное условие независимости событий, применённое к событиям {ξ=ai​} и {η=bj​}.

Совместное и маргинальные распределения

Если дана совместная таблица вероятностей P(ξ=ai​,η=bj​), то суммы по строкам и столбцам дают отдельные распределения случайных величин.

Пример:

ξ=0ξ=1​η=20.30.2​η=30.20.3​​

Тогда

P(ξ=0)=0.3+0.2=0.5, P(ξ=1)=0.5, P(η=2)=0.5, P(η=3)=0.5.

Эти отдельные распределения называются маргинальными.

Смысл: из совместной таблицы «забываем» про вторую величину и смотрим на первую отдельно.

Для проверки независимости каждая ячейка должна удовлетворять

P(ξ=ai​,η=bj​)=P(ξ=ai​)P(η=bj​).

В приведённом примере

0.3=0.5⋅0.5=0.25,

поэтому величины зависимы.

7. Математическое ожидание

Определение

Для дискретной случайной величины ξ, принимающей значения ai​,

E(ξ)=Mξ=i∑​ai​P(ξ=ai​)​.

То есть математическое ожидание — сумма «значение × его вероятность» по всем возможным значениям.

Оно не обязано быть одним из возможных значений ξ и интерпретируется как центр распределения и средний результат в длинной серии повторений.

Пример

E(ξ)=(−1)⋅21​+0⋅41​+1⋅41​=−41​.

Свойства

Для константы c:

E(c)=c​.

Если все значения случайной величины умножить на c:

E(cξ)=cE(ξ)​.

Доказательство:

E(cξ)=i∑​cai​P(ξ=ai​)=ci∑​ai​P(ξ=ai​)=cE(ξ).

Линейность

E(ξ+η)=E(ξ)+E(η)​.

Для этого независимость не требуется.

Доказательство ?

Обозначим

pij​=P(ξ=ai​,η=bj​).

Тогда

E(ξ+η)=i,j∑​(ai​+bj​)pij​.

Раскрываем:

=i,j∑​ai​pij​+i,j∑​bj​pij​.

Группируем:

=i∑​ai​(j∑​pij​)+j∑​bj​(i∑​pij​).

Но

j∑​pij​=P(ξ=ai​), i∑​pij​=P(η=bj​).

Следовательно,

E(ξ+η)=E(ξ)+E(η).

Математическое ожидание произведения

Если ξ и η независимы, то

E(ξη)=E(ξ)E(η)​.

Итак:

E(ξ+η)=E(ξ)+E(η)— всегда​ E(ξη)=E(ξ)E(η)— при независимости​.

Дисперсия

1.0. Определение дисперсии

Пусть ξ — дискретная случайная величина с конечным вторым моментом, а E(ξ) — её математическое ожидание.

Математическое ожидание описывает усреднённый результат многочисленных повторений опыта с учётом вероятностей отдельных значений. Но оно само по себе не показывает, насколько сильно значения отклоняются от этого среднего.

Определение. Дисперсией случайной величины ξ называется математическое ожидание квадрата её отклонения от математического ожидания:

D(ξ)=E([ξ−E(ξ)]2)​.

Квадрат нужен, чтобы положительные и отрицательные отклонения не компенсировали друг друга. Преподаватель отметил, что модуль также позволил бы избежать компенсации, но квадрат удобнее для алгебраических преобразований.

Испытание и схема Бернулли

3. Испытание Бернулли и схема Бернулли

Испытание Бернулли — случайный эксперимент с двумя исходами: успех (вероятность p) и неудача (вероятность q=1−p).

Введём индикатор результата одного испытания ξ:

ξ={1,0,​при успехе,при неудаче.​P(ξ=1)=p,P(ξ=0)=q.

Для одного испытания:

E(ξ)=1⋅p+0⋅q=p.

Поскольку ξ2=ξ при обоих возможных значениях,

E(ξ2)=p,D(ξ)=p−p2=pq​.

Схема Бернулли: проводятся n независимых испытаний, во всех вероятность успеха одинакова и равна p. Пусть ξi​ — индикатор успеха в испытании с номером i (i=1,…,n). Число успехов равно

Sn​=ξ1​+ξ2​+…+ξn​​,Sn​∈{0,1,…,n}.

Независимость принципиальна: исходы всех испытаний должны быть совместно независимы, а не только попарно. Преподаватель обсуждал бросание монеты, рулетку и стрельбу; в реальных опытах независимость нужно оценивать, а не просто предполагать.

Биномиальное распределение

4. Биномиальное распределение

Задача: найти вероятность того, что среди n испытаний Бернулли произойдёт ровно k успехов (0≤k≤n).

Вероятность одной заранее фиксированной последовательности, содержащей k успехов и n−k неудач, по независимости равна

pkqn−k.

Позиции k успехов среди n испытаний можно выбрать Cnk​ способами. Эти последовательности различны и несовместны, поэтому складываем их вероятности:

P(Sn​=k)=Cnk​pkqn−k​,Cnk​=k!(n−k)!n!​.

Это биномиальное распределение числа успехов Sn​; обозначение: Sn​∼Bin(n,p). Важен только счёт успехов, а не их конкретный порядок.

Равномерное распределение

6. Равномерное распределение

Дискретное равномерное распределение: случайная величина ξ принимает m возможных значений a1​,…,am​ с одинаковыми вероятностями:

P(ξ=ai​)=m1​​,i=1,…,m.

Примеры, упомянутые на паре: честная монета, честный игральный кубик.

Для моделирования случайных распределений используется также равномерный выбор числа U из [0,1): вероятность попасть в часть этого отрезка равна её относительной длине. В программировании такую величину получают при помощи генератора псевдослучайных чисел.

Крафт и энтропия

Двоичное дерево и префиксность

1. Двоичный поиск как дерево

Двоичный поиск — поиск неизвестного исхода последовательностью вопросов с двумя вариантами ответа, например «да/нет».

  • Внутренняя вершина дерева соответствует вопросу.
  • Ребро — одному из ответов (0 или 1).
  • Лист — исходу, который уже однозначно установлен.
  • Глубина листа si​ — число вопросов, нужное для исхода i.

В этом дереве sA​=1, sB​=2, sC​=3; соответствующие двоичные слова: 0, 10, 110.

Префиксность: код одного исхода не может быть началом кода другого. Например, если слово 0 уже означает исход A, код 01 невозможен: при ответе 0 поиск завершён.

Если все исходы должны определяться не более чем за k вопросов, то их не может быть больше 2k: после k двоичных развилок существует не больше 2k последовательностей ответов.

Среднее число вопросов

3. Среднее число вопросов

Пусть pi​ — вероятность исхода i; pi​≥0 и ∑i​pi​=1. Пусть N — случайная величина «число вопросов до нахождения исхода». Если при исходе i задаётся si​ вопросов, то

E(N)=i=1∑m​pi​si​.​

Пример: для вероятностей (0,8;0,1;0,1) и длин (1,2,2) получаем

E(N)=0,8⋅1+0,1⋅2+0,1⋅2=1,2.

1,2 — не число вопросов в отдельном поиске. Каждый поиск требует целое число вопросов; 1,2 — среднее по большому числу независимых повторений. Например, 100 поисков со встречаемостями 80/10/10 потребуют всего 120 вопросов, то есть 1,2 на один поиск.

Оптимизационная задача: подобрать длины путей, минимизирующие ∑i​pi​si​, при условии Крафта и целочисленности si​. Практический принцип: более вероятным исходам обычно выгодно назначать более короткие пути.

Бит информации

4.1. Бит

Бит информации — количество информации, получаемое при различении двух равновероятных возможностей. При двоичном вопросе с равновероятными ответами получаем 1 бит.

Отдельный вопрос «да/нет» не всегда даёт в среднем ровно 1 бит: если один ответ почти гарантирован, информации в таком ответе меньше.

Информация об исходе

4.2. Количество информации об одном исходе

Для исхода вероятности p, где 0<p≤1, определим

I(p)=−log2​p=log2​p1​.​

Вход функции: вероятность одного исхода p; выход: количество информации в битах.

Если имеется 2k равновероятных вариантов, k двоичных ответов достаточно, чтобы их различить; вероятность каждого равна p=2−k, поэтому k=−log2​p.

Примеры:

pI(p)
1/21 бит
1/42 бита
1/83 бита
1/325 бит

Чем менее вероятен исход, тем больше информации приносит известие о нём. Для произвольного p величина I(p) может быть дробной: она не обязана равняться буквальному числу вопросов в одном конкретном поиске.

Энтропия

4.3. Энтропия

Пусть случайная схема имеет исходы с вероятностями p1​,…,pm​, где ∑i​pi​=1. Энтропия — математическое ожидание количества информации об исходе:

H(p1​,…,pm​)=i=1∑m​pi​log2​pi​1​=−i=1∑m​pi​log2​pi​.​

Для pi​=0 соответствующее слагаемое считают равным 0, поскольку limp→0+​(−plog2​p)=0.

Вход: всё распределение вероятностей (p1​,…,pm​); выход: одно число — среднее количество информации об исходе (в битах).

Смысл: энтропия характеризует неопределённость до наблюдения исхода; она не предсказывает, какой исход произойдёт.

Пример для двух равновероятных исходов:

H(1/2,1/2)=−2⋅21​log2​21​=1 бит.

Пример для вероятностей (0,9;0,1):

H(0,9,0,1)≈0,469 бита.

Интуиция: при (0,5;0,5) угадать исход трудно, поэтому неопределённость выше, чем при (0,9;0,1), где один исход почти наверняка произойдёт.
