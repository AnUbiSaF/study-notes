Непрерывность скалярного произведения, лемма о покоординатной сходимости

13 нояб. 2026 г.время чтения ~3 мин.

Непрерывность скалярного произведения: дано

Пусть X — линейное пространство со скалярным произведением,
а норма порождена этим скалярным произведением:

∥x∥=⟨x,x⟩​.

Пусть (xn​) и (yn​) — последовательности векторов из X,
которые сходятся соответственно к векторам x0​ и y0​:

xn​→x0​,yn​→y0​.

Непрерывность скалярного произведения: тогда

Числовая последовательность (⟨xn​,yn​⟩) сходится
к скалярному произведению предельных векторов:

⟨xn​,yn​⟩→⟨x0​,y0​⟩.

Полное доказательство непрерывности скалярного произведения

Обозначим

Δn​=⟨xn​,yn​⟩−⟨x0​,y0​⟩.

Чтобы доказать

⟨xn​,yn​⟩→⟨x0​,y0​⟩,

достаточно доказать, что

∣Δn​∣→0.

Добавим и вычтем ⟨xn​,y0​⟩:

Δn​=⟨xn​,yn​⟩−⟨xn​,y0​⟩+⟨xn​,y0​⟩−⟨x0​,y0​⟩ =⟨xn​,yn​−y0​⟩+⟨xn​−x0​,y0​⟩.

Добавление и вычитание одного и того же числа не меняет
Δn​, но разделяет изменения двух аргументов. Это аналог
тождества

ab−cd=a(b−d)+(a−c)d.

Исходная разность содержит одновременно меняющиеся xn​ и yn​.
Вставленный промежуточный член делит её на две разности:

⟨xn​,yn​−y0​⟩и⟨xn​−x0​,y0​⟩.

В первой разность yn​−y0​ стремится к нулю, во второй —
xn​−x0​. Оставшиеся множители не создают проблемы: y0​
фиксирован, а сходящаяся последовательность (xn​) ограничена.

По неравенству треугольника для модуля и неравенству
Коши — Буняковского

∣Δn​∣≤∥xn​∥∥yn​−y0​∥+∥xn​−x0​∥∥y0​∥.

Так как xn​→x0​, по теореме об ограниченности сходящейся
последовательности (xn​) ограничена: существует M>0, для
которого

∀n∈N:∥xn​∥≤M.

Поэтому

∣Δn​∣≤M∥yn​−y0​∥+∥y0​∥∥xn​−x0​∥.

Из условий сходимости

∥yn​−y0​∥→0,∥xn​−x0​∥→0.

Правая часть есть сумма двух бесконечно малых последовательностей,
следовательно,

∣Δn​∣→0.

Значит,

Δn​→0,

то есть

⟨xn​,yn​⟩→⟨x0​,y0​⟩.

Покоординатная сходимость: дано

Пусть в Rm

xn=(x1n​,…,xmn​),x0=(x10​,…,xm0​).

Используется евклидова норма

∥x∥=x12​+…+xm2​​.

Покоординатная сходимость: тогда

Последовательность векторов сходится тогда и только тогда,
когда сходится каждая координата:

xn→x0⟺xkn​→xk0​∀k=1,…,m.

Полное доказательство покоординатной сходимости

Направление ⇒. Пусть

xn→x0.

Зафиксируем произвольную координату k∈{1,…,m}.
Имеем

∥xn−x0∥=i=1∑m​(xin​−xi0​)2​.

Под корнем находится сумма неотрицательных слагаемых, поэтому

(xkn​−xk0​)2≤i=1∑m​(xin​−xi0​)2.

После извлечения корня

∣xkn​−xk0​∣≤∥xn−x0∥.

Для произвольного ε>0 из определения
сходимости xn→x0 существует N∈N такое, что

∀n≥N:∥xn−x0∥<ε.

Тогда для каждого n≥N

∣xkn​−xk0​∣≤∥xn−x0∥<ε.

Следовательно,

∀ε>0 ∃N∈N ∀n≥N:∣xkn​−xk0​∣<ε,

то есть по определению

xkn​→xk0​.

Координата k была выбрана произвольно, поэтому

xkn​→xk0​∀k=1,…,m.

Направление ⇐. Пусть

xkn​→xk0​∀k=1,…,m.

Нужно доказать

∥xn−x0∥→0.

По определению возьмём произвольное ε>0. Нужно найти
номер N такой, чтобы для всех n≥N выполнялось

∥xn−x0∥<ε.

Выберем общую допустимую ошибку δ>0 для каждой координаты.
Если одновременно для всех k=1,…,m выполняется

∣xkn​−xk0​∣<δ,

то

∥xn−x0∥​=k=1∑m​(xkn​−xk0​)2​<k=1∑m​δ2​=mδ2​=m​δ.​

Чтобы эта оценка дала требуемое
∥xn−x0∥<ε, выберем δ из равенства

m​δ=ε.

Отсюда

δ=m​ε​.

Поскольку каждая координата сходится и δ>0, по определению
предела для каждого k=1,…,m существует номер Nk​ такой,
что

∀n≥Nk​:∣xkn​−xk0​∣<δ,k=1,…,m.

Координат конечное число, поэтому выбирается общий номер

N=max{N1​,…,Nm​}.

При n≥N все координатные неравенства выполняются
одновременно:

∀n≥N ∀k∈{1,…,m}:∣xkn​−xk0​∣<δ.

По полученной выше оценке и выбору
δ=m​ε​ имеем

∥xn−x0∥<m​δ=m​⋅m​ε​=ε.

Итак, для произвольного ε>0 построен номер N, для
которого

∀n≥N:∥xn−x0∥<ε.

Поскольку ε>0 было произвольным, по определению
сходимости xn→x0.

Общий номер N можно выбрать как максимум
N1​,…,Nm​ именно потому, что координат конечное число.

Источники: непрерывность скалярного произведения; покоординатная сходимость.
