Аксиома Архимеда. Плотность множества рациональных чисел в R

Info

Исходный текст: Математический анализ/Лекции/Лекция 07 — Предел частного, упорядоченные поля, аксиома Архимеда > 6. Аксиома Архимеда и Математический анализ/Лекции/Лекция 08 — Индукция, границы, плотность > 4. Плотность рациональных чисел.

Дано

Для аксиомы Архимеда: x,y>0.

Для плотности рациональных чисел: a,b∈R и

a<b.

Тогда

Аксиома Архимеда утверждает:

∀x,y>0∃n∈N: nx>y.

Эквивалентная форма:

∀t∈R∃n∈N: n>t.

Рациональные числа плотны в R:

∀a,b∈Ra<b⟹∃q∈Q: a<q<b.

Маршрут доказательства

Берём t=y/x для эквивалентной формы Архимеда → выбираем сетку k/m с 1/m<b−a → берём первую точку правее a → проверяем a<q<b.

Полное доказательство

Аксиома Архимеда

Саму аксиому Архимеда не доказывают: она принимается как исходное свойство вещественных чисел. Она говорит, что повторением любого положительного шага x можно превзойти любую положительную величину y.

Эквивалентная форма говорит, что натуральные числа не ограничены сверху. Чтобы получить исходную формулировку из неё, для данных x,y>0 берём

t=xy​.

Тогда найдётся n∈N такое, что

n>xy​.

Так как x>0, умножаем на x:

nx>y.

Плотность рациональных чисел

Нужно построить рациональное число между a и b. Длина промежутка равна

L=b−a>0.

Ищем рациональное число вида

mk​,k∈Z,m∈N.

Сначала выбираем m: оно задаёт сетку

…, −m2​, −m1​, 0, m1​, m2​,…

с постоянным шагом

mk+1​−mk​=m1​.

Число m остаётся фиксированным; целое k нумерует точки этой сетки. Числитель берут из Z, чтобы сетка покрывала и отрицательную часть прямой. Знаменатель берут из N, поэтому шаг 1/m положителен и при делении на m знак неравенства не меняется.

Хотим, чтобы шаг сетки был меньше длины промежутка:

m1​<L=b−a.

Это равносильно условию

m>b−a1​.

По аксиоме Архимеда можно выбрать такое m∈N.

Теперь ищем первую точку этой сетки строго правее a. Для точки k/m условие «она правее a» имеет вид

mk​>a⟺k>ma.

Здесь ma — обычное произведение m⋅a, а ⌊ma⌋ — целая часть, то есть округление ma вниз. Поэтому

k=⌊ma⌋+1

— первое целое число, строго большее ma. Берём соответствующую точку сетки:

q=mk​=m⌊ma⌋+1​.

Проверим левую границу. По выбору k:

ma<⌊ma⌋+1=k.

Делим на m>0:

a<mk​=q.

Проверим правую границу. Из свойства целой части:

⌊ma⌋≤ma.

Прибавляем 1 и делим на m>0:

q=m⌊ma⌋+1​≤a+m1​.

Но шаг сетки меньше длины промежутка:

m1​<b−a.

Прибавляем a:

a+m1​<b.

Следовательно,

q≤a+m1​<b,

то есть

a<q<b.

Число q рационально, потому что его числитель k целый, а знаменатель m натуральный.

Как запомнить конструкцию

Длина интервала b−a → делаем сетку из дробей k/m с шагом 1/m<b−a → берём первую точку этой сетки строго правее a.
