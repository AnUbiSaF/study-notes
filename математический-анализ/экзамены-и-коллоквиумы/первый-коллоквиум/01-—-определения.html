Лекция 04 — Последовательность, семейство, конечный набор и упорядоченная пара

Последовательность, семейство, конечный набор, упорядоченная пара

Семейство

x:I→X,α↦xα​.

Семейство (xα​)α∈I​ — индексированная совокупность элементов множества X: каждому индексу α∈I соответствует элемент xα​∈X.

Последовательность

x:N→X,n↦xn​.

Последовательность — семейство с натуральными индексами: каждому номеру n∈N соответствует элемент xn​∈X.

Конечный набор

(x1​,…,xm​).

Конечный набор — конечная m-членная последовательность.

Упорядоченная пара

(x1​,x2​).

Упорядоченная пара — частный случай конечного набора при m=2. Порядок элементов существенен:

9. Декартово произведение

Декартово произведение множеств X и Y — это множество всех упорядоченных пар (x,y), где x∈X, а y∈Y:

X×Y={(x,y):x∈X, y∈Y}.

Для семейства множеств обобщение имеет вид

α∈I∏​Xα​.

Его элемент — набор, в котором для каждого индекса α выбран один элемент xα​∈Xα​.

Лекция 03 — Образ и прообраз

Образ и прообраз

Пусть f:X→Y.

Для A⊂X образ множества A:

f(A)={f(x):x∈A}⊂Y.

То есть образ — все элементы Y, в которые отображаются элементы A.

Для B⊂Y прообраз множества B:

f−1(B)={x∈X:f(x)∈B}⊂X.

То есть прообраз — все элементы X, образы которых лежат в B. Прообраз может быть пустым; обратная функция для него не нужна.

2. Инъекция, сюръекция и биекция

Инъекция, сюръекция и биекция — определения

Пусть f:X→Y — отображение.

Удобно смотреть на уравнение

f(x)=y.
  • Сюръекция: для каждого y∈Y существует хотя бы один x∈X.
  • Инъекция: для каждого y∈Y существует не более одного x∈X.
  • Биекция: для каждого y∈Y существует ровно один x∈X.

Лекция 04 — Композиция, сужение и продолжение

Композиция, сужение и продолжение

Если f:X→Y и g:Y→Z, то композиция

g∘f:X→Z,(g∘f)(x)=g(f(x)).

Сначала применяется f, затем g.

Если A⊆X, то сужение f на A:

f∣A​:A→Y.

Правило остаётся тем же, но аргументы берутся только из A. Сужение сохраняет инъективность, но может уничтожить сюръективность.

Отображение g:B→Y — продолжение f:X→Y, если

X⊆B,g∣X​=f.

То есть g задано на большей области и совпадает с f на старой. Продолжение может уничтожить инъективность.

Лекция 04 — Обратное и тождественное отображения

Обратное и тождественное отображения

Тождественное отображение:

idX​(x)=x.

То есть тождественное отображение оставляет каждый элемент множества X на месте.

Если f:X→Y — биекция, существует обратное отображение

f−1:Y→X,

причём

f−1∘f=idX​,f∘f−1=idY​.

У биекции у каждого y∈Y ровно один прообраз x∈X, поэтому можно однозначно сопоставить y этот x.

Пример: для f(x)=x2 на [0,+∞) обратное отображение равно f−1(y)=y​.

Метрики и нормированные пространства

🔴 Метрика, метрическое пространство, подпространство ✓

1. Метрика

Метрика на множестве X — отображение

ρ:X×X→R,

которое задаёт расстояние между элементами и удовлетворяет условиям:

  1. ρ(x,y)≥0, причём ρ(x,y)=0⟺x=y; (невырожденность)
  2. ρ(x,y)=ρ(y,x); (симметричность)
  3. ρ(x,y)≤ρ(x,z)+ρ(z,y). (нер-во треугольника)

Метрическое пространство — пара (X,ρ): множество точек X и метрика ρ, которая измеряет расстояние между ними.

Лекция 14 — Метрическое подпространство

Метрическое подпространство

Пусть (X,ρ) — метрическое пространство и

Y⊆X.

Ограничим метрику ρ на пары точек из Y:

ρY​=ρ​Y×Y​,ρY​:Y×Y→R.

То есть

∀y1​,y2​∈Y:ρY​(y1​,y2​)=ρ(y1​,y2​).

Тогда (Y,ρY​) называется метрическим подпространством
пространства (X,ρ).

Расстояния между точками Y не изменяются; ограничивается только
множество рассматриваемых точек.

Лекция 02 — Шары и окрестность

Шары и окрестность

Открытый шар с центром a и радиусом r>0:

B(a,r)={x∈X:ρ(x,a)<r}.

Замкнутый шар:

B(a,r)={x∈X:ρ(x,a)≤r}.

ε-окрестность точки a — открытый шар с центром a и радиусом ε>0:

Uε​(a)=B(a,ε)={x∈X:ρ(x,a)<ε}.

То есть это все точки, расстояние от которых до a меньше ε.

Линейное пространство ✓

Лекция 05 — Линейное пространство

Линейное (векторное) пространство

Пусть K — поле скаляров. Линейное (векторное) пространство X над K — множество векторов, в котором определены сложение и умножение на скаляр:

X×X→X,(x,y)↦x+y, K×X→X,(α,x)↦αx.

Оно называется линейным, только если выполнены все 7 аксиом:

  1. Коммутативность сложения: x+y=y+x.
  2. Ассоциативность сложения: (x+y)+z=x+(y+z).
  3. Нулевой вектор: ∃0X​∈X: 0X​+x=x.
  4. Дистрибутивность по сложению скаляров: (α+β)x=αx+βx.
  5. Дистрибутивность по сложению векторов: α(x+y)=αx+αy.
  6. Согласованность умножения на скаляры: (αβ)x=α(βx).
  7. Единичный скаляр: 1x=x.

Если хотя бы одна из аксиом не выполнена, это не линейное пространство.

🔴 Норма, нормированное пространство, примеры ✓

Лекция 05 — Норма

Норма

Норма — обобщённая длина вектора:

∥⋅∥:X→R.

Для любых x,y∈X и α∈K:

  1. Неотрицательность и определённость:
    ∥x∥≥0,∥x∥=0⟺x=0.
  2. Абсолютная однородность:
    ∥αx∥=∣α∣∥x∥.
  3. Неравенство треугольника:
    ∥x+y∥≤∥x∥+∥y∥.

Для ∞-нормы модуль ∣α∣ неотрицателен: умножение всех координат на одно такое число сохраняет их порядок, поэтому этот множитель можно вынести из максимума.

Линейное пространство с выбранной нормой называется нормированным пространством.

Примеры

На Rm:

∥x∥∞​=imax​∣xi​∣.

Например,

∥(−2,−3,−1)∥∞​=max{2,3,1}=3.

Почему это норма

Для ∥x∥∞​=maxi​∣xi​∣:

  1. ∥x∥∞​≥0, а равенство нулю возможно только при xi​=0 для всех i, то есть при x=0.
  2. ∥αx∥∞​=maxi​∣αxi​∣=∣α∣maxi​∣xi​∣=∣α∣∥x∥∞​. Множитель ∣α∣≥0 одинаков для всех координат, поэтому выносится из максимума.
  3. ∥x+y∥∞​=maxi​∣xi​+yi​∣≤maxi​(∣xi​∣+∣yi​∣)≤maxi​∣xi​∣+maxi​∣yi​∣. Первое неравенство — треугольник для каждой координаты; второе — каждая сумма не больше суммы максимумов.

Для ℓ∞ доказательство то же: вместо max берётся sup.

В ℓ∞, пространстве ограниченных последовательностей:

∥x∥∞​=nsup​∣xn​∣.

Например,

x=(−21​,−32​,−43​,…),∥x∥∞​=1.

Почему это норма на ℓ∞

Для x,y∈ℓ∞:

  1. ∥x∥∞​=supn​∣xn​∣≥0; равенство нулю возможно только при xn​=0 для всех n, то есть при x=0.
  2. ∥αx∥∞​=supn​∣αxn​∣=∣α∣supn​∣xn​∣=∣α∣∥x∥∞​. Множитель ∣α∣≥0 одинаков для всех членов, поэтому выносится из супремума.
  3. ∥x+y∥∞​=supn​∣xn​+yn​∣≤supn​(∣xn​∣+∣yn​∣)≤supn​∣xn​∣+supn​∣yn​∣. Первое неравенство — неравенство треугольника для каждого номера n; второе — каждая сумма не больше суммы супремумов.

Лекция 06 — Метрика, порождённая нормой

Метрика, порождённая нормой

Пусть x и y — векторы нормированного пространства. Метрика, порождённая нормой, задаётся формулой

ρ(x,y)=∥x−y∥.

То есть расстояние между x и y равно длине вектора x−y.

В частности, норма вектора равна его расстоянию до нуля:

∥x∥=ρ(x,0).

Любая норма задаёт метрику. Обратно неверно: не всякая метрика согласована с умножением векторов на числа.

Почему это метрика

  1. Неотрицательность и определённость: ρ(x,y)=∥x−y∥≥0, причём ρ(x,y)=0⟺x−y=0⟺x=y.
  2. Симметрия: x−y=−(y−x), поэтому ρ(x,y)=∥x−y∥=∥−(y−x)∥=∣−1∣∥y−x∥=ρ(y,x). Здесь используется абсолютная однородность нормы: ∥αv∥=∣α∣∥v∥.
  3. Неравенство треугольника: из x−y=(x−z)+(z−y) следует ρ(x,y)=∥x−y∥≤∥x−z∥+∥z−y∥=ρ(x,z)+ρ(z,y).

Контрпример: метрика, которая не порождена нормой

На R рассмотрим метрику

ρ(a,b)=1+∣a−b∣∣a−b∣​.

Для неё

ρ(1,0)=21​,ρ(2,0)=32​.

Для метрики от нормы из однородности должно следовать

ρ(2,0)=2ρ(1,0)=1.

Но 32​=1, поэтому эта метрика не порождена нормой.

Лекции 02–03 — Ограниченное множество, последовательность и функция

Ограниченное множество, последовательность и функция

Множество

Пусть (X,ρ) — метрическое пространство, A⊂X, а a∈X — центр шара.

∃a∈X∃R>0:A⊂B(a,R).

Множество A ограничено, если оно целиком помещается в некоторый шар конечного радиуса. Само существование A ограниченности не гарантирует: например, R в обычной метрике не ограничено.

Последовательность

∃a∈X∃R>0∀n∈N:ρ(xn​,a)<R.

Последовательность (xn​) ограничена, если все её члены лежат в одном шаре конечного радиуса.

Функция

∃a∈X∃R>0:f(Y)⊂B(a,R).

Функция f:Y→X ограничена, если множество всех её значений лежит в одном шаре конечного радиуса.

Короткий пример

{n1​:n∈N}

бесконечно, но ограничено: все его элементы помещаются в шар конечного радиуса.

Лекция 02 — Предел последовательности

Предел последовательности

Пусть (xn​) — последовательность в метрическом пространстве (X,ρ). Точка a∈X называется её пределом, если

∀ε>0∃K∈N∀n>K:ρ(xn​,a)<ε.

Какую бы малую точность ε мы ни задали, начиная с некоторого номера K все члены последовательности находятся от a на расстоянии меньше ε.

xn​→a.

Номер K может зависеть от ε.

Фиксированный множитель C>0 перед ε не меняет определение: когда ε пробегает все положительные числа, Cε также пробегает все положительные числа.

Лекция 13 — Окрестность и проколотая окрестность

Окрестность точки, проколотая окрестность

Пусть (X,ρ) — метрическое пространство, x∈X, ε>0.

Окрестность точки

Uε​(x)=B(x,ε)={y∈X:ρ(x,y)<ε}.

ε-окрестность точки x — открытый шар радиуса ε с центром в точке x.

Проколотая окрестность

U˙ε​(x)=Uε​(x)∖{x}={y∈X:0<ρ(x,y)<ε}.

Проколотая ε-окрестность точки x — её ε-окрестность, из которой удалена сама точка x.

Обычная окрестность содержит центр x, проколотая — не содержит.

Лекция 11 — Предел последовательности на языке окрестностей

Предел последовательности на языке окрестностей

Пусть (xn​) — последовательность в метрическом пространстве (X,ρ), а a∈X. Через U(a) обозначим произвольную окрестность точки a.

xn​→a⟺∀U(a)∃N∈N∀n>N:xn​∈U(a).

Последовательность стремится к точке a, если для любой окрестности U(a) точки a существует номер N, такой что при всех n>N выполняется xn​∈U(a).

В метрическом пространстве достаточно проверять ε-окрестности: xn​∈Uε​(a)⟺ρ(xn​,a)<ε. Поэтому это то же ε-N определение, записанное геометрическим языком.

Лекция 11 — Последовательность, стремящаяся к бесконечности

Последовательность, стремящаяся к бесконечности

Пусть (xn​) — вещественная последовательность.

xn​→+∞⟺∀E∈R∃N∈N∀n>N:xn​>E.

Последовательность стремится к +∞, если весь её хвост выше любого заданного уровня E.

Здесь E — произвольный уровень; достаточно проверять только E>0.

xn​→−∞⟺∀E∈R∃N∈N∀n>N:xn​<E.

Последовательность стремится к −∞, если весь её хвост ниже любого заданного уровня E.

xn​→∞⟺∀R>0∃N∈N∀n>N:∣xn​∣>R.

Последовательность стремится к беззнаковой бесконечности, если весь её хвост выходит за любой отрезок [−R,R]. Знак членов может меняться.

Если xn​→+∞ или xn​→−∞, то ∣xn​∣→+∞. Обратно неверно: знак членов может бесконечно меняться.

Записи n>N и n≥N задают один и тот же хвост: меняется только номер начала.

Пример со сменой знака

xn​=(−1)nn.

Последовательность не стремится ни к +∞, ни к −∞, но ∣xn​∣=n→+∞; значит, xn​→∞ в беззнаковом смысле.

Возрастающая, убывающая, монотонная функция ✓

Возрастающая, убывающая и монотонная функция

Возрастающая, убывающая и монотонная функция

Пусть D⊂R, f:D→R.

Функция называется возрастающей на D, если

∀x1​,x2​∈D:x1​<x2​⇒f(x1​)≤f(x2​).

Функция называется убывающей на D, если

∀x1​,x2​∈D:x1​<x2​⇒f(x1​)≥f(x2​).

Функция называется монотонной на D, если она возрастает или убывает на D.

Здесь «возрастающая» и «убывающая» понимаются в нестрогом смысле: постоянная функция одновременно возрастающая и убывающая, следовательно, монотонная. Для строгого возрастания или убывания в определениях ставят < и > вместо ≤ и ≥.

Источник: лекция 15, §2.2.

Лекции 05 и 07 — Аксиомы вещественных чисел

Аксиомы вещественных чисел

R — упорядоченное поле: пара (K,≤), где K должно быть полем, а ≤ — линейным порядком, согласованным с операциями.

1. Поле

Чтобы K было полем, на нём должны быть заданы операции сложения и умножения. Для любых a,b,c∈K должны выполняться следующие аксиомы:

  1. Коммутативность:
    a+b=b+a,ab=ba.
  2. Ассоциативность:
    (a+b)+c=a+(b+c),(ab)c=a(bc).
  3. Нулевой и единичный элементы: существуют 0 и 1=0:
    a+0=a,a⋅1=a.
  4. Противоположный элемент: для каждого a существует −a:
    a+(−a)=0.
  5. Обратный элемент: для каждого a=0 существует a−1:
    aa−1=1.
  6. Дистрибутивность:
    a(b+c)=ab+ac.

Значит, в поле можно выполнять обычные алгебраические действия, включая деление на ненулевой элемент.

2. Линейный порядок

Чтобы нестрогое отношение ≤ было линейным порядком, оно должно удовлетворять трём аксиомам. Для любых x,y,z∈K:

  1. Сравнимость: x≤y или y≤x.
  2. Транзитивность: x≤y, y≤z⇒x≤z.
  3. Антисимметричность: x≤y, y≤x⇒x=y.

3. Согласованность порядка с операциями

Чтобы (K,≤) было упорядоченным полем, порядок должен удовлетворять ещё двум аксиомам:

  1. Согласованность со сложением: x≤y⇒x+z≤y+z.
  2. Согласованность с умножением: 0≤x, 0≤y⇒0≤xy.

Бинарное отношение

Бинарное отношение R на X — любое подмножество R⊆X×X; аксиом для него не требуется.

Строгий порядок

В лекции аксиомы проверяются только для нестрогого отношения ≤. Знак < не задаёт новый порядок и не требует отдельного списка аксиом: это сокращение «меньше или равно, но не равно»:

x<y⟺(x≤y и x=y).

Поэтому 2≤2 верно, а 2<2 неверно; при 2<3 верны обе записи: 2<3 и 2≤3.

Почему C нельзя упорядочить как поле

В упорядоченном поле квадрат ненулевого элемента положителен. Тогда 1=12>0 и i2=−1>0, поэтому 0=1+(−1)>0 — противоречие.

Аксиома Архимеда

Для любых положительных x и y существует натуральное n, для которого

nx>y.

То есть конечным числом одинаковых положительных шагов можно превзойти любую заданную величину.

∀y∈R ∃n∈N:n>y.

[a1​,b1​]⊇[a2​,b2​]⊇[a3​,b3​]⊇⋯

Лекция 10 — Ограниченное множество, границы и максимум

Ограниченное множество в R, границы, максимум

Пусть E⊆R.

Ограниченность сверху

∃c∈R ∀x∈E:x≤c.

Число c называется верхней границей множества E.

Ограниченность снизу

∃c∈R ∀x∈E:c≤x.

Число c называется нижней границей множества E.

Множество называется ограниченным, если оно ограничено сверху и снизу.

Максимум

Число m является максимумом множества E, если

m∈Eи∀x∈E:x≤m.

Тогда m=maxE: это наибольший элемент самого множества.

Лекция 10 — Супремум, инфимум и техническое описание

Супремум, инфимум. Техническое описание супремума

Пусть E⊆R.

Супремум и инфимум

supE=min{c∈R: ∀x∈Ex≤c}.

То есть супремум — наименьшая верхняя граница.

infE=max{c∈R: ∀x∈Ec≤x}.

То есть инфимум — наибольшая нижняя граница.

Супремум и инфимум могут не принадлежать E. Если принадлежат, то являются соответственно maxE и minE.

Техническое описание супремума

Пусть E непусто и ограничено сверху. Тогда M=supE тогда и только тогда, когда:

  1. M — верхняя граница: ∀x∈E:x≤M;
  2. к M можно подойти элементами E сколь угодно близко снизу: ∀ε>0 ∃x∈E:M−ε<x≤M.

Первое условие говорит: выше M элементов нет. Второе: между E и M нет положительного зазора.

Соглашения

supE=+∞

для множества, не ограниченного сверху;

infE=−∞

для множества, не ограниченного снизу;

sup∅=−∞,inf∅=+∞.Ссылка на оригинал

Супремум функции и последовательности

Функция

Пусть

f:D→R,

Множество всех значений функции:

f(D)={f(x):x∈D}.

∃C∈R ∀x∈D:f(x)≤C.

x∈Dsup​f(x)=supf(D).

∃C∈R ∀n∈N:xn​≤C.

Векторнозначная функция, её координатные функции ✓

Векторнозначная функция и координатные функции

Векторнозначная функция и координатные функции

Warning

⚠️ На лекциях тема не разбиралась. Карточка составлена по Виноградову.

Пусть f:X→Rm. Функция f называется векторнозначной, если каждому x∈X она сопоставляет вектор из m координат:

f(x)=(f1​(x),…,fm​(x)).

Функция fk​:X→R, возвращающая k-ю координату вектора f(x), называется k-й координатной функцией. Таким образом,

f=(f1​,…,fm​).

То есть одна векторнозначная функция — это несколько числовых функций, собранных в один вектор. Например,

f:R→R2,f(t)=(t2,sint),

имеет координатные функции f1​(t)=t2 и f2​(t)=sint.

Область определения

Чтобы f:X→Rm была функцией, каждая координатная функция fk​ должна быть определена для любого x∈X. Если хотя бы одно fk​(x) не существует, то не существует и весь вектор f(x); область определения нужно сузить.

Например, f(x)=(x,lnx) задаёт функцию (0,+∞)→R2, но не функцию R→R2.

Лекция 09 — Скалярное произведение и порождённая норма

Скалярное произведение, норма, порождённая скалярным произведением

Пусть X — линейное пространство над полем K, где

K=RилиK=C.

Скалярное произведение — отображение

⟨⋅,⋅⟩:X×X→K,

которое паре векторов (x,y) сопоставляет число ⟨x,y⟩.

Чтобы отображение было скалярным произведением, оно должно удовлетворять трём аксиомам.

  1. Линейность по первому аргументу: ⟨αx+βz,y⟩=α⟨x,y⟩+β⟨z,y⟩. При фиксированном y можно сначала смешать векторы αx+βz, а потом умножить на y; либо умножить каждый на y отдельно и смешать результаты с теми же коэффициентами.
  2. Эрмитова симметрия: ⟨y,x⟩=⟨x,y⟩​. При перестановке векторов результат комплексно сопрягается; над R сопряжение ничего не меняет: ⟨x,y⟩=⟨y,x⟩.
  3. Положительная определённость: ⟨x,x⟩≥0,⟨x,x⟩=0⟺x=0. Поэтому ⟨x,x⟩ можно понимать как квадрат длины.

Норма, порождённая скалярным произведением:

∥x∥=⟨x,x⟩​.

«Порождённая» означает: сначала задано скалярное произведение, а эта формула определяет его норму. Величина ⟨x,x⟩ неотрицательна и при замене x на αx умножается на ∣α∣2, поэтому ведёт себя как квадрат длины. Корень возвращает саму длину: норма увеличивается в ∣α∣ раз, как и должна.

Параллелепипед в R^m ✓

Виноградов — Параллелепипед в R^m

Параллелепипед в Rm

Точка в Rm — это набор из m чисел:

x=(x1​,…,xm​).

Возьмём два таких набора:

a=(a1​,…,am​),b=(b1​,…,bm​),

где ai​<bi​ для каждого i.

Замкнутый параллелепипед

[a,b]={(x1​,…,xm​)∈Rm:∀i∈{1,…,m}ai​≤xi​≤bi​}.

Здесь i — только номер проверяемой координаты. Параллелепипед содержит готовые наборы x=(x1​,…,xm​), для которых все эти проверки выполнены.

В R2:

[(1,2),(4,5)]={(x1​,x2​):1≤x1​≤4, 2≤x2​≤5}.

Это прямоугольник вместе с его сторонами.

Куб

Если все рёбра одной длины,

b1​−a1​=…=bm​−am​,

то параллелепипед называется кубом.

Открытый и общий параллелепипеды

(a,b)={x∈Rm:ai​<xi​<bi​ для каждого i}

— тот же параллелепипед без границы.

Виноградов называет параллелепипедом любое множество Δ, для которого

(a,b)⊆Δ⊆[a,b].

То есть внутренность должна войти целиком, а граничные точки можно включать или не включать.

Лекции 12–13 — Внутренняя точка, открытое множество и внутренность

Внутренняя точка множества, открытое множество, внутренность

Пусть (X,ρ) — метрическое пространство, а M⊂X — изучаемое множество.

Для точки p∈M открытый шар радиуса r>0 с центром в p:

Br​(p)={x∈X:ρ(x,p)<r}.

Здесь p — фиксированный центр шара, а x перебирает точки всего пространства X.

Внутренняя точка

Точка p∈M называется внутренней для M, если

∃r>0:Br​(p)⊂M.

То есть вокруг p можно выбрать шар, который целиком лежит в M.

Открытое множество

Множество M называется открытым, если каждая его точка внутренняя:

∀p∈M ∃r>0:Br​(p)⊂M.

Внутренность множества

Внутренность intM — это множество всех внутренних точек M:

intM={p∈M:∃r>0, Br​(p)⊂M}.

Иначе: сначала проверяем точки M по одной, затем собираем все прошедшие проверку точки в intM.

Внутренность открыта и является наибольшим открытым подмножеством M. В частности,

M открыто⟺M=intM.Ссылка на оригинал

Предельная точка множества ✓

Лекция 13 — Предельная точка множества

Предельная точка множества

Пусть (X,ρ) — метрическое пространство, D⊂X, p∈X.

Проколотый шар радиуса r>0:

B˙r​(p)=Br​(p)∖{p}={x∈X:0<ρ(x,p)<r}.

Это шар вокруг p, из которого удалили сам центр p.

Точка p называется предельной точкой множества D, если любая её проколотая окрестность пересекается с D:

∀r>0B˙r​(p)∩D=∅.

Равносильно:

∀r>0 ∃x∈D:0<ρ(x,p)<r.

То есть какой бы малый радиус ни выбрали, найдётся точка D, отличная от p, на расстоянии меньше этого радиуса. При новом радиусе точку x можно выбирать заново.

Мини-пример

Пусть D=(0,1)⊂R. Тогда 0∈/D, но 0 — предельная точка D: при любом r>0 число x=min{r/2,1/2} лежит в D и удовлетворяет 0<∣x−0∣<r.

Если D=[0,1], то 0∈D и всё равно 0 — предельная точка D: рядом с нулём есть другие точки отрезка. Предельная точка может как входить, так и не входить в множество.

Замкнутое множество, замыкание, граница ✓

Лекция 13 — Замкнутое множество и замыкание

Замкнутое множество, замыкание, граница

Пусть (X,ρ) — метрическое пространство, D⊂X.

Замкнутое множество

Обозначим через D′ множество всех предельных точек D:

D′={p∈X:∀r>0:B˙r​(p)∩D=∅}.

D называется замкнутым, если содержит все свои предельные точки:

D замкнуто⟺D′⊆D.

С кванторами:

D замкнуто⟺[∀p∈X:p∈D′⟹p∈D].

Эквивалентно:

D замкнуто⟺∀p∈X∖D ∃r>0:Br​(p)∩D=∅.

А значит,

D замкнуто⟺X∖D открыто.

Замыкание

Замыкание D — это исходное множество вместе со всеми его предельными точками:

D=D∪{p∈X:p — предельная точка D}.

Это наименьшее по включению замкнутое множество, содержащее D: точки D не выбрасываются, добавляются нужные предельные точки, но не лишние.

Технически:

D=F⊃DF замкнуто в X​⋂​F.

Здесь F перебирает все замкнутые множества, содержащие D. Их пересечение замкнуто, содержит D и лежит в каждом таком F, поэтому оно — наименьшее по включению.

D замкнуто⟺D=D.

Например,

(0,1)​=[0,1].

Не путать замыкание и замкнутый шар

В общем метрическом пространстве замыкание открытого шара B(a,r)​ не обязано совпадать с замкнутым шаром B(a,r)={x:ρ(x,a)≤r}.

Например, в X={a,b} с дискретной метрикой и при r=1:

B(a,1)={a},B(a,1)​={a},

но

B(a,1)={a,b}.

В первой записи черта означает операцию замыкания; во второй — условие ρ(x,a)≤r.

Граница множества

Граница множества D — множество всех точек, каждая окрестность
которых пересекается и с D, и с его дополнением X∖D:

∂D={a∈X:∀r>0:Br​(a)∩D=∅ ∧ Br​(a)∩(X∖D)=∅}.

То есть

a∈∂D⟺∀r>0:{Br​(a)∩D=∅,Br​(a)∩(X∖D)=∅.​

Граничная точка не обязана принадлежать D.

Например, в R:

∂(3,4)=∂[3,4]={3,4},∂Q=R,∂∅=∅.

Изолированная точка, граничная точка ✓

Лекция 13 — Изолированная точка

Изолированная точка, граничная точка

Пусть (X,ρ) — метрическое пространство, D⊂X.

Изолированная точка

Пусть p∈D.

Точка p называется изолированной точкой D, если она не является предельной точкой D:

∃r>0:B˙r​(p)∩D=∅.

Равносильно:

∃r>0:Br​(p)∩D={p}.

То есть можно выбрать шар вокруг p, в котором из точек D есть только p.

В отличие от предельной точки, изолированная точка по определению принадлежит D.

Например, для D=Z⊂R любая точка k∈Z изолирована:

B1/2​(k)∩Z={k}.

Граничная точка

Пусть a∈X. Точка a называется граничной точкой D, если
любая её окрестность пересекается и с D, и с его дополнением:

a — граничная точка D⟺∀r>0:{Br​(a)∩D=∅,Br​(a)∩(X∖D)=∅.​

При этом

a∈Dне требуется.

Например, в R точки 3 и 4 являются граничными и для
(3,4), и для [3,4]:

3,4∈∂(3,4),3,4∈∂[3,4].

Не путать предельную и граничную точки

Для предельной точки требуется пересечение каждой проколотой
окрестности с D:

a∈D′⟺∀r>0:B˙r​(a)∩D=∅.

Для граничной точки требуется пересечение обычной окрестности сразу
с D и с X∖D.

Лекция 14 — Четыре определения предела отображения

Определения предела отображения (4 шт)

Пусть

(X,ρX​), (Y,ρY​)

— метрические пространства,

D⊆X,f:D→Y,a∈D′,L∈Y.

Во всех четырёх определениях используется обозначение

x→alim​f(x)=L.

1. Определение Коши

∀ε>0 ∃δ>0 ∀x∈D:0<ρX​(x,a)<δ⟹ρY​(f(x),L)<ε.​

Сначала задаётся допустимая погрешность ε для значений
f(x). Под неё выбирается δ для аргументов, причём выбранное
δ должно работать для всех допустимых x∈D.

Зачем нужны две метрики?

Например, если

f:R2→R,

то близость аргументов измеряется в R2, а близость значений
— в R:

ρX​(x,a)=(x1​−a1​)2+(x2​−a2​)2​,ρY​(f(x),L)=∣f(x)−L∣.

2. Определение на языке окрестностей

Для каждой окрестности U(L) в Y существует окрестность V(a)
в X, для которых

f((V(a)∩D)∖{a})⊆U(L).​

С кванторами:

∀U(L) ∃V(a) ∀x∈(V(a)∩D)∖{a}:f(x)∈U(L).

3. Определение Гейне

∀(xn​):[∀n∈N: xn​∈D∖{a},xn​→a]⟹f(xn​)→L.​

Квантор ∀(xn​) существенен: условие должно выполняться для
каждой допустимой последовательности xn​→a.

4. Определение на языке открытых множеств

Полная запись:

∀G⊆Y:[G открыто в Y ∧ L∈G]⟹∃F⊆X:{F открыто в X,a∈F,∀x∈(F∩D)∖{a}:f(x)∈G.​

Открытость и принадлежность точек дают

G открыто, L∈GF открыто, a∈F​⟹∃ε>0:Uε​(L)⊆G,⟹∃δ>0:Vδ​(a)⊆F.​

Значит, G содержит окрестность L, а F содержит окрестность a.
Все точки x∈D∩F, кроме a, при этом отображаются в G.

Почему точка a исключается

Во всех определениях рассматриваются только точки

x∈D∖{a}.

Поэтому значение f(a) не влияет на предел; функция может быть даже
не определена в точке a.

Топология и топологическое пространство

Семейство T⊆2X называется топологией на X, если:

  1. ∅∈T и X∈T;
  2. объединение произвольного семейства множеств из T принадлежит T;
  3. пересечение конечного количества множеств из T принадлежит T.

Пара (X,T) называется топологическим пространством. Множества из T называются открытыми.

Связь топологии с метрикой

Метрика ρ на X порождает топологию

Tρ​={G⊆X: ∀x∈G ∃r>0: Br​(x)⊆G}.

Это совокупность всех множеств, открытых относительно метрики ρ.

Топология T называется метризуемой, если существует метрика ρ на X, для которой

Tρ​=T.

Примеры

  • Метризуемая: дискретная топология T=2X. Её порождает метрика

    ρ(x,y)={0,1,​x=y,x=y.​

    При r=21​ имеем Br​(x)={x}, поэтому открыто любое подмножество X.

  • Неметризуемая: на X={1,2} топология

    T={∅,{1},X}

    не порождается метрикой: при любой метрике множество {2}=Bρ(1,2)/2​(2) должно быть открытым, но {2}∈/T.

Источники: лекция 15, §8; согласованное пользовательское дополнение о метризуемости.
