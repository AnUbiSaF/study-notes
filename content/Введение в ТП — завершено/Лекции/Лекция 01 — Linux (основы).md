# Переменные окружения Linux

Переменная окружения — это настройка вида:

```bash
NAME=value
```

Примеры:

```bash
HOME=/home/user
USER=user
PATH=/usr/bin:/bin
SHELL=/bin/bash
```

## Получить значение переменной

```bash
echo $HOME
```

`$HOME` — взять значение переменной `HOME`.

## Создать переменную

```bash
MY_VAR=hello
```

Создаёт переменную в текущем shell.

```bash
echo $MY_VAR
```

выведет:

```text
hello
```

## `export`

```bash
export MY_VAR=hello
```

`export` делает переменную доступной программам и новым shell, которые запускаются из текущего shell.

```text
без export:
текущий shell → переменная есть
дочерняя программа → может не видеть

с export:
текущий shell → переменная есть
дочерняя программа → переменную получает
```

Пример:

```bash
export MY_VAR=hello
bash -c 'echo $MY_VAR'
```

Новый `bash` увидит `MY_VAR` и выведет `hello`.

## `env`

```bash
env
```

Показывает переменные окружения.

## `PATH`

`PATH` — список директорий, в которых shell ищет команды.

Пример:

```text
PATH=/usr/local/bin:/usr/bin:/bin
```

Папки разделяются `:`.

Если написать:

```bash
gcc
```

shell будет искать `gcc` в директориях из `PATH`.

Посмотреть:

```bash
echo $PATH
```

### Добавить папку в PATH

```bash
export PATH=$PATH:/home/user/.dotnet
```

Здесь:

```bash
$PATH
```

— старое значение PATH,

а:

```bash
:/home/user/.dotnet
```

— новая директория в конце списка.

То есть:

```text
старый PATH
+
новая папка
=
новый PATH
```

## Основные переменные

```text
PATH  — где искать команды
HOME  — домашняя директория
USER  — текущий пользователь
SHELL — текущий shell
LANG  — язык и локаль
PS1   — вид приглашения shell
```

## Время жизни

Если написать:

```bash
export TEST=123
```

переменная существует в текущей сессии shell.

После закрытия терминала она обычно исчезнет.

Чтобы настройка создавалась при запуске shell, её можно записать, например, в:

```bash
~/.bashrc
```

и применить изменения:

```bash
source ~/.bashrc
```
## Главное

```text
NAME=value     — создать переменную
$NAME          — получить значение
export         — передавать её дочерним программам
env            — показать переменные окружения
PATH           — где shell ищет команды
```
