# Практика 08 — Эллипс и гипербола

> [!note]
> Карточка содержит краткий маршрут по практике. Формулы и решения задач находятся в сворачиваемых блоках.

## Краткая схема

> [!summary]
> Сначала определить тип кривой и её параметры $a,b,c$. Для эллипса использовать $a^2=b^2+c^2$, для гиперболы — $c^2=a^2+b^2$. Через заданные точки удобнее искать $1/a^2$ и $1/b^2$; для касательной с данным наклоном после подстановки требуется $D=0$.
