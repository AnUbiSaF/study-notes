# C++ — шпаргалка по лекции

[[Практики по C++|← К списку практик]]

## Память
```cpp
int *p = new int;
delete p;

int *arr = new int[n];
delete[] arr;
```

- `new` выделяет память и возвращает адрес.
- `delete` / `delete[]` освобождают её.
- `nullptr` — указатель никуда не указывает.

## Ссылки
```cpp
int a = 5;
int &ref = a;
ref = 10; // a = 10
```

- ссылка — второе имя переменной;
- её нужно сразу привязать к объекту;
- перенаправить потом нельзя.

В функции:
```cpp
void f(int &x) {
    x = 10;
}
```

`const int &x` — через ссылку значение менять нельзя.

## Перегрузка
```cpp
int f(int x);
int f(int x, int y);
double f(double x);
```

Можно иметь функции с одним именем, если отличаются аргументы.

Нельзя различать только по возвращаемому типу.

## Классы
```cpp
class Student {
private:
    int age;

public:
    void set_age(int age) {
        this->age = age;
    }
};
```

- поле — переменная внутри класса;
- метод — функция класса;
- `private` — доступ только из класса;
- `public` — доступ снаружи;
- `this` — указатель на текущий объект;
- `this->age` — поле текущего объекта.

## `::`
Если метод реализован вне класса:

```cpp
int Array::get(size_t index) {
    ...
}
```

`Array::get` = метод `get` класса `Array`.

## Конструктор и деструктор
```cpp
Array::Array(size_t size) {
    this->size = size;
    data = new int[size];
}

Array::~Array() {
    delete[] data;
}
```

- конструктор вызывается автоматически при создании объекта;
- деструктор — при уничтожении;
- конструктор обычно инициализирует объект;
- деструктор освобождает ресурсы.

## Связка с C
```text
malloc/free   → new/delete
struct        → class
p->field      → this->field
ручной init   → конструктор
ручная очистка→ деструктор
```
