# C++ — практика 3: краткий конспект

## `explicit`

Конструктор с одним аргументом без `explicit` может использоваться для неявного преобразования:

```cpp
A a = 5;
```

если существует:

```cpp
A(int x);
```

С `explicit`:

```cpp
explicit A(int x);
```

разрешено:

```cpp
A a(5);
A a{5};
```

но запрещено:

```cpp
A a = 5;
```

## Список инициализации

```cpp
Class::Class(int x)
    : field(x) {
}
```

`field` сразу создаётся со значением `x`.

Это отличается от:

```cpp
Class::Class(int x) {
  field = x;
}
```

где поле сначала создаётся, а потом получает новое значение через присваивание.

Особенно важно для полей-объектов без default-конструктора, `const`-полей и ссылок.

---

## `const`-методы

```cpp
int get() const;
```

Последний `const` означает: метод не меняет обычные поля текущего объекта.

`const`-метод можно вызвать и у обычного, и у `const`-объекта.

Не-`const` метод нельзя вызвать у `const`-объекта.

---

## `mutable`

`mutable` разрешает менять конкретное поле даже внутри `const`-метода.

```cpp
mutable double cached_value;
```

Главное применение здесь — кеширование:

```text
полином не меняется
но служебный кеш обновляется
```

## Перегрузка операторов

### Как метод

```cpp
A A::operator+(const A& other) const;
```

Вызов:

```cpp
a + b
```

по смыслу:

```cpp
a.operator+(b)
```

`this -> a`, `other -> b`.

### Как свободная функция

```cpp
A operator+(const A& a, const A& b);
```

Вызов:

```cpp
a + b
```

по смыслу:

```cpp
operator+(a, b)
```

---

## `+=` и `+`

Часто удобно сначала реализовать:

```cpp
A& A::operator+=(const A& other) {
  ...
  return *this;
}
```

а `+` через него:

```cpp
A operator+(A a, const A& b) {
  return a += b;
}
```

Почему `a` — копия: её можно менять, не изменяя исходный левый объект.

Почему `b` — `const&`: его нужно только читать.

---

## Два `operator[]`

```cpp
double& operator[](size_t i);
const double& operator[](size_t i) const;
```

Обычный объект:

```cpp
p[2] = 5;
```

`const`-объект:

```cpp
double x = p[2];
```

но менять через `p[2]` нельзя.

---

## Операторы сравнения

Обычно базово реализуют:

```cpp
==
<
```

а остальные выражают через них:

```cpp
!=
>
<=
>=
```

Например:

```cpp
a > b
```

то же самое, что:

```cpp
b < a
```

## Префиксный и постфиксный `++`

```cpp
A& operator++();     // ++a
A operator++(int);   // a++
```

Постфиксный вариант хранит старую копию, поэтому обычно дороже.

---

## Приведение типов

```cpp
explicit operator double() const;
```

Не меняет сам объект, а создаёт значение другого типа на основе его данных.

`const` нужен, потому что исходный объект только читается.

---

## Copy elision, RVO, NRVO

**Copy elision** — устранение лишнего копирования объекта компилятором.

RVO:

```cpp
return A(...);
```

NRVO:

```cpp
A result(...);
return result;
```

Идея: объект может быть сразу создан в месте, куда должен попасть результат, без промежуточной копии.
