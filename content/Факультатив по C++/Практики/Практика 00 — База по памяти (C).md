# C — база перед C++

[[Практики по C++|← К списку практик]]

## Указатели

- `&x` — адрес `x`
- `int *p = &x` — `p` хранит адрес `x`
- `*p` — значение по адресу `p`

## Функции
Обычная переменная через указатель:
```c
void f(int *p) {
    *p = 99;
}

int x = 10;
f(&x);
```

Массив:
```c
void f(int *p) {
    p[0] = 99;
}

int arr[3] = {10, 20, 30};
f(arr);
```

- переменная → передаём `&x`
- массив → `arr` при передаче ведёт себя как адрес первого элемента

## Массивы
- `arr[i] == *(arr + i)`
- `arr + 1` — следующий элемент, не следующий байт

## Динамическая память
```c
int *arr = malloc(n * sizeof(int));
...
free(arr);
```

- `malloc` выделяет память и возвращает её адрес
- `sizeof(int)` — размер одного `int` в байтах
- память из `malloc` нужно освобождать вручную
- после `free` обращаться к памяти нельзя

## struct
```c
struct Student {
    int age;
    int grade;
};
```

- `s.age` — доступ к полю
- `p->age` = `(*p).age`
- через указатель на структуру можно менять оригинал

## typedef
```c
typedef struct Student {
    int age;
} Student;
```

Позволяет писать `Student s;` вместо `struct Student s;`.

## const
- `const int *p` — нельзя менять `*p`
- `int *const p` — нельзя менять `p`

## size_t
Целочисленный тип для размеров и индексов.

## .h и .c
- `.h` — объявления / интерфейс
- `.c` — реализация
- `#include` подключает заголовок

Пример:
```c
// math.h
int add(int a, int b);
```

```c
// math.c
int add(int a, int b) {
    return a + b;
}
```
