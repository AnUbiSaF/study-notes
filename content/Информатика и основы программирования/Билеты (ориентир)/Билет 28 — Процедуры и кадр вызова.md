## Процедуры и переменные

**Процедура** — подпрограмма с параметрами и собственными локальными переменными каждого вызова. В C процедуру записывают как функцию: параметры получают входные значения, функция может вернуть результат или иметь тип `void`.

- **Глобальная переменная** объявляется вне функции и доступна в своей области видимости на уровне файла.
- **Локальная переменная** объявляется внутри блока; её имя доступно в соответствующей области исходного текста.
- **Область видимости** — где доступно имя. **Время хранения** — как долго существует объект. Эти понятия различны.

Глобальный объект существует всё время работы программы. На уровне файла `extern` ссылается на определение в другом модуле, а `static` ограничивает имя текущей единицей трансляции. Обычная локальная переменная имеет автоматическое время хранения: при новом вызове функция получает новое значение. Локальная `static` сохраняет значение между вызовами и существует всё время работы программы. Автоматическое время хранения не гарантирует физического размещения строго на стеке: компилятор может использовать регистры и оптимизации.

```c
void f(void) {
    int local = 0;
    static int calls = 0;
    ++local;
    ++calls;
}
```

При каждом вызове `local` начинается с `0`, а `calls` сохраняет предыдущее значение. Это показывает разницу времени хранения, а не области видимости: оба имени локальны для функции.

## Вызовы и кадры

При вызове функции сохраняется отдельное состояние её параметров и автоматических локальных переменных. Реализации обычно размещают такие состояния в стеке вызовов: каждый вызов создаёт кадр; после возврата программа восстанавливает состояние предыдущего. Поэтому рекурсивные вызовы могут одновременно хранить разные значения параметров.

![[lecture-06-call-stack.svg]]

Исторически `GOSUB` (*Go to subroutine* — переход к подпрограмме) в BASIC (*Beginner's All-purpose Symbolic Instruction Code*) и `PERFORM` в COBOL (*Common Business-Oriented Language*) были примерами подпрограмм. В 1958 году Fortran (*Formula Translation* — перевод формул) II Джона Бэкуса получил подпрограммы с параметрами; ALGOL (*Algorithmic Language* — алгоритмический язык) 60 в 1960 году поддержал отдельные локальные данные для вызовов и рекурсию — важный шаг к привычной модели кадра вызова.
