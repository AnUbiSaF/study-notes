# Конспект: аффинные пространства и барицентрические координаты

## 1. Деление отрезка и центр масс двух точек

Пусть точка `z` делит отрезок между точками `x` и `y`, а в них помещены массы `m₁` и `m₂` соответственно. Тогда центр масс имеет вид

`z = (m₁/(m₁ + m₂))x + (m₂/(m₁ + m₂))y`.

Коэффициент при точке равен массе, находящейся в этой точке. Геометрически расстояния обратно пропорциональны массам:

`|xz| : |zy| = m₂ : m₁`.

Это же является формулой деления отрезка в данном отношении.

## 2. Барицентрические (аффинные) комбинации трёх точек

Для точек `x, y, z`, не лежащих на одной прямой, точка

`p = λx + μy + νz`, где `λ + μ + ν = 1`,

называется аффинной (барицентрической) комбинацией. Коэффициенты позволяют определить положение `p` относительно треугольника `xyz`:

- `λ, μ, ν > 0` — точка внутри треугольника;
- один коэффициент равен нулю — точка лежит на противоположной стороне;
- один коэффициент отрицателен — точка лежит во внешней области за соответствующей стороной;
- два коэффициента отрицательны — точка находится в одной из угловых внешних областей.

Для системы трёх масс `m₁, m₂, m₃` в точках `x, y, z` центр масс:

`p = (m₁x + m₂y + m₃z)/(m₁ + m₂ + m₃)`.

Его можно находить последовательно: заменить две массы их центром масс, суммировать эти массы и затем найти центр масс полученной системы. Результат не зависит от выбранной пары.

## 3. Аффинное пространство

Аффинное пространство — множество точек, в котором можно вычитать точки, получая векторы, и прибавлять векторы к точкам. При этом:

- разность двух точек — вектор;
- к точке можно прибавить вектор и получить точку;
- нельзя складывать две точки как векторы без выбора начала координат.

Выбор точки `o` как начала связывает аффинное пространство с линейным: точка `x` описывается вектором `ox`. Смена начала координат не меняет геометрические объекты и аффинные комбинации.

## 4. Аффинные подпространства

Аффинное подпространство через точку `x` с направляющим линейным пространством `L` записывается как

`x + L = {x + v | v ∈ L}`.

Если `u₁, …, uᵣ` — векторы, то

`x + Lin(u₁, …, uᵣ)`

— аффинное подпространство, проходящее через `x`.

Его размерность равна `dim Lin(u₁, …, uᵣ)` и не превосходит `r`. Она равна `r` тогда и только тогда, когда векторы `u₁, …, uᵣ` линейно независимы.

Примеры:

- `x + Lin(u)` — прямая, если `u ≠ 0`;
- `x + Lin(u, v)` — плоскость, если `u` и `v` линейно независимы.

## 5. Отрезок как множество аффинных комбинаций

Отрезок с концами `x` и `y` задаётся формулой

`[x, y] = {λx + (1 − λ)y | 0 ≤ λ ≤ 1}`.

Это определение полезно тем, что работает не только в обычном евклидовом пространстве, но и в любом аффинном пространстве.

## 6. Аффинная оболочка

Аффинной оболочкой множества `B` называется множество всех конечных аффинных комбинаций его точек:

`Aff(B) = {Σ λᵢxᵢ | xᵢ ∈ B, Σ λᵢ = 1}`.

Это наименьшее аффинное подпространство, содержащее `B`.

Для `r` точек `x₁, …, xᵣ`:

`dim Aff(x₁, …, xᵣ) ≤ r − 1`.

Равенство достигается, когда точки аффинно независимы. Эквивалентно: для некоторой (и тогда любой подходящей) точки `o` векторы `ox₁, …, oxᵣ` имеют нужную линейную независимость после выбора базовой точки; обычно проверяют независимость векторов `x₂ − x₁, …, xᵣ − x₁`.

Примеры:

- две различные точки порождают прямую (размерность 1);
- три неколлинеарные точки порождают плоскость (размерность 2).

## Что важно запомнить

1. Аффинная комбинация отличается от линейной условием: сумма коэффициентов равна 1.
2. Положительные барицентрические координаты означают нахождение внутри выпуклой оболочки точек.
3. Любое аффинное подпространство — это «точка + линейное направляющее пространство».
4. Размерность аффинной оболочки `r` точек не больше `r − 1`.
