# Лекция 02 — Указатели и выравнивания

[[Лекции по программированию на C|← К списку лекций]]

Краткий конспект для подготовки к летучке по материалам лекции.

## Указатели

**Указатель** — переменная, значением которой является адрес объекта в памяти.

```c
int *p;
```

Важно:

```c
int *a, b;
```

`a` — указатель на `int`, `b` — обычный `int`.

### `&` и `*`

- `&x` — получить адрес `x`;
- `*p` — получить значение по адресу `p`.

`&` применяется к допустимым операндам, например к переменной или функции; взять адрес результата выражения `x + 1` нельзя. У некоторых объектов, например битовых полей, адрес взять тоже нельзя.

---

## `void *`

`void *` — указатель без информации о типе объекта.

```c
void *p;
```

В C `void *` можно присваивать указателю на объект другого типа и наоборот без явного каста. Для указателей на функции такой гарантии нет.

Разыменовывать `void *` напрямую нельзя: компилятор не знает размер и тип объекта.

`malloc` возвращает `void *`.

---

## Универсальные функции через `void *`

```c
void swap(void *a, void *b, size_t size);
```

Функция получает:
- адрес первого объекта;
- адрес второго объекта;
- размер объекта в байтах.

Через `memcpy` можно копировать `size` байт, не зная конкретный тип.

---

## Адресная арифметика

Разрешено:
- `pointer + k`;
- `pointer - k`;
- вычитание двух связанных указателей.

```c
pointer + k
```

сдвигает указатель на `k` элементов, а не на `k` байт.

Например для `int *p`:

```c
p + 1
```

сдвигается на `sizeof(int)` байт.

Массив:

```c
a[i] == *(a + i)
```

Также:

```c
&a[i] == a + i
```

Разность двух указателей даёт количество элементов между ними. Для результата используется `ptrdiff_t`.

Арифметика допустима в пределах одного массива или до позиции сразу после него; разность вычисляют для указателей на элементы одного массива или на эту позицию. Указатель за последним элементом разыменовывать нельзя.

---

## Сравнение указателей

`==`, `!=` — проверяют, одинаковый ли адрес.

Сравнения `<`, `>` имеют смысл для указателей, связанных с одним массивом/объектом.

```c
stack_end = stack + SIZE;
current = stack;
```

`stack_end` указывает **сразу после последнего элемента** массива.

---

## Многоуровневая адресация

```c
int x = 10;
int *p = &x;
int **q = &p;
```

- `q` — адрес `p`;
- `*q` — значение `p`, то есть адрес `x`;
- `**q` — значение `x`.

Каждый `*` снимает один уровень указателя.

---

## `NULL`

Неинициализированный локальный указатель содержит неопределённое значение.

Если указатель никуда не должен указывать:

```c
int *p = NULL;
```

или

```c
int *p = 0;
```

`NULL` легко проверить:

```c
if (p == NULL)
if (!p)
```

`free(NULL)` допустим.

Разыменование `NULL`:

```c
int *p = 0;
*p = 10;
```

→ undefined behavior, обычно `SIGSEGV`.

---

## Указатель на функцию

Функция имеет адрес, который можно сохранить в указателе.

```c
int (*f)(int);
```

`f` — указатель на функцию, принимающую `int` и возвращающую `int`.

```c
f = func;
f(10);
```

Можно динамически выбирать, какую функцию вызвать.

Применение: callback, обработчики, компаратор в `qsort`.

# Выравнивание и padding

Разные типы требуют подходящих адресов.

Типично:
- `int16_t` — адрес кратен 2;
- `int32_t`, `float` — кратен 4;
- `int64_t`, `double`, 64-битные указатели — кратен 8;
- `char` может лежать по любому адресу.

Это примеры для распространённых платформ, а не универсальные гарантии C: требования выравнивания зависят от реализации и не обязательно равны размеру типа.

## Padding

**Padding** — пустые байты, которые компилятор вставляет для правильного выравнивания полей.

```c
struct {
    char a;
    int b;
};
```

Типично:

```text
char a      1 байт
padding     3 байта
int b       4 байта
-------------------
итого       8 байт
```

Padding может быть:
- между полями;
- в конце структуры.

---

## Выравнивание структуры

Обычно структура выравнивается как минимум по самому требовательному полю; точные требования зависят от реализации.

```c
struct struct1 {
    char *p; // 8
    char c;  // 1
};
```

Типичный размер — `16`, а не `9`:

```text
p        8
c        1
padding  7
```

Это нужно, чтобы элементы массива таких структур тоже начинались с правильно выровненного адреса.

---

## Упаковка

Выравнивание можно изменить:

```c
#pragma pack(push, 1)
/* объявления упакованных структур */
#pragma pack(pop)
```

или:

```c
__attribute__((packed))
```

Packed-структуры уменьшают/убирают padding.

Это расширения компилятора, не переносимая возможность стандарта C. Упаковка сама по себе не гарантирует совместимость с протоколом: также важны порядок байтов, размеры типов и раскладка полей.

Применение:
- сетевые протоколы;
- бинарные форматы файлов;
- структуры оборудования.

Использовать везде не стоит: невыровненный доступ может быть медленнее или проблемным.

---

## Порядок полей

Порядок полей влияет на размер структуры.

Плохо:

```c
struct bad {
    char a;
    void *p;
    char c;
};
```

→ типично `24` байта.

Лучше:

```c
struct good {
    void *p;
    char a;
    char c;
};
```

→ типично `16` байт.

Правило: крупные поля обычно располагать раньше, чтобы уменьшить padding.

Компилятор сам поля не переставляет.

---

## Битовые поля

```c
struct flags {
    int a : 4;
    int b : 1;
};
```

`a` занимает 4 бита, `b` — 1 бит.

Применение:
- флаги;
- сетевые протоколы;
- регистры оборудования.

Раскладка битовых полей зависит от компилятора.

### Поле ширины `0`

```c
int a : 4;
int   : 0;
int b : 4;
```

Безымянное поле ширины `0` заставляет следующее поле начать новое слово выравнивания.

---

## `union`

```c
union value {
    int intValue;
    float floatValue;
} val;
```

Все поля `union` используют **один и тот же участок памяти**.

Размер `union` не меньше размера самого большого поля и может быть больше из-за выравнивания.

Например, при размере и выравнивании обоих типов по 4 байта на типичной платформе:

```c
sizeof(val) == 4
```

`union` полезен, если разные поля никогда не нужны одновременно.

---

## Самое важное к летучке

```text
void * = адрес без типа

a[i] == *(a + i)

pointer + 1 → сдвиг на sizeof(type)

NULL можно проверять, разыменовывать нельзя

int **q → два уровня указателя

указатель на функцию хранит адрес функции

padding = пустые байты ради выравнивания

структура обычно выравнивается по самому требовательному полю

порядок полей влияет на sizeof(struct)

packed → меньше/нет padding

int x : 4 → битовое поле шириной 4 бита

int : 0 → следующее поле с нового слова

union → все поля используют одну память
```
