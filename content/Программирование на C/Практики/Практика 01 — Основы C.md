# Практика 01 — Основы C

[[Практики по программированию на C|← К списку практик]]

> [!abstract] Кратко о практике
> Основы языка C: препроцессор, функции, области видимости, типы, указатели, память и структуры.

## Особенности C

- **Компилируемый язык**: исходный код обрабатывается компилятором и превращается в запускаемый файл.
- **Статическая типизация**: типы значений известны на этапе компиляции, поэтому часть ошибок ловится до запуска.
- **Слабая типизация**: возможны неявные преобразования типов.
- **Ручное управление памятью**: память можно явно выделять и освобождать.

## Declaration и Definition

- **Declaration** — делает имя сущности доступным для кода ниже.
- **Definition** — задаёт реализацию функции или выделяет память под переменную.
- Определение автоматически является объявлением.

```c
int foo(int);          // declaration

int foo(int x) {       // definition
    return x + 1;
}
```

## Препроцессор

Работает **до компиляции** и изменяет текст программы.

Основное:
- `#define`, `#undef` — макросы;
- `#include` — вставка содержимого файла;
- `#if`, `#ifdef`, `#ifndef`, `#elif`, `#else`, `#endif` — условная компиляция;
- `#pragma` — специальные инструкции компилятору.

### Макросы

Макрос — **текстовая подстановка**, а не функция.

```c
#define MAX(a, b) ((a) > (b) ? (a) : (b))
```

Аргументы подставляются как текст, без проверки типов, поэтому скобки важны.

### `#include`

`#include` **не подключает библиотеку**, а вставляет содержимое файла.

```c
#include <stdio.h>   // стандартные пути
#include "mylib.h"  // сначала текущая директория
```

Обычно:
- `<...>` — системные/сторонние headers;
- `"..."` — headers проекта.

### Header-файл

Обычно `.h`. Содержит объявления типов, переменных, функций и директивы препроцессора.

### Условная компиляция

Выполняется на этапе препроцессинга, а не во время работы программы.

```c
#ifdef __linux__
...
#endif
```

`0` — ложь, ненулевое значение — истина.

### `#pragma`

Передаёт специальные инструкции компилятору.

Примеры:
- управление предупреждениями GCC;
- OpenMP (`#pragma omp ...`).

## Функции

Если функция используется раньше определения, нужен прототип:

```c
int abs(int x);
```

Имена параметров в прототипе необязательны:

```c
int abs(int);
```

Для C99/C11 функцию без аргументов лучше писать так:

```c
int foo(void);
```

До C23 `int foo();` означало, что типы и количество аргументов не описаны.

Variadic-функция:

```c
int foo(int, ...);
```

`...` — переменное число аргументов.

## `static` и `extern`

### `static` у функции

```c
static int foo(void);
```

Функция видна только внутри текущего `.c`-файла.

### `static` у глобальной переменной

Тоже ограничивает видимость текущим файлом.

### `extern`

```c
extern int x;
```

Говорит, что определение глобальной переменной находится в другом месте.

## Scope и Lifetime

- **Scope** — где в исходном коде имя доступно.
- **Lifetime** — когда реально существует память объекта.

### Глобальная переменная

- объявлена вне функций;
- живёт всю программу;
- без явной инициализации получает ноль.

### Локальная переменная

- объявлена внутри блока;
- живёт до выхода из блока;
- без инициализации может содержать мусор.

### Локальная `static`

```c
void foo(void) {
    static int cnt = 0;
}
```

- scope остаётся локальным;
- lifetime — вся программа;
- инициализируется один раз;
- сохраняет значение между вызовами.

## Типы

Тип определяет размер/выравнивание, внутреннее представление, допустимые операции и правила взаимодействия с другими типами.

Обычный `char` может быть signed или unsigned — зависит от компилятора.

Если нужен точный размер, используют типы из `stdint.h`:

```c
int8_t
uint8_t
int32_t
```

Не гарантируется, что `int` всегда 4 байта.

`size_t` используется для размеров и индексов; `sizeof` возвращает `size_t`.

## Массивы, указатели и строки

Массив и указатель — разные типы.

В параметрах функции:

```c
void f(int *arr);
void f(int arr[]);
void f(int arr[8]);
```

эквивалентны как параметр — внутрь передаётся указатель, размер отдельно не передаётся.

Строка в C — массив `char`, заканчивающийся `\0`.

```text
'\0' — нулевой байт
'0'  — символ цифры 0
```

## Указатели и память

- `&x` — взять адрес.
- `*p` — разыменовать указатель.
- `NULL` — нет валидного адреса.
- неинициализированный указатель содержит мусор.

```c
malloc(size)        // выделить size байт, память не инициализируется
calloc(n, size)     // выделить n * size байт и заполнить нулями
realloc(p, size)    // изменить размер блока
free(p)             // освободить память
```

После `free` рекомендуется:

```c
p = NULL;
```

## Структуры

```c
struct point {
    int x;
    int y;
};
```

В C без `typedef` имя типа пишется со словом `struct`:

```c
struct point p;
```

Через указатель:

```c
ptr->x
```

эквивалентно:

```c
(*ptr).x
```

## `sizeof(*p)`

```c
malloc(sizeof(*p))
```

предпочтительнее, чем `malloc(sizeof(struct point))`: не нужно дублировать тип.

`sizeof(*p)` не выполняет реального разыменования.

## Практические правила

- инициализировать переменные;
- для внутренних функций/глобальных переменных использовать `static`;
- фиксированные целые — `stdint.h`;
- размеры/индексы — `size_t`;
- на каждый `malloc` должен быть `free`;
- после `free` — `NULL`;
- связанные значения лучше объединять в `struct`;
- не кастить результат `malloc`;
- лучше `sizeof(*ptr)`, чем `sizeof(type)`;
- проверять коды возврата функций;
- осторожнее с изменяемыми глобальными переменными.

> [!tip] Самое вероятное на летучке
>
> - `compiled` ≠ `statically typed`.
> - `declaration` ≠ `definition`.
> - Препроцессор работает до компиляции; макрос — текстовая подстановка, не функция.
> - `#include` вставляет текст файла, а не «подключает библиотеку».
> - `f(void)` — функция без аргументов.
> - `static` у функции или глобальной переменной ограничивает видимость текущим файлом; локальная `static` живёт всю программу.
> - `extern` означает, что определение переменной находится в другом месте.
> - `scope` ≠ `lifetime`.
> - Глобальная переменная без инициализации получает `0`, локальная может содержать мусор.
> - `int8_t` — 8-битный signed integer; `size_t` — тип размеров и индексов, результат `sizeof`.
> - `malloc` → мусор, `calloc` → нули, `realloc` → изменить размер, `free` → освободить.
> - `ptr->x == (*ptr).x`.
> - `sizeof(*p)` не разыменовывает `p` во время выполнения.
