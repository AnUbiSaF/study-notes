# Разбор практики 02 — Указатели и выравнивание

[[Практика 02 — Указатели и выравнивание|← К карточке практики]]

## Доступ через указатель

```c
int x = 10;
int *p = &x;

printf("%d\n", *p);
*p = 20;
int y = *p;
```

`p` хранит адрес `x`, `*p` — значение `x`.  
`int y = *p;` копирует значение, поэтому дальнейшее изменение `y` не меняет `x`.

## `swap`

```c
void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}
```

В C аргументы всегда передаются по значению. В `swap(&x, &y)` копируются адреса, поэтому через `*a` и `*b` меняются исходные переменные.

## Диапазон `[begin, end)`

```c
int sum(const int *begin, const int *end) {
    int s = 0;
    while (begin != end) {
        s += *begin;
        begin++;
    }
    return s;
}
```

`end` указывает сразу после последнего элемента и не разыменовывается.

## `my_strlen`

```c
size_t my_strlen(const char *s) {
    const char *p = s;
    while (*p)
        p++;
    return p - s;
}
```

`p - s` — число элементов между указателями.  
`strlen("test") == 4`: `'\0'` в длину не входит.

## `my_strcpy`

```c
void my_strcpy(char *dst, const char *src) {
    while ((*dst++ = *src++))
        ;
}
```

Сначала символ копируется, затем результат проверяется в `while`. Поэтому `'\0'` успевает записаться в `dst`, после чего условие становится ложным.

Эквивалентно:

```c
while (*src != '\0') {
    *dst = *src;
    dst++;
    src++;
}
*dst = '\0';
```

## Строковый литерал и массив

```c
char *p = "abc";   // литерал, менять нельзя
char a[] = "abc";  // отдельный изменяемый массив
```

Для строки:

```c
printf("%s\n", a);
```

Для одного символа:

```c
printf("%c\n", *a);
```

`char *` — это просто указатель на `char`; строкой он является только если по адресу лежит последовательность символов, заканчивающаяся `'\0'`.

## `const` и указатели

```c
const int *p1 = &a;       // нельзя менять *p1, можно менять p1
int *const p2 = &a;       // можно менять *p2, нельзя менять p2
const int *const p3 = &a; // нельзя менять ни *p3, ни p3
```

Шпаргалка:

```text
const int *p       → const данные
int *const p       → const указатель
const int *const p → const оба
```

## Объявление указателей

```c
int *a, b;
```

Здесь:

```text
a → int *
b → int
```

Два указателя:

```c
int *a, *b;
```

## Многоуровневые указатели

```c
int x = 10;
int *p = &x;
int **q = &p;
```

```text
q   → адрес p
*q  → p
**q → x
```

```c
**q = 20; // меняет x
*q = &y;  // заставляет p указывать на y
```

## `void *`

`void *` — адрес без информации о типе объекта.

```c
void swap(void *a, void *b, size_t size) {
    char *tmp = malloc(size);
    memcpy(tmp, a, size);
    memcpy(a, b, size);
    memcpy(b, tmp, size);
    free(tmp);
}
```

Разыменовать `void *` напрямую нельзя: неизвестен размер объекта. Поэтому отдельно передаётся `size`.

## Адресная арифметика

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;
p += 3;
```

Если `sizeof(int) == 4`, то `p` сдвинется на 12 байт.

```c
*p                         // 40
p - a                      // 3 элемента
(char *)p - (char *)a      // 12 байт
```

Почему `char *`: `sizeof(char) == 1`, поэтому разность считается в байтах.

Пример:

```text
a    = 0x1000
a+1  = 0x1004
a+2  = 0x1008
a+3  = 0x100C

p - a = 3
(char *)p - (char *)a = 12
```

## Массивы и указатели

```c
char str[80] = "abcdefgh";
char *p1 = str;
```

```c
str[4] == *(p1 + 4)
```

Общее правило:

```text
a[i] == *(a + i)
```

```c
sizeof str // размер всего массива
sizeof p1  // размер указателя
```

Указатель не хранит длину массива.

## `NULL`

```c
int *p = NULL;
```

Допустимо:

```c
p != NULL;
free(p);
```

Нельзя:

```c
*p;
p + 1;
```

Это UB.

Пример:

```c
int get_or_default(const int *p, int def) {
    return p ? *p : def;
}
```

## Указатели на функции

```c
int apply(int (*op)(int, int), int a, int b) {
    return op(a, b);
}
```

```c
int (*f)(int, int);
```

— указатель на функцию, принимающую два `int` и возвращающую `int`.

```c
int *f(int, int);
```

— функция, возвращающая `int *`.

Массив указателей:

```c
int (*ops[])(int, int) = {add, sub, mul};
```

## Компаратор для `qsort`

На слайде:

```c
int cmp_desc(const void *pa, const void *pb) {
    int a = *(const int *)pa;
    int b = *(const int *)pb;
    return (a < b) - (a > b);
}
```

Почему `void *`:

- интерфейс `qsort` универсальный;
- компаратор обязан принимать `const void *`;
- внутри конкретного компаратора тип уже известен, поэтому делается каст к `const int *`.

Разбор:

```c
(const int *)pa
```

— трактовать `pa` как указатель на `int`.

```c
*(const int *)pa
```

— получить сам `int` по этому адресу.

Для другого типа каст был бы другим:

```text
double → const double *
struct → const struct Type *
```

Строка:

```c
return (a < b) - (a > b);
```

даёт:

```text
a > b → -1
a < b →  1
a = b →  0
```

То есть большие значения идут раньше — сортировка по убыванию.

То же самое более явно:

```c
if (a > b)
    return -1;
if (a < b)
    return 1;
return 0;
```

## Самое важное

```text
*p → значение по адресу p
&p → адрес переменной

swap через указатели меняет оригинальные объекты

[begin, end) → end не разыменовывается

p - s → число элементов между указателями

strlen не считает '\0'
strcpy обязан скопировать '\0'

char *p = "abc" → литерал, менять нельзя
char p[] = "abc" → массив, менять можно

const int *p       → нельзя менять данные
int *const p       → нельзя менять p
const int *const p → нельзя менять оба

int *a, b → только a указатель

q → p → x
*q = p
**q = x

void * → адрес без типа

p + n → сдвиг на n * sizeof(*p) байт
p - a → разность в элементах
(char *)p - (char *)a → разность в байтах

a[i] == *(a + i)

sizeof массива ≠ sizeof указателя

NULL можно сравнивать и free
NULL нельзя разыменовывать

int (*f)(int, int) → указатель на функцию
int *f(int, int)   → функция, возвращающая int *

qsort-компаратор:
const void * → каст к реальному типу → разыменование
```
