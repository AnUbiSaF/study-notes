## Быстрый вход

```text
*p  → значение по адресу p
&x  → адрес переменной x

swap(&x, &y) → функция получает копии адресов,
               но меняет исходные переменные через *a и *b

[begin, end) → end указывает после последнего элемента и не разыменовывается

p - s → число элементов между указателями

a[i] == *(a + i)
```

## Строки и `const`

```c
char *p = "abc";   // литерал, менять нельзя
char a[] = "abc";  // отдельный изменяемый массив
```

```text
const int *p       → const данные
int *const p       → const указатель
const int *const p → const оба
```

`strlen` не считает `\0`; `strcpy` обязан скопировать завершающий `\0`.

## Арифметика и специальные указатели

```text
p + n                    → сдвиг на n * sizeof(*p) байт
p - a                    → разность в элементах
(char *)p - (char *)a    → разность в байтах

sizeof массива ≠ sizeof указателя
```

`void *` хранит адрес без информации о типе. `NULL` можно сравнивать и передавать в `free`, но нельзя разыменовывать или выполнять над ним адресную арифметику.

## Указатели на функции

```c
int (*f)(int, int); // указатель на функцию
int *f(int, int);   // функция, возвращающая int *
```

Для `qsort` компаратор принимает `const void *`, приводит аргументы к реальному типу и разыменовывает их. Полные примеры и пояснения — в [[Разбор практики 02 — Указатели и выравнивание]].
