# ДЗ 01 — Поиск корней уравнения и новые инструменты C

[[Домашние задания по программированию на C|← К списку домашних заданий]]

**Статус:** в работе

> [!summary]- Суть задачи
> Найти все корни $f(x)=x\sin x-1$ на отрезке $[a,b]$ с точностью $10^{-5}$. Границы читаются из `--from` и `--to`, по умолчанию `1` и `2`. При ошибке аргументов — сообщение в `stderr`, пустой `stdout`, код завершения `2`.

> [!example]- 1. Обработка аргументов командной строки
>
> ```c
> int main(int argc, char *argv[])
> ```
>
> - `argc` — количество аргументов, включая имя программы.
> - `argv[0]` — путь/имя программы; `argv[1]`, `argv[2]` и далее — строки аргументов.
> - Цикл обработки начинается с `i = 1`.
> - После чтения значения параметра нужно пропустить его (`i++`), иначе оно будет воспринято как новый параметр.
> - Для необязательных параметров нужны **значения по умолчанию**, а для поиска повторов — отдельные флаги `has_from`, `has_to`. Нельзя использовать `from != 0`: ноль допустим как значение.
>
> ### `strcmp` — сравнение строк (`<string.h>`)
>
> ```c
> strcmp(argv[i], "--from") == 0
> ```
>
> - Возвращает `0`, **если строки равны**.
> - Возвращает отрицательное или положительное число, если отличаются.
> - `if (strcmp(...))` срабатывает на *неравенство*, что часто путают.
>
> ### `strtod` — строка → `double` (`<stdlib.h>`)
>
> ```c
> char *end;
> double value = strtod(argv[i + 1], &end);
>
> if (end == argv[i + 1] || *end != '\0') {
>     fprintf(stderr, "Invalid args\n");
>     return 2;
> }
> ```
>
> - Возвращает считанное число типа `double`.
> - Записывает в `end` указатель на символ, **следующий за прочитанным числом**.
> - `end == argv[i + 1]` — не прочитано ни одного символа числа (в частности, пустая строка).
> - `*end != '\0'` — после числа остался мусор (`"12.5abc"`, `"--to"`).
> - `atoi` здесь не подходит: не поддерживает дробные значения и не сообщает надёжно об ошибке.
>
>> [!warning] Дополнение: крайние значения
>> `strtod` также распознаёт `nan` и `inf`. Если по требованиям нужны только конечные числа, добавляют `isfinite(value)` из `<math.h>`. Для контроля переполнения диапазона применяется `errno`/`ERANGE`. В учебной реализации эти проверки могут не требоваться, но это отдельные случаи.
>
> ### Вывод ошибок и код завершения
>
> ```c
> fprintf(stderr, "Invalid args\n"); // сообщение об ошибке
> return 2;                          // статус некорректных аргументов
> ```
>
> `printf(...)` пишет в `stdout`; `fprintf(stderr, ...)` — в поток ошибок. При некорректных аргументах обычный вывод должен оставаться пустым.
>
> Если `a >= b`, согласно заданию, корней нет:
>
> ```c
> printf("0\n");
> return 0;
> ```
>
> **`printf("0\n")` и `return 0` — разные вещи:** первое печатает количество корней, второе означает успешное завершение программы.
>
>

> [!example]- 2. Алгоритм: поиск корней и бисекция
>
> Функция:
>
> ```c
> #include <math.h>
>
> double f(double x) {
>     return x * sin(x) - 1;
> }
> ```
>
> ### Поиск отрезков-кандидатов
>
> 1. Идти по `[from, to]` небольшими участками `[x, next]`.
> 2. Вычислить `f(x)` и `f(next)`.
> 3. Если знаки разные (`f(x) * f(next) < 0`), на этом участке **есть хотя бы один** корень (непрерывность функции).
> 4. Передать найденный участок функции уточнения корня.
> 5. После каждого участка выполнить `x = next`.
>
> Чтобы не потерять последний неполный участок:
>
> ```c
> while (x < to) {
>     double next = x + 0.1;
>     if (next > to)
>         next = to;
>
>     // проверка смены знака на [x, next]
>
>     x = next;
> }
> ```
>
> ### Метод бисекции (деление пополам)
>
> **Вход:** `[left, right]`, на котором уже установлена смена знака.
>
> 1. Найти `mid = (left + right) / 2`.
> 2. Если `f(mid) == 0`, вернуть `mid`.
> 3. Оставить ту половину, где значения на концах разных знаков.
> 4. Повторять, пока длина отрезка не станет достаточно малой.
> 5. Вернуть `(left + right) / 2` — **середину**, а не `(right - left) / 2` (это лишь половина длины).
>
> Для гарантии ошибки координаты не более $10^{-5}$ при корректном начальном интервале достаточно закончить с длиной интервала не более $2\cdot 10^{-5}$; меньший порог оставляет запас.
>
>> [!warning] Ограничение выбранного способа
>> Сканирование с **фиксированным шагом `0.1` не гарантирует нахождение абсолютно всех корней на произвольных допустимых диапазонах**: на одном участке могут оказаться два корня, а знаки на концах останутся одинаковыми. Также условие `< 0` не ловит корень, попавший точно на границу участка. Это важное ограничение алгоритма, даже если открытые тесты проходят.
>
> Для этой функции $f(-x)=f(x)$, поэтому корни симметричны относительно нуля. Необходимое условие существования корня — $|x|\ge 1$, поскольку $|\sin x|\le 1$.
>
>

> [!example]- 3. `realloc` — динамическое расширение массива (`<stdlib.h>`)
>
> Когда число корней заранее неизвестно:
>
> ```c
> double *roots = NULL;
> size_t count = 0;
> ```
>
> При добавлении нового корня:
>
> ```c
> double *tmp = realloc(roots, (count + 1) * sizeof(*roots));
> if (tmp == NULL) {
>     free(roots);
>     fprintf(stderr, "Memory error\n");
>     return 2;  // выбранный код для ошибки; в условии оговорён только код ошибок аргументов
> }
>
> roots = tmp;
> roots[count] = root;
> count++;
> ```
>
> - `realloc(ptr, new_size)` принимает **размер в байтах**, не количество элементов.
> - `(count + 1) * sizeof(*roots)` — память под следующий элемент.
> - `realloc(NULL, size)` ведёт себя как `malloc(size)`.
> - Используют временный `tmp`: при ошибке старый указатель `roots` остаётся действительным.
> - После использования обязательно `free(roots)`.
> - `realloc` может переместить массив на новый адрес, поэтому дальше используется обновлённый `roots`.
>
>> [!tip] Улучшение на будущее
>> Увеличивать размер на один элемент при каждом добавлении можно, но эффективнее хранить отдельную ёмкость `capacity` и увеличивать её, например, вдвое при заполнении. Для небольшого количества корней простая реализация удобнее.
>
>

> [!example]- 4. Формат вывода
>
> Требование:
>
> ```text
> n
> x_1
> ...
> x_n
> ```
>
> ```c
> printf("%zu\n", count); // если count имеет тип size_t
> for (size_t i = 0; i < count; i++) {
>     printf("%.6f\n", roots[i]);
> }
> free(roots);
> ```
>
> - `%.6f` — **ровно шесть цифр после десятичной точки**.
> - У массива из `count` элементов допустимые индексы `0 ... count - 1`, поэтому `i < count`, а не `i <= count`.
> - При отсутствии корней выводится только `0` и перевод строки.
>
>

> [!example]- 5. Типичные ошибки из практики
>
> | Ошибка | Почему неправильно | Как мыслить |
> |---|---|---|
> | `if (strcmp(a,b))` как проверка равенства | `0` означает равенство | `strcmp(a,b) == 0` |
> | `atoi` для дробных чисел | Теряет дробную часть, плохо выявляет ошибку | Использовать `strtod` |
> | `argv[i++]` при чтении после `--from` | Читает сам параметр, не его значение | Сначала `argv[i+1]`, затем пропустить значение |
> | `from != 0` для проверки повтора | Ноль — допустимая граница | Отдельный флаг `has_from` |
> | `*end != "\0"` | Сравнение `char` со строковым литералом | Символ — `'\0'` |
> | `i + 0.1` | Не изменяет `i` | `i += 0.1` |
> | `int x = from` | Отбрасывает дробную часть | `double x` |
> | `for (...; i <= to; ...)` с постоянным шагом | Может пропустить последний кусок | `next = min(x + step, to)` |
> | `(to - from)/2` как корень | Половина длины вместо координаты | `(from + to)/2` |
> | `realloc(roots, count)` | Размер задан в байтах, при `count=0` запрашивает 0 | `(count+1)*sizeof(*roots)` |
> | `printf("%i", root)` для `double` | Неверный спецификатор | `%.6f` |
> | `i <= count` при печати | Выход за пределы массива | `i < count` |
>

> [!example]- 6. Исходный код
>
> ```c
> #include <stdio.h>
> #include <stdlib.h>
> #include <string.h>
> #include <math.h>
>
> /*
>  * TODO: implement the task. This file is part of the solution code.
>  *
>  * Requirements and examples are in README.md. Add new C sources to this
>  * directory; they are picked up by src/CMakeLists.txt. The solution must be
>  * pure C (C99): only the C standard library and libm may be used.
>  */
> double f(double x) {
>     return x * sin(x) - 1;
> }
>
> double find_root(double from, double to) {
>     while (to - from > 1e-6) {
>         double mid = (from + to) / 2;
>         if (f(from) * f(mid) < 0) {
>             to = mid;
>         }
>         else if (f(mid) == 0) {
>             return mid;
>         }
>         else {
>             from = mid;
>         }
>     }
>     return (from + to) / 2;
> }
>
> int main(int argc, char* argv[]) {
>     double from = 1;
>     double to = 2;
>
>     int has_from = 0;
>     int has_to = 0;
>     char *end;
>
>     for (int i = 1; i < argc; i++) {
>         if (strcmp("--from", argv[i]) == 0)  {
>             if (i + 1 >= argc || has_from != 0) {
>                 fprintf(stderr, "Invalid args \n");
>                 return 2;
>             }
>             from = strtod(argv[i + 1], &end);
>             if (*end != '\0' || end == argv[i+1]) {
>                 fprintf(stderr, "Invalid args\n");
>                 return 2;
>             }
>             has_from = 1;
>             i++;
>         }
>         else if (strcmp("--to", argv[i]) == 0) {
>             if (i + 1 >= argc || has_to != 0) {
>                 fprintf(stderr, "Invalid args\n");
>                 return 2;
>             }
>             to = strtod(argv[i + 1], &end);
>             if (*end != '\0' || end == argv[i+1]) {
>                 fprintf(stderr, "Invalid args\n");
>                 return 2;
>             }
>             has_to = 1;
>             i++;
>         }
>         else {
>             fprintf(stderr, "Invalid args\n");
>             return 2;
>         }
>     }
>     if (from >= to) {
>         printf("0\n");
>         return 0;
>     }
>     double x = from;
>     int count = 0;
>     double *roots = NULL;
>     while (x < to) {
>         double next = x + 0.1;
>
>         if (next > to) {
>             next = to;
>         }
>
>         if (f(x) * f(next) < 0) {
>             double *tmp = realloc(roots, (count+1)*sizeof(double));

>                 fprintf(stderr, "memory error\n");

>                 roots = tmp;
>             }
>             roots[count] = find_root(x, next);
>             count++;
>         }
>
>         x = next;
>     }
>     printf("%d\n", count);
>     for (int i = 0; i < count; i++) {
>         printf("%.6f\n", roots[i]);
>     }
>
>     free(roots);
>     return 0;

> ```
