> [!summary] Вспомнить за минуту
> Для доказательства равенства множеств работаем с произвольным элементом и раскрываем принадлежность по определениям.
> В декартовом произведении пара не принадлежит произведению, если хотя бы одна координата не подходит.

## Ключевые определения

- $f(A)=\{y\in Y\mid \exists x\in A: f(x)=y\}$ — образ.
- $f^{-1}(B)=\{x\in X\mid f(x)\in B\}$ — прообраз; обратная функция для него не нужна.
- Инъекция: $f(x_1)=f(x_2)\Rightarrow x_1=x_2$.
- Сюръекция: $\forall y\in Y\ \exists x\in X: f(x)=y$.
- Биекция — оба свойства одновременно.

## Алгоритмы

1. Для $L\subseteq R$: взять произвольный $x\in L$ и вывести $x\in R$.
2. Для $L=R$: доказать оба включения или провести цепочку $\Longleftrightarrow$.
3. Для инъективности начать с $f(x_1)=f(x_2)$; контрпримером служат два разных входа с одним выходом.
4. Для сюръективности взять произвольный $y$ и решить $f(x)=y$; контрпример — выход без прообраза.

## Что проверить

- В системе условий работает «и», в совокупности — «или».
- $x\notin B$ не означает $f(x)\notin f(B)$: другой элемент может иметь тот же образ.
- Для разности образов равенство требует инъективности; для прообразов соответствующие равенства выполняются всегда.
