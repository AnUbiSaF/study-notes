# Норма

Норма — обобщённая длина вектора:

$$
\|\cdot\|:X\to\mathbb R.
$$

Для любых $x,y\in X$ и $\alpha\in K$:

1. **Неотрицательность и определённость:**
   $$\|x\|\ge0,\qquad \|x\|=0\iff x=0.$$
2. **Абсолютная однородность:**
   $$\|\alpha x\|=|\alpha|\|x\|.$$
3. **Неравенство треугольника:**
   $$\|x+y\|\le\|x\|+\|y\|.$$

Для $\infty$-нормы модуль $|\alpha|$ неотрицателен: умножение всех координат на одно такое число сохраняет их порядок, поэтому этот множитель можно вынести из максимума.

Линейное пространство с выбранной нормой называется нормированным пространством.

## Примеры

На $\mathbb R^m$:

$$
\|x\|_\infty=\max_i|x_i|.
$$

Например,

$$
\|(-2,-3,-1)\|_\infty=\max\{2,3,1\}=3.
$$

> [!example]- Почему это норма
> Для $\|x\|_\infty=\max_i|x_i|$:
>
> 1. $\|x\|_\infty\ge0$, а равенство нулю возможно только при $x_i=0$ для всех $i$, то есть при $x=0$.
> 2. $\|\alpha x\|_\infty=\max_i|\alpha x_i|=|\alpha|\max_i|x_i|=|\alpha|\|x\|_\infty$. Множитель $|\alpha|\ge0$ одинаков для всех координат, поэтому выносится из максимума.
> 3. $\|x+y\|_\infty=\max_i|x_i+y_i|\le\max_i(|x_i|+|y_i|)\le\max_i|x_i|+\max_i|y_i|$. Первое неравенство — треугольник для каждой координаты; второе — каждая сумма не больше суммы максимумов.
>
> Для $\ell^\infty$ доказательство то же: вместо $\max$ берётся $\sup$.

В $\ell^\infty$, пространстве ограниченных последовательностей:

$$
\|x\|_\infty=\sup_n|x_n|.
$$

Например,

$$
x=\left(-\frac12,-\frac23,-\frac34,\ldots\right),
\qquad
\|x\|_\infty=1.
$$

> [!example]- Почему это норма на $\ell^\infty$
> Для $x,y\in\ell^\infty$:
>
> 1. $\|x\|_\infty=\sup_n|x_n|\ge0$; равенство нулю возможно только при $x_n=0$ для всех $n$, то есть при $x=0$.
> 2. $\|\alpha x\|_\infty=\sup_n|\alpha x_n|=|\alpha|\sup_n|x_n|=|\alpha|\|x\|_\infty$. Множитель $|\alpha|\ge0$ одинаков для всех членов, поэтому выносится из супремума.
> 3. $\|x+y\|_\infty=\sup_n|x_n+y_n|\le\sup_n(|x_n|+|y_n|)\le\sup_n|x_n|+\sup_n|y_n|$. Первое неравенство — неравенство треугольника для каждого номера $n$; второе — каждая сумма не больше суммы супремумов.
