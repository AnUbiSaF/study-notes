# Теоремы — кратко

[[00 — Карта коллоквиума|← К карте]] · [[03 — Теоремы — полно|Полные карточки]]

> [!info]
> Структура, порядок и названия карточек полностью совпадают с полной версией. Неподготовленные карточки отмечены `⏳`; готовые краткие версии составляются только по полной карточке и лекционному источнику.

## Последовательности и пределы

> [!note]- Единственность предела и ограниченность сходящейся последовательности ✓
>
> ### 1. Единственность предела
>
>> [!abstract] Дано
>> Последовательность $(x_n)$ в метрическом пространстве $(X,\rho)$ имеет два предела:
>> $$
>> x_n\to a,
>> \qquad
>> x_n\to b.
>> $$
>
>> [!success] Тогда
>> Оба предела совпадают, то есть предел единственен:
>> $$
>> a=b.
>> $$
>
>> [!tip] Маршрут доказательства
>> Предполагаем $a\ne b$ → берём $\varepsilon=\rho(a,b)/3$ → объединяем два хвоста → неравенство треугольника даёт противоречие.
>
>> [!example] Короткое доказательство
>> Предположим, что $a\ne b$, и положим
>> $$
>> d=\rho(a,b)>0,
>> \qquad
>> \varepsilon=\frac d3.
>> $$
>> Из $x_n\to a$ и $x_n\to b$ существуют номера $N_a,N_b$, после которых
>> $$
>> \rho(x_n,a)<\varepsilon,
>> \qquad
>> \rho(x_n,b)<\varepsilon.
>> $$
>> При $n>\max\{N_a,N_b\}$ по симметричности метрики и неравенству треугольника
>> $$
>> \rho(a,b)
>> \le \rho(a,x_n)+\rho(x_n,b)
>> <2\varepsilon
>> =\frac{2d}{3}
>> <d
>> =\rho(a,b),
>> $$
>> что невозможно. Следовательно, $a=b$. $\square$
>
> ### 2. Ограниченность сходящейся последовательности
>
>> [!abstract] Дано
>> Последовательность $(x_n)$ в метрическом пространстве $(X,\rho)$ сходится к точке $a\in X$:
>> $$
>> x_n\to a.
>> $$
>
>> [!success] Тогда
>> Последовательность $(x_n)$ ограничена: существует $R>0$, для которого
>> $$
>> \rho(x_n,a)<R
>> \qquad\text{для всех }n\in\mathbb N.
>> $$
>
>> [!tip] Маршрут доказательства
>> Берём $\varepsilon=1$ → хвост попадает в $B(a,1)$ → ограничиваем конечное начало максимумом $M$ → выбираем общий радиус $R$.
>
>> [!example] Короткое доказательство
>> Берём в определении предела
>> $$
>> \varepsilon=1.
>> $$
>> Тогда существует $N$, после которого
>> $$
>> n>N\Rightarrow \rho(x_n,a)<1.
>> $$
>> Для конечного начала последовательности положим
>> $$
>> M=\max\{\rho(x_1,a),\ldots,\rho(x_N,a)\},
>> \qquad
>> R=\max\{1,M\}+1.
>> $$
>> Если $n>N$, то $\rho(x_n,a)<1<R$; если $1\le n\le N$, то $\rho(x_n,a)\le M<R$. Поэтому
>> $$
>> \rho(x_n,a)<R
>> \qquad\text{для всех }n\in\mathbb N,
>> $$
>> то есть последовательность ограничена. $\square$

> [!warning]- Предельный переход в неравенствах для последовательностей и для функций ✓ · ⚠️ Нет формулировки для функций
>
>> [!warning] Покрытие карточки
>> В лекциях найдена формулировка для последовательностей. Отдельная формулировка для функций пока не найдена.
>
>> [!abstract] Дано
>> Вещественные последовательности $(x_n)$ и $(y_n)$ удовлетворяют неравенству на некотором хвосте:
>> $$
>> \exists N_0\in\mathbb N\ \forall n>N_0:
>> \quad x_n\le y_n,
>> $$
>> и имеют конечные пределы
>> $$
>> x_n\to a,
>> \qquad
>> y_n\to b,
>> \qquad
>> a,b\in\mathbb R.
>> $$
>
>> [!success] Тогда
>> Неравенство сохраняется при переходе к пределу в нестрогой форме:
>> $$
>> a\le b.
>> $$
>
>> [!tip] Маршрут доказательства
>> Предполагаем $a>b$ → выбираем середину через $\varepsilon=(a-b)/2$ → объединяем номера хвоста → получаем $y_n<x_n$ вопреки $x_n\le y_n$.
>
>> [!example] Короткое доказательство
>> Предположим противное: $a>b$. Чтобы развести окрестности $b$ и $a$, берём
>> $$
>> \varepsilon=\frac{a-b}{2}>0.
>> $$
>> По определениям пределов существуют $N_1,N_2$, такие что
>> $$
>> n>N_1\Rightarrow a-\varepsilon<x_n,
>> \qquad
>> n>N_2\Rightarrow y_n<b+\varepsilon.
>> $$
>> Выбираем
>> $$
>> N=\max\{N_0,N_1,N_2\}.
>> $$
>> Тогда при любом $n>N$
>> $$
>> y_n
>> <b+\varepsilon
>> =\frac{a+b}{2}
>> =a-\varepsilon
>> <x_n,
>> $$
>> что противоречит условию $x_n\le y_n$. Следовательно,
>> $$
>> a\le b.
>> $$
>> $\square$
>
>> [!tip] Следствие: постоянная верхняя граница
>> **Дано:**
>> $$
>> x_n\to a,
>> \qquad
>> \exists N_0\in\mathbb N\ \forall n>N_0:
>> \quad x_n\le b.
>> $$
>> **Тогда:** предел также не превосходит эту границу:
>> $$
>> a\le b.
>> $$
>> Рассматриваем постоянную последовательность
>> $$
>> y_n\equiv b,
>> \qquad
>> y_n\to b.
>> $$
>> Тогда $x_n\le y_n$ на хвосте, поэтому по основной теореме
>> $$
>> \lim x_n\le\lim y_n,
>> $$
>> то есть $a\le b$.
>
>> [!note] Строгость может потеряться
>> Например,
>> $$
>> -\frac1n<\frac1n,
>> \qquad
>> -\frac1n\to0,
>> \qquad
>> \frac1n\to0.
>> $$
>> Поэтому из $x_n<y_n$ на хвосте следует только $a\le b$, но не обязательно $a<b$.

> [!danger]- 🔴 Теорема о двух городовых ✓
>
>> [!abstract] Дано
>> Вещественные последовательности $(x_n)$, $(y_n)$, $(z_n)$, число $a\in\mathbb R$ и номер $N_0$, причём
>> $$
>> n>N_0\Rightarrow x_n\le y_n\le z_n,
>> \qquad x_n\to a,
>> \qquad z_n\to a.
>> $$
>
>> [!success] Тогда
>> $$
>> y_n\to a.
>> $$
>
>> [!tip] Маршрут доказательства
>> Берём $\varepsilon$ → выбираем номера для двух крайних последовательностей и зажатия → берём их максимум → зажимаем $y_n$ между $a-\varepsilon$ и $a+\varepsilon$.
>
>> [!example] Короткое доказательство
>> Берём произвольное $\varepsilon>0$. По определениям пределов существуют номера $N_1$ и $N_2$, для которых
>> $$
>> n>N_1\Rightarrow a-\varepsilon<x_n,
>> \qquad
>> n>N_2\Rightarrow z_n<a+\varepsilon.
>> $$
>> Выбираем
>> $$
>> N=\max\{N_0,N_1,N_2\}.
>> $$
>> Тогда при любом $n>N$
>> $$
>> a-\varepsilon<x_n\le y_n\le z_n<a+\varepsilon,
>> $$
>> поэтому
>> $$
>> |y_n-a|<\varepsilon.
>> $$
>> Следовательно, по определению предела $y_n\to a$. $\square$
>
>> [!tip] Следствие
>> Если
>> $$
>> |y_n|\le z_n,
>> \qquad z_n\to0,
>> $$
>> то
>> $$
>> y_n\to0.
>> $$
>> Действительно,
>> $$
>> -z_n\le y_n\le z_n,
>> $$
>> причём $-z_n\to0$ и $z_n\to0$. По теореме о двух городовых $y_n\to0$. $\square$

> [!note]- Лемма о свойствах бесконечно малых последовательностей ✓
>
>> [!abstract] Определение
>> Последовательность $(x_n)$ называется **бесконечно малой**, если
>> $$
>> x_n\to0.
>> $$
>
> ### 1. Сумма бесконечно малых последовательностей
>
>> [!abstract] Дано
>> $$
>> x_n\to0,
>> \qquad
>> y_n\to0.
>> $$
>
>> [!success] Тогда
>> Сумма также является бесконечно малой:
>> $$
>> x_n+y_n\to0.
>> $$
>
>> [!tip] Маршрут доказательства
>> Делим $\varepsilon$ пополам → берём максимум двух номеров → применяем неравенство треугольника.
>
>> [!example] Короткое доказательство
>> Заданную точность делят между двумя слагаемыми:
>> $$
>> |x_n|<\frac{\varepsilon}{2},
>> \qquad
>> |y_n|<\frac{\varepsilon}{2}.
>> $$
>> Тогда
>> $$
>> |x_n+y_n|
>> \le |x_n|+|y_n|
>> <\varepsilon.
>> $$
>
> ### 2. Произведение бесконечно малой и ограниченной последовательностей
>
>> [!abstract] Дано
>> Последовательность $(x_n)$ является бесконечно малой, а $(y_n)$ ограничена:
>> $$
>> x_n\to0,
>> \qquad
>> \exists R>0\ \forall n\in\mathbb N:
>> \quad |y_n|<R.
>> $$
>
>> [!success] Тогда
>> Произведение является бесконечно малой последовательностью:
>> $$
>> x_ny_n\to0.
>> $$
>
>> [!tip] Маршрут доказательства
>> Берём границу $R$ для $y_n$ → выбираем для $x_n$ точность $\varepsilon/R$ → оцениваем произведение через $|x_n|R$.
>
>> [!example] Короткое доказательство
>> Для заданного $\varepsilon>0$ выбираем точность для $(x_n)$:
>> $$
>> \gamma=\frac{\varepsilon}{R}>0.
>> $$
>> Из $x_n\to0$ для достаточно больших $n$ следует $|x_n|<\gamma$. Поэтому
>> $$
>> |x_ny_n|
>> =|x_n|\,|y_n|
>> <\frac{\varepsilon}{R}R
>> =\varepsilon.
>> $$
>> Следовательно, $x_ny_n\to0$. Последовательности $(y_n)$ достаточно быть ограниченной; стремиться к нулю она не обязана.

## Множества и отображения

> [!note]- Законы де Моргана ✓
>
>> [!abstract] Дано
>> Множество $Y$ и семейство множеств $(X_\alpha)_{\alpha\in I}$.
>>
>> Объединение соответствует «существует индекс», а пересечение — «для всех индексов».
>
>> [!success] Тогда
>>
>> $$
>> Y\setminus\bigcup_{\alpha\in I}X_\alpha
>> =
>> \bigcap_{\alpha\in I}(Y\setminus X_\alpha),
>> \qquad
>> Y\setminus\bigcap_{\alpha\in I}X_\alpha
>> =
>> \bigcup_{\alpha\in I}(Y\setminus X_\alpha),
>> $$
>>
>> $$
>> Y\cap\bigcup_{\alpha\in I}X_\alpha
>> =
>> \bigcup_{\alpha\in I}(Y\cap X_\alpha),
>> \qquad
>> Y\cup\bigcap_{\alpha\in I}X_\alpha
>> =
>> \bigcap_{\alpha\in I}(Y\cup X_\alpha).
>> $$
>
>> [!tip] Маршрут доказательства
>> Берём произвольный $x$ → заменяем объединение на $\exists$, пересечение на $\forall$ → переставляем логические связки → получаем принадлежность правой части.
>
>> [!note] Как читать переходы
>> - Вычесть из $Y$ объединение $\Longleftrightarrow$ пересечь результаты вычитания из $Y$ каждого $X_\alpha$.
>> - Вычесть из $Y$ пересечение $\Longleftrightarrow$ объединить результаты вычитания из $Y$ каждого $X_\alpha$.
>> - Пересечь $Y$ с объединением $\Longleftrightarrow$ объединить пересечения $Y$ с каждым $X_\alpha$.
>> - Объединить $Y$ с пересечением $\Longleftrightarrow$ пересечь объединения $Y$ с каждым $X_\alpha$.
>
>> [!example] Короткое доказательство
>> Берём произвольный $x$ и переводим принадлежность множеству в кванторы:
>>
>> $$
>> x\notin\bigcup_{\alpha\in I}X_\alpha
>> \iff
>> \forall\alpha\in I:\ x\notin X_\alpha,
>> \qquad
>> x\notin\bigcap_{\alpha\in I}X_\alpha
>> \iff
>> \exists\alpha\in I:\ x\notin X_\alpha.
>> $$
>>
>> Отсюда получаются два закона де Моргана. Для распределительных законов:
>>
>> $$
>> \bigl(x\in Y\ \text{и}\ \exists\alpha\in I:\ x\in X_\alpha\bigr)
>> \iff
>> \exists\alpha\in I:\ x\in Y\cap X_\alpha,
>> $$
>>
>> $$
>> \bigl(x\in Y\ \text{или}\ \forall\alpha\in I:\ x\in X_\alpha\bigr)
>> \iff
>> \forall\alpha\in I:\ x\in Y\cup X_\alpha.
>> $$
>>
>> Поэтому равны множества в каждой из четырёх формул.

## Порядок и полнота

> [!note]- Аксиома Архимеда. Плотность множества рациональных чисел в $\mathbb R$ ✓
>
>> [!abstract] Дано
>> Для аксиомы Архимеда: $x,y>0$.
>>
>> Для плотности рациональных чисел: $a,b\in\mathbb R$ и $a<b$.
>
>> [!success] Тогда
>>
>> $$
>> \forall x,y>0\quad\exists n\in\mathbb N:\ nx>y.
>> $$
>>
>> Эквивалентно:
>>
>> $$
>> \forall t\in\mathbb R\quad\exists n\in\mathbb N:\ n>t.
>> $$
>>
>> Кроме того,
>>
>> $$
>> \exists q\in\mathbb Q:\ a<q<b.
>> $$
>
>> [!tip] Маршрут доказательства
>> Берём $t=y/x$ для эквивалентной формы Архимеда → выбираем сетку $k/m$ с $1/m<b-a$ → берём первую точку правее $a$ → проверяем $a<q<b$.
>
>> [!example] Короткое доказательство
>> Аксиома Архимеда не доказывается. Для перехода от формы $n>t$ к исходной берём
>>
>> $$
>> t=\frac yx;
>> \qquad
>> n>\frac yx
>> \Longrightarrow
>> nx>y.
>> $$
>>
>> Для плотности выбираем сетку $k/m$ с шагом $1/m$. Берём
>>
>> $$
>> m>\frac1{b-a},
>> \qquad
>> \frac1m<b-a,
>> $$
>>
>> и первую точку этой сетки правее $a$:
>>
>> $$
>> q=\frac{\lfloor ma\rfloor+1}{m}.
>> $$
>>
>> Из
>>
>> $$
>> ma<\lfloor ma\rfloor+1
>> $$
>>
>> следует $a<q$. Из
>>
>> $$
>> \lfloor ma\rfloor\le ma
>> $$
>>
>> получаем
>>
>> $$
>> q\le a+\frac1m<b.
>> $$
>>
>> Следовательно, $a<q<b$, причём $q\in\mathbb Q$.

> [!note]- Неравенство Бернулли ✓
>
>> [!abstract] Дано
>>
>> $$
>> n\in\mathbb N,
>> \qquad n\ge2,
>> \qquad x>-1.
>> $$
>
>> [!success] Тогда
>>
>> $$
>> (1+x)^n\ge1+nx.
>> $$
>>
>> При $x\ne0$ неравенство строгое.
>
>> [!tip] Маршрут доказательства
>> База $n=2$ → индукционное предположение $P(n)$ → умножение на $1+x>0$ → раскрытие скобок → $nx^2\ge0$.
>
>> [!example] Короткое доказательство
>> Обозначим
>>
>> $$
>> P(n):\quad (1+x)^n\ge1+nx.
>> $$
>>
>> База:
>>
>> $$
>> (1+x)^2=1+2x+x^2\ge1+2x.
>> $$
>>
>> Пусть верно $P(n)$. Так как $x>-1$, то $1+x>0$, поэтому
>>
>> $$
>> (1+x)^{n+1}
>> \ge
>> (1+nx)(1+x)
>> =
>> 1+(n+1)x+nx^2
>> \ge
>> 1+(n+1)x.
>> $$
>>
>> Значит, верно $P(n+1)$; по индукции утверждение доказано. При $x\ne0$ имеем $nx^2>0$, поэтому неравенство строгое.

> [!danger]- 🔴 Теорема Кантора о стягивающихся отрезках ✓
>
>> [!abstract] Дано
>> Последовательность непустых замкнутых отрезков:
>>
>> $$
>> [a_1,b_1]\supset[a_2,b_2]\supset\ldots,
>> \qquad
>> b_n-a_n\to0.
>> $$
>
>> [!success] Тогда
>> Существует ровно одна точка
>>
>> $$
>> c\in\bigcap_{n=1}^{\infty}[a_n,b_n],
>> $$
>>
>> причём
>>
>> $$
>> a_n\to c,
>> \qquad
>> b_n\to c.
>> $$
>
>> [!tip] Маршрут доказательства
>> Аксиома Кантора → выбираем общую точку $c$ → зажатие концов длиной $b_n-a_n$ → $a_n,b_n\to c$ → единственность предела.
>
>> [!example] Короткое доказательство
>> По аксиоме Кантора
>>
>> $$
>> \bigcap_{n=1}^{\infty}[a_n,b_n]\ne\varnothing.
>> $$
>>
>> Выбираем $c$ из этого пересечения. Тогда для каждого $n$
>>
>> $$
>> a_n\le c\le b_n.
>> $$
>>
>> Поэтому
>>
>> $$
>> 0\le c-a_n\le b_n-a_n\to0
>> \quad\Longrightarrow\quad
>> a_n-c=-(c-a_n)\to0
>> \quad\Longrightarrow\quad
>> a_n\to c,
>> $$
>>
>> $$
>> 0\le b_n-c\le b_n-a_n\to0
>> \quad\Longrightarrow\quad
>> b_n\to c.
>> $$
>>
>> Если $d$ тоже лежит во всех отрезках, то тем же рассуждением $a_n\to d$. Но $a_n\to c$, поэтому по единственности предела $d=c$.

> [!note]- Десятичная запись числа ✓
>
>> [!abstract] Дано
>> $x\in[0,1]$.
>
>> [!tip] Маршрут
>> Делим текущий отрезок на $10$ частей → берём часть с $x$ → её номер записываем следующей цифрой → повторяем.
>
>> [!example] Схема
>> Например,
>>
>> $$
>> x\in[0{,}2,0{,}3]\ \to\ 2,\qquad
>> x\in[0{,}28,0{,}29]\ \to\ 8,\qquad
>> x\in[0{,}283,0{,}284]\ \to\ 3.
>> $$
>>
>> Так получаем $x=0{,}283\ldots$.
>
>> [!note] Граничный случай
>> На общей границе двух частей есть два выбора: вправо — дальше нули, влево — дальше девятки:
>>
>> $$
>> 0{,}28=0{,}28000\ldots=0{,}27999\ldots.
>> $$

> [!note]- Теорема о существовании супремума ✓
>
>> [!abstract] Дано
>> $E\subseteq\mathbb R$, $E\ne\varnothing$,
>> и $E$ ограничено сверху.
>
>> [!success] Тогда
>> Существует $M\in\mathbb R$, для которого
>>
>> $$
>> M=\sup E.
>> $$
>
>> [!tip] Маршрут доказательства
>>
>> 1. $a_n$ ещё не потолок множества $E$;
>> $b_n$ уже потолок.
>>
>> 2. Делим $[a_n,b_n]$ пополам и сохраняем
>> половину с теми же ролями.
>>
>> 3. Отрезки сжимаются к точке $M$.
>>
>> 4. $b_n\to M$ делает $M$ верхней границей,
>> а $a_n\to M$ позволяет подойти к $M$ снизу.
>
>> [!example] Короткое доказательство
>> **Старт.** Берём $a_1\in E$.
>> Если $a_1$ — верхняя граница, то
>>
>> $$
>> a_1=\max E=\sup E.
>> $$
>>
>> Иначе берём верхнюю границу $b_1$.
>> Если $b_1\in E$, то
>>
>> $$
>> b_1=\max E=\sup E.
>> $$
>>
>> В оставшемся случае
>>
>> $$
>> a_1<b_1,
>> $$
>>
>> $$
>> a_1\text{ не верхняя граница},
>> \qquad
>> b_1\text{ верхняя граница}.
>> $$
>>
>> Начинаем с отрезка $[a_1,b_1]$.
>>
>> **Шаг.** Пусть уже есть $[a_n,b_n]$ с теми же ролями.
>>
>> Для середины
>>
>> $$
>> d_n=\frac{a_n+b_n}{2}
>> $$
>>
>> сохраняем левую половину, если $d_n$ — верхняя граница,
>> и правую — иначе. Тогда
>>
>> $$
>> a_n\text{ не верхняя граница},
>> \qquad
>> b_n\text{ верхняя граница},
>> $$
>>
>> $$
>> [a_{n+1},b_{n+1}]\subseteq[a_n,b_n],
>> $$
>>
>> $$
>> b_n-a_n=
>> \frac{b_1-a_1}{2^{n-1}}\to0.
>> $$
>>
>> **Предел отрезков.** По Кантору отрезки имеют единственную
>> общую точку $M$, причём
>>
>> $$
>> a_n\to M,
>> \qquad
>> b_n\to M.
>> $$
>>
>> Зафиксируем произвольный $x\in E$. Тогда
>>
>> $$
>> \forall n\in\mathbb N:\quad x\le b_n.
>> $$
>>
>> Из $b_n\to M$ получаем $x\le M$.
>> Поскольку $x$ произвольный,
>>
>> $$
>> \forall x\in E:\quad x\le M.
>> $$
>>
>> Значит, $M$ — верхняя граница.
>>
>> **Минимальность.** Берём произвольное $\varepsilon>0$.
>> Из $a_n\to M$ найдётся $N$, такое что для каждого $n\ge N$:
>>
>> $$
>> M-\varepsilon<a_n.
>> $$
>>
>> Берём любой $n\ge N$. Так как $a_n$ не верхняя граница,
>> найдётся $x\in E$:
>>
>> $$
>> M-\varepsilon<a_n<x\le M.
>> $$
>>
>> Это критерий супремума, значит $M=\sup E$. $\square$

> [!question]- ❓ Лемма о свойствах супремума
>
>> [!abstract] Дано
>> $D\subset E$, $\lambda>0$,
>> $\lambda E=\{\lambda x:x\in E\}$ и $-E=\{-x:x\in E\}$.
>
>> [!success] Тогда
>>
>> $$
>> \sup D\le\sup E,
>> $$
>>
>> $$
>> \sup(\lambda E)=\lambda\sup E,
>> $$
>>
>> $$
>> \sup(-E)=-\inf E.
>> $$
>
>> [!tip] Маршрут доказательства
>>
>> 1. Верхняя граница $E$ ограничивает и $D$.
>>
>> 2. $\lambda>0$ сохраняет порядок и верхние границы.
>>
>> 3. Знак «минус» меняет верхнюю границу
>> на нижнюю.
>
>> [!example] Короткое доказательство
>> Из $D\subset E$ следует:
>>
>> $$
>> x\in D\Rightarrow x\le\sup E.
>> $$
>>
>> Поэтому $\sup E$ — верхняя граница $D$, откуда
>> $\sup D\le\sup E$.
>>
>> При $\lambda>0$:
>>
>> $$
>> x\le a
>> \iff
>> \lambda x\le\lambda a.
>> $$
>>
>> Поэтому верхние границы $E$ и $\lambda E$
>> соответствуют друг другу, а значит
>> $\sup(\lambda E)=\lambda\sup E$.
>>
>> Наконец,
>>
>> $$
>> -x\le a
>> \iff
>> x\ge-a.
>> $$
>>
>> Поэтому верхние границы $-E$ соответствуют нижним границам
>> $E$, то есть $\sup(-E)=-\inf E$. $\square$

> [!note]- Теорема о пределе монотонной последовательности ✓
>
>> [!abstract] Дано
>>
>> - $(x_n)$ возрастает и ограничена сверху; или
>> - $(x_n)$ убывает и ограничена снизу.
>
>> [!success] Тогда
>> Если $(x_n)$ возрастает, то
>>
>> $$
>> \lim_{n\to\infty}x_n=\sup_n x_n.
>> $$
>>
>> Если $(x_n)$ убывает, то
>>
>> $$
>> \lim_{n\to\infty}x_n=\inf_n x_n.
>> $$
>
>> [!tip] Маршрут доказательства
>>
>> 1. $b$ — супремум, верхняя граница; хотим доказать $x_n\to b$.
>>
>> 2. $\varepsilon>0$ — любая нужная точность.
>>
>> 3. По супремуму находим $n_0$:
>> $x_{n_0}>b-\varepsilon$.
>>
>> 4. $n_0$ начинает хвост; монотонность и граница $b$
>> удерживают его на расстоянии меньше $\varepsilon$ от $b$.
>>
>> 5. Для убывания так же, но $a$ — инфимум,
>> нижняя граница вместо $b$.
>
>> [!example] Короткое доказательство
>> **Возрастает.** Пусть
>>
>> $$
>> b=\sup\{x_1,x_2,\ldots\}.
>> $$
>>
>> Для любого $\varepsilon>0$ найдётся $n_0$, такое что
>>
>> $$
>> b-\varepsilon<x_{n_0}.
>> $$
>>
>> Тогда для каждого $n\ge n_0$
>>
>> $$
>> b-\varepsilon<x_{n_0}\le x_n\le b.
>> $$
>>
>> Поэтому
>>
>> $$
>> x_n\le b,
>> \qquad
>> |x_n-b|=b-x_n<\varepsilon.
>> $$
>>
>> То есть $x_n\to b$.
>>
>> **Убывает.** Если $a=\inf x_n$, то для $n\ge n_0$
>>
>> $$
>> a\le x_n\le x_{n_0}<a+\varepsilon.
>> $$
>>
>> Значит, $|x_n-a|<\varepsilon$ и $x_n\to a$. $\square$

> [!note]- Определение числа e, соответствующий замечательный предел ✓
>
>> [!abstract] Дано
>> Для всех $n\in\mathbb N$:
>>
>> $$
>> x_n=\left(1+\frac1n\right)^n,
>> \qquad
>> y_n=\left(1+\frac1n\right)^{n+1}.
>> $$
>
>> [!success] Тогда
>> Существует число $e$, для которого
>>
>> $$
>> \lim_{n\to\infty}\left(1+\frac1n\right)^n
>> =e=
>> \lim_{n\to\infty}\left(1+\frac1n\right)^{n+1}.
>> $$
>
>> [!tip] Маршрут доказательства
>> Отношение соседних $y_n$ → Бернулли → $(y_n)$ убывает
>> → $y_n>0$ → существует предел $L$
>> → выражаем $x_n$ через $y_n$ → оба предела равны $L$
>> → по определению $L=e$.
>
>> [!example] Короткое доказательство
>> **1. Убывание.** Для каждого $n\ge2$:
>>
>> $$
>> \frac{y_{n-1}}{y_n}
>> =
>> \frac{n-1}{n}
>> \left(1+\frac1{n^2-1}\right)^{n+1}.
>> $$
>>
>> По неравенству Бернулли
>>
>> $$
>> \left(1+\frac1{n^2-1}\right)^{n+1}
>> \ge
>> 1+\frac1{n-1}.
>> $$
>>
>> Поэтому
>>
>> $$
>> \frac{y_{n-1}}{y_n}
>> \ge
>> \frac{n-1}{n}
>> \left(1+\frac1{n-1}\right)
>> =1.
>> $$
>>
>> Так как $y_n>0$, для каждого $n\ge2$:
>>
>> $$
>> y_{n-1}\ge y_n.
>> $$
>>
>> Следовательно, $(y_n)$ убывает.
>>
>> **2. Предел $y_n$.** Для всех $n\in\mathbb N$:
>>
>> $$
>> y_n>0.
>> $$
>>
>> Поэтому $(y_n)$ ограничена снизу нулём.
>> По теореме о монотонной последовательности существует
>>
>> $$
>> \exists L\in\mathbb R:
>> \quad y_n\to L.
>> $$
>>
>> **3. Предел $x_n$.**
>>
>> $$
>> x_n=
>> \frac{y_n}{1+\frac1n},
>> \qquad
>> 1+\frac1n\to1.
>> $$
>>
>> Поэтому по теореме о пределе частного
>>
>> $$
>> x_n\to\frac L1=L.
>> $$
>>
>> Общий предел определяют как число $e$:
>>
>> $$
>> e=L.
>> $$
>>
>> $\square$

> [!note]- Лемма о сходимости к нулю "быстро убывающей" последовательности ✓
>
>> [!abstract] Дано
>> Последовательность положительных чисел $(x_n)$ и предел отношения соседних членов:
>>
>> $$
>> x_n>0,
>> \qquad
>> \lim_{n\to\infty}\frac{x_{n+1}}{x_n}=q,
>> \qquad
>> q<1.
>> $$
>
>> [!success] Тогда
>>
>> $$
>> x_n\to0.
>> $$
>
>> [!example] Короткое доказательство
>> Выбираем число $m$ так, что $q<m<1$, и берём
>>
>> $$
>> \varepsilon=m-q>0.
>> $$
>>
>> Тогда начиная с некоторого $N$:
>>
>> $$
>> \left|\frac{x_{n+1}}{x_n}-q\right|<m-q.
>> $$
>>
>> Следовательно,
>>
>> $$
>> \frac{x_{n+1}}{x_n}<m.
>> $$
>>
>> Так как $x_n>0$,
>>
>> $$
>> x_{n+1}<mx_n.
>> $$
>>
>> Фиксируем $k\ge N$. Последовательно применяем оценку для $k,k+1,\ldots$:
>>
>> $$
>> x_{k+p}<m^p x_k.
>> $$
>>
>> Для любого $n\ge k$ полагаем $p=n-k$. Тогда
>>
>> $$
>> 0<x_n<m^{n-k}x_k.
>> $$
>>
>> Так как $0<m<1$, а $x_k$ фиксировано,
>>
>> $$
>> m^{n-k}x_k\to0.
>> $$
>>
>> По теореме о двух городовых $x_n\to0$. $\square$
>
>> [!tip] Следствие
>> Для $a>0$
>>
>> $$
>> \frac{a^n}{n!}\to0.
>> $$
>>
>> При $x_n=\frac{a^n}{n!}$
>>
>> $$
>> \frac{x_{n+1}}{x_n}=\frac{a}{n+1}\to0<1,
>> $$
>>
>> поэтому применима лемма.

## Скалярное произведение и координаты

> [!note]- Неравенство КБШ для конечных числовых наборов ✓
>
>> [!abstract] Дано
>> Два вещественных числовых набора одинаковой длины:
>>
>> $$
>> a=(a_1,\ldots,a_n),
>> \qquad
>> b=(b_1,\ldots,b_n).
>> $$
>
>> [!success] Тогда
>>
>> $$
>> \left(\sum_{i=1}^{n}a_i b_i\right)^2
>> \le
>> \left(\sum_{i=1}^{n}a_i^2\right)
>> \left(\sum_{i=1}^{n}b_i^2\right).
>> $$
>>
>> Эквивалентно:
>>
>> $$
>> \left|\sum_{i=1}^{n}a_i b_i\right|
>> \le
>> \sqrt{\sum_{i=1}^{n}a_i^2}
>> \sqrt{\sum_{i=1}^{n}b_i^2}.
>> $$
>>
>> Равенство достигается тогда и только тогда, когда наборы линейно зависимы.
>
>> [!tip] Маршрут доказательства
>> Сумма квадратов $S$ → тождество Лагранжа → $S\ge0$ → неравенство КБШ → $S=0$ даёт линейную зависимость.
>
>> [!example] Короткое доказательство
>> Записываем сумму квадратов
>>
>> $$
>> S=\sum_{i,k=1}^{n}(a_i b_k-a_k b_i)^2\ge0.
>> $$
>>
>> Раскрываем квадрат и переставляем множители в среднем слагаемом:
>>
>> $$
>> S=
>> \sum_{i,k=1}^{n}a_i^2b_k^2
>> -2\sum_{i,k=1}^{n}a_i b_i a_k b_k
>> +\sum_{i,k=1}^{n}a_k^2b_i^2.
>> $$
>>
>> Сворачиваем двойные суммы:
>>
>> $$
>> \sum_{i,k=1}^{n}a_i^2b_k^2
>> =
>> \sum_{i,k=1}^{n}a_k^2b_i^2
>> =
>> \left(\sum_{i=1}^{n}a_i^2\right)
>> \left(\sum_{i=1}^{n}b_i^2\right),
>> $$
>>
>> $$
>> \sum_{i,k=1}^{n}a_i b_i a_k b_k
>> =
>> \left(\sum_{i=1}^{n}a_i b_i\right)^2.
>> $$
>>
>> Поэтому
>>
>> $$
>> S=
>> 2\left[
>> \left(\sum_{i=1}^{n}a_i^2\right)
>> \left(\sum_{i=1}^{n}b_i^2\right)
>> -
>> \left(\sum_{i=1}^{n}a_i b_i\right)^2
>> \right].
>> $$
>>
>> Из $S\ge0$ делим на $2$ и переносим квадрат суммы вправо:
>>
>> $$
>> \left(\sum_{i=1}^{n}a_i b_i\right)^2
>> \le
>> \left(\sum_{i=1}^{n}a_i^2\right)
>> \left(\sum_{i=1}^{n}b_i^2\right).
>> $$
>>
>> Извлечение квадратного корня даёт форму с модулем.
>>
>> Для равенства необходимо и достаточно, чтобы
>>
>> $$
>> S=0
>> \iff
>> a_i b_k-a_k b_i=0
>> \quad\text{для всех }i,k.
>> $$
>>
>> Если $b\ne0$, выбираем $j$ с $b_j\ne0$. При $k=j$ получаем
>>
>> $$
>> a_i=\frac{a_j}{b_j}b_i
>> \quad\text{для всех }i,
>> $$
>>
>> то есть $a=\lambda b$. Обратно, при $a=\lambda b$ каждое слагаемое в $S$ равно нулю.
