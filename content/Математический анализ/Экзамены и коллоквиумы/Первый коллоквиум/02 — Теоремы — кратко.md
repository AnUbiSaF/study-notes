# Теоремы — кратко

[[00 — Карта коллоквиума|← К карте]] · [[03 — Теоремы — полно|Полные карточки]]

> [!info]
> Структура, порядок и названия карточек полностью совпадают с полной версией. Неподготовленные карточки отмечены `⏳`; готовые краткие версии составляются только по полной карточке и лекционному источнику.

## Последовательности и пределы

> [!note]- Единственность предела и ограниченность сходящейся последовательности ✓
>
> ### 1. Единственность предела
>
>> [!abstract] Дано
>> Последовательность $(x_n)$ в метрическом пространстве $(X,\rho)$ имеет два предела:
>> $$
>> x_n\to a,
>> \qquad
>> x_n\to b.
>> $$
>
>> [!success] Тогда
>> Оба предела совпадают, то есть предел единственен:
>> $$
>> a=b.
>> $$
>
>> [!tip] Маршрут доказательства
>> Предполагаем $a\ne b$ → берём $\varepsilon=\rho(a,b)/3$ → объединяем два хвоста → неравенство треугольника даёт противоречие.
>
>> [!example] Короткое доказательство
>> Предположим, что $a\ne b$, и положим
>> $$
>> d=\rho(a,b)>0,
>> \qquad
>> \varepsilon=\frac d3.
>> $$
>> Из $x_n\to a$ и $x_n\to b$ существуют номера $N_a,N_b$, после которых
>> $$
>> \rho(x_n,a)<\varepsilon,
>> \qquad
>> \rho(x_n,b)<\varepsilon.
>> $$
>> При $n>\max\{N_a,N_b\}$ по симметричности метрики и неравенству треугольника
>> $$
>> \rho(a,b)
>> \le \rho(a,x_n)+\rho(x_n,b)
>> <2\varepsilon
>> =\frac{2d}{3}
>> <d
>> =\rho(a,b),
>> $$
>> что невозможно. Следовательно, $a=b$. $\square$
>
> ### 2. Ограниченность сходящейся последовательности
>
>> [!abstract] Дано
>> Последовательность $(x_n)$ в метрическом пространстве $(X,\rho)$ сходится к точке $a\in X$:
>> $$
>> x_n\to a.
>> $$
>
>> [!success] Тогда
>> Последовательность $(x_n)$ ограничена: существует $R>0$, для которого
>> $$
>> \rho(x_n,a)<R
>> \qquad\text{для всех }n\in\mathbb N.
>> $$
>
>> [!tip] Маршрут доказательства
>> Берём $\varepsilon=1$ → хвост попадает в $B(a,1)$ → ограничиваем конечное начало максимумом $M$ → выбираем общий радиус $R$.
>
>> [!example] Короткое доказательство
>> Берём в определении предела
>> $$
>> \varepsilon=1.
>> $$
>> Тогда существует $N$, после которого
>> $$
>> n>N\Rightarrow \rho(x_n,a)<1.
>> $$
>> Для конечного начала последовательности положим
>> $$
>> M=\max\{\rho(x_1,a),\ldots,\rho(x_N,a)\},
>> \qquad
>> R=\max\{1,M\}+1.
>> $$
>> Если $n>N$, то $\rho(x_n,a)<1<R$; если $1\le n\le N$, то $\rho(x_n,a)\le M<R$. Поэтому
>> $$
>> \rho(x_n,a)<R
>> \qquad\text{для всех }n\in\mathbb N,
>> $$
>> то есть последовательность ограничена. $\square$

> [!warning]- Предельный переход в неравенствах для последовательностей и для функций ✓ · ⚠️ Нет формулировки для функций
>
>> [!warning] Покрытие карточки
>> В лекциях найдена формулировка для последовательностей. Отдельная формулировка для функций пока не найдена.
>
>> [!abstract] Дано
>> Вещественные последовательности $(x_n)$ и $(y_n)$ удовлетворяют неравенству на некотором хвосте:
>> $$
>> \exists N_0\in\mathbb N\ \forall n>N_0:
>> \quad x_n\le y_n,
>> $$
>> и имеют конечные пределы
>> $$
>> x_n\to a,
>> \qquad
>> y_n\to b,
>> \qquad
>> a,b\in\mathbb R.
>> $$
>
>> [!success] Тогда
>> Неравенство сохраняется при переходе к пределу в нестрогой форме:
>> $$
>> a\le b.
>> $$
>
>> [!tip] Маршрут доказательства
>> Предполагаем $a>b$ → выбираем середину через $\varepsilon=(a-b)/2$ → объединяем номера хвоста → получаем $y_n<x_n$ вопреки $x_n\le y_n$.
>
>> [!example] Короткое доказательство
>> Предположим противное: $a>b$. Чтобы развести окрестности $b$ и $a$, берём
>> $$
>> \varepsilon=\frac{a-b}{2}>0.
>> $$
>> По определениям пределов существуют $N_1,N_2$, такие что
>> $$
>> n>N_1\Rightarrow a-\varepsilon<x_n,
>> \qquad
>> n>N_2\Rightarrow y_n<b+\varepsilon.
>> $$
>> Выбираем
>> $$
>> N=\max\{N_0,N_1,N_2\}.
>> $$
>> Тогда при любом $n>N$
>> $$
>> y_n
>> <b+\varepsilon
>> =\frac{a+b}{2}
>> =a-\varepsilon
>> <x_n,
>> $$
>> что противоречит условию $x_n\le y_n$. Следовательно,
>> $$
>> a\le b.
>> $$
>> $\square$
>
>> [!tip] Следствие: постоянная верхняя граница
>> **Дано:**
>> $$
>> x_n\to a,
>> \qquad
>> \exists N_0\in\mathbb N\ \forall n>N_0:
>> \quad x_n\le b.
>> $$
>> **Тогда:** предел также не превосходит эту границу:
>> $$
>> a\le b.
>> $$
>> Рассматриваем постоянную последовательность
>> $$
>> y_n\equiv b,
>> \qquad
>> y_n\to b.
>> $$
>> Тогда $x_n\le y_n$ на хвосте, поэтому по основной теореме
>> $$
>> \lim x_n\le\lim y_n,
>> $$
>> то есть $a\le b$.
>
>> [!note] Строгость может потеряться
>> Например,
>> $$
>> -\frac1n<\frac1n,
>> \qquad
>> -\frac1n\to0,
>> \qquad
>> \frac1n\to0.
>> $$
>> Поэтому из $x_n<y_n$ на хвосте следует только $a\le b$, но не обязательно $a<b$.

> [!danger]- 🔴 Теорема о двух городовых ✓
>
>> [!abstract] Дано
>> Вещественные последовательности $(x_n)$, $(y_n)$, $(z_n)$, число $a\in\mathbb R$ и номер $N_0$, причём
>> $$
>> n>N_0\Rightarrow x_n\le y_n\le z_n,
>> \qquad x_n\to a,
>> \qquad z_n\to a.
>> $$
>
>> [!success] Тогда
>> $$
>> y_n\to a.
>> $$
>
>> [!tip] Маршрут доказательства
>> Берём $\varepsilon$ → выбираем номера для двух крайних последовательностей и зажатия → берём их максимум → зажимаем $y_n$ между $a-\varepsilon$ и $a+\varepsilon$.
>
>> [!example] Короткое доказательство
>> Берём произвольное $\varepsilon>0$. По определениям пределов существуют номера $N_1$ и $N_2$, для которых
>> $$
>> n>N_1\Rightarrow a-\varepsilon<x_n,
>> \qquad
>> n>N_2\Rightarrow z_n<a+\varepsilon.
>> $$
>> Выбираем
>> $$
>> N=\max\{N_0,N_1,N_2\}.
>> $$
>> Тогда при любом $n>N$
>> $$
>> a-\varepsilon<x_n\le y_n\le z_n<a+\varepsilon,
>> $$
>> поэтому
>> $$
>> |y_n-a|<\varepsilon.
>> $$
>> Следовательно, по определению предела $y_n\to a$. $\square$
>
>> [!tip] Следствие
>> Если
>> $$
>> |y_n|\le z_n,
>> \qquad z_n\to0,
>> $$
>> то
>> $$
>> y_n\to0.
>> $$
>> Действительно,
>> $$
>> -z_n\le y_n\le z_n,
>> $$
>> причём $-z_n\to0$ и $z_n\to0$. По теореме о двух городовых $y_n\to0$. $\square$

> [!note]- Лемма о свойствах бесконечно малых последовательностей ✓
>
>> [!abstract] Определение
>> Последовательность $(x_n)$ называется **бесконечно малой**, если
>> $$
>> x_n\to0.
>> $$
>
> ### 1. Сумма бесконечно малых последовательностей
>
>> [!abstract] Дано
>> $$
>> x_n\to0,
>> \qquad
>> y_n\to0.
>> $$
>
>> [!success] Тогда
>> Сумма также является бесконечно малой:
>> $$
>> x_n+y_n\to0.
>> $$
>
>> [!tip] Маршрут доказательства
>> Делим $\varepsilon$ пополам → берём максимум двух номеров → применяем неравенство треугольника.
>
>> [!example] Короткое доказательство
>> Заданную точность делят между двумя слагаемыми:
>> $$
>> |x_n|<\frac{\varepsilon}{2},
>> \qquad
>> |y_n|<\frac{\varepsilon}{2}.
>> $$
>> Тогда
>> $$
>> |x_n+y_n|
>> \le |x_n|+|y_n|
>> <\varepsilon.
>> $$
>
> ### 2. Произведение бесконечно малой и ограниченной последовательностей
>
>> [!abstract] Дано
>> Последовательность $(x_n)$ является бесконечно малой, а $(y_n)$ ограничена:
>> $$
>> x_n\to0,
>> \qquad
>> \exists R>0\ \forall n\in\mathbb N:
>> \quad |y_n|<R.
>> $$
>
>> [!success] Тогда
>> Произведение является бесконечно малой последовательностью:
>> $$
>> x_ny_n\to0.
>> $$
>
>> [!tip] Маршрут доказательства
>> Берём границу $R$ для $y_n$ → выбираем для $x_n$ точность $\varepsilon/R$ → оцениваем произведение через $|x_n|R$.
>
>> [!example] Короткое доказательство
>> Для заданного $\varepsilon>0$ выбираем точность для $(x_n)$:
>> $$
>> \gamma=\frac{\varepsilon}{R}>0.
>> $$
>> Из $x_n\to0$ для достаточно больших $n$ следует $|x_n|<\gamma$. Поэтому
>> $$
>> |x_ny_n|
>> =|x_n|\,|y_n|
>> <\frac{\varepsilon}{R}R
>> =\varepsilon.
>> $$
>> Следовательно, $x_ny_n\to0$. Последовательности $(y_n)$ достаточно быть ограниченной; стремиться к нулю она не обязана.

> [!danger]- 🔴 Арифметические свойства пределов последовательностей в нормированном пространстве ✓
>
>> [!abstract] Дано
>> $(X,\|\cdot\|)$ — нормированное пространство над $K$,
>>
>> $$
>> x_n\to x_0,
>> \qquad y_n\to y_0,
>> \qquad \lambda_n\to\lambda_0,
>> $$
>>
>> где $x_n,y_n,x_0,y_0\in X$, а
>> $\lambda_n,\lambda_0\in K$.
>
>> [!success] Тогда
>>
>> $$
>> x_n+y_n\to x_0+y_0,
>> \qquad x_n-y_n\to x_0-y_0,
>> $$
>>
>> $$
>> \lambda_nx_n\to\lambda_0x_0,
>> \qquad \|x_n\|\to\|x_0\|.
>> $$
>
>> [!tip] Маршрут доказательства
>> **Сумма:**
>>
>> $$
>> \varepsilon/2\to N_x,N_y
>> \to N=\max\{N_x,N_y\}
>> \to \text{неравенство треугольника}
>> \to \text{закрытие кванторов}.
>> $$
>>
>> **Разность:**
>>
>> $$
>> \varepsilon/2\to N_x,N_y
>> \to N=\max\{N_x,N_y\}
>> \to \|-v\|=\|v\|
>> \to \text{закрытие кванторов}.
>> $$
>>
>> **Умножение:**
>>
>> $$
>> (\lambda_n)\text{ ограничена}
>> \to M=\max\{1,C\}
>> \to \text{вставка }\lambda_nx_0
>> \to \text{выбор точностей из оценки}
>> \to N=\max\{N_x,N_\lambda\}
>> \to \text{закрытие кванторов}.
>> $$
>>
>> **Норма:**
>>
>> $$
>> \text{обратное неравенство треугольника}
>> \to \text{определение }x_n\to x_0
>> \to \text{закрытие кванторов}.
>> $$
>
>> [!example] 1. Короткое доказательство суммы
>>
>> $$
>> \forall\varepsilon>0:\quad
>> \begin{cases}
>> \exists N_x\in\mathbb N\ \forall n\in\mathbb N:\
>> n>N_x\Rightarrow
>> \|x_n-x_0\|<\dfrac{\varepsilon}{2},\\[2mm]
>> \exists N_y\in\mathbb N\ \forall n\in\mathbb N:\
>> n>N_y\Rightarrow
>> \|y_n-y_0\|<\dfrac{\varepsilon}{2}.
>> \end{cases}
>> $$
>>
>> $$
>> N=\max\{N_x,N_y\}.
>> $$
>>
>> $$
>> \begin{aligned}
>> \forall n\in\mathbb N:\quad n>N\Rightarrow
>> \|(x_n+y_n)-(x_0+y_0)\|
>> &\le\|x_n-x_0\|+\|y_n-y_0\|\\
>> &<\varepsilon.
>> \end{aligned}
>> $$
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\ \forall n\in\mathbb N:
>> \quad n>N\Rightarrow\|(x_n+y_n)-(x_0+y_0)\|<\varepsilon,
>> $$
>>
>> то есть $x_n+y_n\to x_0+y_0$.
>
>> [!example] 2. Короткое доказательство разности
>>
>> $$
>> \forall\varepsilon>0:\quad
>> \begin{cases}
>> \exists N_x\in\mathbb N\ \forall n\in\mathbb N:\
>> n>N_x\Rightarrow
>> \|x_n-x_0\|<\dfrac{\varepsilon}{2},\\[2mm]
>> \exists N_y\in\mathbb N\ \forall n\in\mathbb N:\
>> n>N_y\Rightarrow
>> \|y_n-y_0\|<\dfrac{\varepsilon}{2}.
>> \end{cases}
>> $$
>>
>> $$
>> N=\max\{N_x,N_y\}.
>> $$
>>
>> $$
>> \begin{aligned}
>> \forall n\in\mathbb N:\quad n>N\Rightarrow
>> \|(x_n-y_n)-(x_0-y_0)\|
>> &\le\|x_n-x_0\|+\|-(y_n-y_0)\|\\
>> &=\|x_n-x_0\|+\|y_n-y_0\|\\
>> &<\varepsilon.
>> \end{aligned}
>> $$
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\ \forall n\in\mathbb N:
>> \quad n>N\Rightarrow\|(x_n-y_n)-(x_0-y_0)\|<\varepsilon,
>> $$
>>
>> то есть $x_n-y_n\to x_0-y_0$.
>
>> [!example] 3. Короткое доказательство умножения
>> По теореме об ограниченности сходящейся последовательности
>>
>> $$
>> \exists C\ge0\ \forall n:\quad |\lambda_n|\le C,
>> \qquad M=\max\{1,C\}.
>> $$
>>
>> $$
>> \begin{aligned}
>> \lambda_nx_n-\lambda_0x_0
>> &=\lambda_n(x_n-x_0)+(\lambda_n-\lambda_0)x_0,\\
>> \|\lambda_nx_n-\lambda_0x_0\|
>> &\le M\|x_n-x_0\|
>> +|\lambda_n-\lambda_0|\,\|x_0\|.
>> \end{aligned}
>> $$
>>
>> Пусть $\varepsilon>0$.
>>
>> Выбираем точности назад от оценки:
>>
>> $$
>> M\delta_x<\frac{\varepsilon}{2},
>> \qquad \|x_0\|\delta_\lambda<\frac{\varepsilon}{2},
>> $$
>>
>> $$
>> \delta_x=\frac{\varepsilon}{2M},
>> \qquad
>> \delta_\lambda=\frac{\varepsilon}{2(\|x_0\|+1)}.
>> $$
>>
>> $$
>> M\delta_x=\frac{\varepsilon}{2},
>> \qquad \|x_0\|\delta_\lambda<\frac{\varepsilon}{2}.
>> $$
>>
>> $$
>> \begin{cases}
>> \exists N_x\ \forall n>N_x:
>> \|x_n-x_0\|<\delta_x,\\[2mm]
>> \exists N_\lambda\ \forall n>N_\lambda:
>> |\lambda_n-\lambda_0|<\delta_\lambda,
>> \end{cases}
>> \qquad N=\max\{N_x,N_\lambda\}.
>> $$
>>
>> $$
>> \forall n>N:\quad
>> \|\lambda_nx_n-\lambda_0x_0\|
>> <M\delta_x+\|x_0\|\delta_\lambda
>> <\varepsilon.
>> $$
>>
>> $$
>> \forall\varepsilon>0\ \exists N\ \forall n>N:
>> \quad \|\lambda_nx_n-\lambda_0x_0\|<\varepsilon,
>> $$
>>
>> то есть $\lambda_nx_n\to\lambda_0x_0$.
>
>> [!example] 4. Короткое доказательство предела нормы
>> По обратному неравенству треугольника
>>
>> $$
>> \bigl|\|x_n\|-\|x_0\|\bigr|\le\|x_n-x_0\|.
>> $$
>>
>> $$
>> \varepsilon>0\Longrightarrow
>> \exists N\ \forall n>N:\quad
>> \|x_n-x_0\|<\varepsilon.
>> $$
>>
>> $$
>> \forall n>N:\quad
>> \bigl|\|x_n\|-\|x_0\|\bigr|<\varepsilon.
>> $$
>>
>> $$
>> \forall\varepsilon>0\ \exists N\ \forall n>N:
>> \quad \bigl|\|x_n\|-\|x_0\|\bigr|<\varepsilon,
>> $$
>>
>> то есть $\|x_n\|\to\|x_0\|$.

> [!danger]- 🔴 Арифметические свойства пределов последовательностей в  $\mathbb R$ ✓
>
>> [!abstract] Дано
>> $$
>> x_n\to x_0,
>> \qquad
>> y_n\to y_0,
>> \qquad
>> x_0,y_0\in\mathbb R,
>> \qquad
>> \forall n\in\mathbb N:\ x_n,y_n\in\mathbb R.
>> $$
>
>> [!success] Тогда
>> $$
>> x_ny_n\to x_0y_0,
>> \qquad
>> |x_n|\to|x_0|.
>> $$
>>
>> $$
>> y_0\ne0
>> \quad\Longrightarrow\quad
>> \begin{cases}
>> \exists N_0\in\mathbb N\ \forall n\in\mathbb N:
>> n>N_0\Rightarrow y_n\ne0,\\[2mm]
>> \dfrac{x_n}{y_n}\to\dfrac{x_0}{y_0}.
>> \end{cases}
>> $$
>
>> [!tip] Маршрут доказательства
>> **Произведение:**
>>
>> $$
>> (x_n)\text{ ограничена}
>> \to
>> x_ny_n-x_0y_0
>> =
>> x_n(y_n-y_0)+y_0(x_n-x_0)
>> \to \varepsilon/2+\varepsilon/2.
>> $$
>>
>> **Модуль:**
>>
>> $$
>> \bigl||x_n|-|x_0|\bigr|
>> \le |x_n-x_0|.
>> $$
>>
>> **Частное:**
>>
>> $$
>> |y_n|>\frac{|y_0|}{2}
>> \to
>> \frac1{y_n}\to\frac1{y_0}
>> \to
>> \frac{x_n}{y_n}\to\frac{x_0}{y_0}.
>> $$
>
>> [!example] 1. Короткое доказательство предела произведения
>> По теореме об ограниченности сходящейся последовательности
>>
>> $$
>> \exists M>0\ \forall n\in\mathbb N:
>> \quad |x_n|\le M.
>> $$
>>
>> $$
>> \begin{aligned}
>> |x_ny_n-x_0y_0|
>> &=
>> \bigl|x_n(y_n-y_0)+y_0(x_n-x_0)\bigr|\\
>> &\le
>> M|y_n-y_0|+|y_0|\,|x_n-x_0|.
>> \end{aligned}
>> $$
>>
>> Пусть $\varepsilon>0$. Выбираем
>>
>> $$
>> \delta_y=\frac{\varepsilon}{2M},
>> \qquad
>> \delta_x=\frac{\varepsilon}{2(|y_0|+1)}.
>> $$
>>
>> Тогда
>>
>> $$
>> M\delta_y=\frac{\varepsilon}{2},
>> \qquad
>> |y_0|\delta_x<\frac{\varepsilon}{2}.
>> $$
>>
>> $$
>> \begin{cases}
>> \exists N_x\in\mathbb N\ \forall n\in\mathbb N:
>> n>N_x\Rightarrow |x_n-x_0|<\delta_x,\\[2mm]
>> \exists N_y\in\mathbb N\ \forall n\in\mathbb N:
>> n>N_y\Rightarrow |y_n-y_0|<\delta_y,
>> \end{cases}
>> \qquad
>> N=\max\{N_x,N_y\}.
>> $$
>>
>> Для каждого $n>N$:
>>
>> $$
>> \begin{aligned}
>> |x_ny_n-x_0y_0|
>> &\le
>> M|y_n-y_0|+|y_0|\,|x_n-x_0|\\
>> &<
>> M\delta_y+|y_0|\delta_x\\
>> &<
>> \frac{\varepsilon}{2}+\frac{\varepsilon}{2}
>> =\varepsilon.
>> \end{aligned}
>> $$
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\
>> \forall n\in\mathbb N:
>> \quad n>N\Rightarrow
>> |x_ny_n-x_0y_0|<\varepsilon,
>> $$
>>
>> то есть $x_ny_n\to x_0y_0$.
>
>> [!example] 2. Короткое доказательство предела модуля
>> По обратному неравенству треугольника
>>
>> $$
>> \bigl||x_n|-|x_0|\bigr|
>> \le |x_n-x_0|.
>> $$
>>
>> Из $x_n\to x_0$:
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\
>> \forall n\in\mathbb N:
>> \quad
>> n>N\Rightarrow
>> \bigl||x_n|-|x_0|\bigr|
>> \le |x_n-x_0|
>> <\varepsilon,
>> $$
>>
>> то есть $|x_n|\to|x_0|$.
>
>> [!example] 3. Короткое доказательство предела частного
>> Пусть $y_0\ne0$. По определению $y_n\to y_0$:
>>
>> $$
>> \forall\varepsilon>0\ \exists N_\varepsilon\in\mathbb N\
>> \forall n\in\mathbb N:
>> \quad
>> n>N_\varepsilon
>> \Rightarrow
>> |y_n-y_0|<\varepsilon.
>> $$
>>
>> Положим
>>
>> $$
>> \varepsilon=\frac{|y_0|}{2}>0.
>> $$
>>
>> Тогда
>>
>> $$
>> \exists N_0\in\mathbb N\ \forall n\in\mathbb N:
>> \quad
>> n>N_0\Rightarrow
>> |y_n-y_0|<\frac{|y_0|}{2}.
>> $$
>>
>> Для каждого $n>N_0$:
>>
>> $$
>> \begin{aligned}
>> |y_0|
>> &=|(y_0-y_n)+y_n|\\
>> &\le |y_n-y_0|+|y_n|
>> \end{aligned}
>> \Rightarrow
>> |y_n|
>> \ge |y_0|-|y_n-y_0|
>> >\frac{|y_0|}{2}>0.
>> $$
>>
>> Следовательно,
>>
>> $$
>> \forall n\in\mathbb N:
>> \quad n>N_0\Rightarrow y_n\ne0.
>> $$
>>
>> Достаточно доказать
>>
>> $$
>> \frac1{y_n}\to\frac1{y_0},
>> \qquad
>> \frac{x_n}{y_n}=x_n\cdot\frac1{y_n}.
>> $$
>>
>> $$
>> |y_n|>\frac{|y_0|}{2}
>> \Rightarrow
>> \frac1{|y_n|\,|y_0|}
>> <\frac2{|y_0|^2}.
>> $$
>>
>> Для каждого $n>N_0$:
>>
>> $$
>> \begin{aligned}
>> 0
>> &\le
>> \left|\frac1{y_n}-\frac1{y_0}\right|\\
>> &=
>> \frac{|y_n-y_0|}{|y_n|\,|y_0|}\\
>> &\le
>> \frac2{|y_0|^2}|y_n-y_0|
>> \to0.
>> \end{aligned}
>> $$
>>
>> По теореме о двух милиционерах
>>
>> $$
>> \left|\frac1{y_n}-\frac1{y_0}\right|\to0
>> \quad\Longrightarrow\quad
>> \frac1{y_n}\to\frac1{y_0}.
>> $$
>>
>> Если первые $y_n$ равны нулю, соответствующие первые члены
>> $(1/y_n)$ задаются произвольно: конечный фрагмент не влияет на предел.
>>
>> По доказанному пределу произведения
>>
>> $$
>> \frac{x_n}{y_n}
>> =
>> x_n\cdot\frac1{y_n}
>> \to
>> x_0\cdot\frac1{y_0}
>> =
>> \frac{x_0}{y_0}.
>> $$

## Множества и отображения

> [!note]- Законы де Моргана ✓
>
>> [!abstract] Дано
>> Множество $Y$ и семейство множеств $(X_\alpha)_{\alpha\in I}$.
>>
>> Объединение соответствует «существует индекс», а пересечение — «для всех индексов».
>
>> [!success] Тогда
>>
>> $$
>> Y\setminus\bigcup_{\alpha\in I}X_\alpha
>> =
>> \bigcap_{\alpha\in I}(Y\setminus X_\alpha),
>> \qquad
>> Y\setminus\bigcap_{\alpha\in I}X_\alpha
>> =
>> \bigcup_{\alpha\in I}(Y\setminus X_\alpha),
>> $$
>>
>> $$
>> Y\cap\bigcup_{\alpha\in I}X_\alpha
>> =
>> \bigcup_{\alpha\in I}(Y\cap X_\alpha),
>> \qquad
>> Y\cup\bigcap_{\alpha\in I}X_\alpha
>> =
>> \bigcap_{\alpha\in I}(Y\cup X_\alpha).
>> $$
>
>> [!tip] Маршрут доказательства
>> Берём произвольный $x$ → заменяем объединение на $\exists$, пересечение на $\forall$ → переставляем логические связки → получаем принадлежность правой части.
>
>> [!note] Как читать переходы
>> - Вычесть из $Y$ объединение $\Longleftrightarrow$ пересечь результаты вычитания из $Y$ каждого $X_\alpha$.
>> - Вычесть из $Y$ пересечение $\Longleftrightarrow$ объединить результаты вычитания из $Y$ каждого $X_\alpha$.
>> - Пересечь $Y$ с объединением $\Longleftrightarrow$ объединить пересечения $Y$ с каждым $X_\alpha$.
>> - Объединить $Y$ с пересечением $\Longleftrightarrow$ пересечь объединения $Y$ с каждым $X_\alpha$.
>
>> [!example] Короткое доказательство
>> Берём произвольный $x$ и переводим принадлежность множеству в кванторы:
>>
>> $$
>> x\notin\bigcup_{\alpha\in I}X_\alpha
>> \iff
>> \forall\alpha\in I:\ x\notin X_\alpha,
>> \qquad
>> x\notin\bigcap_{\alpha\in I}X_\alpha
>> \iff
>> \exists\alpha\in I:\ x\notin X_\alpha.
>> $$
>>
>> Отсюда получаются два закона де Моргана. Для распределительных законов:
>>
>> $$
>> \bigl(x\in Y\ \text{и}\ \exists\alpha\in I:\ x\in X_\alpha\bigr)
>> \iff
>> \exists\alpha\in I:\ x\in Y\cap X_\alpha,
>> $$
>>
>> $$
>> \bigl(x\in Y\ \text{или}\ \forall\alpha\in I:\ x\in X_\alpha\bigr)
>> \iff
>> \forall\alpha\in I:\ x\in Y\cup X_\alpha.
>> $$
>>
>> Поэтому равны множества в каждой из четырёх формул.

## Порядок и полнота

> [!note]- Аксиома Архимеда. Плотность множества рациональных чисел в $\mathbb R$ ✓
>
>> [!abstract] Дано
>> Для аксиомы Архимеда: $x,y>0$.
>>
>> Для плотности рациональных чисел: $a,b\in\mathbb R$ и $a<b$.
>
>> [!success] Тогда
>>
>> $$
>> \forall x,y>0\quad\exists n\in\mathbb N:\ nx>y.
>> $$
>>
>> Эквивалентно:
>>
>> $$
>> \forall t\in\mathbb R\quad\exists n\in\mathbb N:\ n>t.
>> $$
>>
>> Кроме того,
>>
>> $$
>> \exists q\in\mathbb Q:\ a<q<b.
>> $$
>
>> [!tip] Маршрут доказательства
>> Берём $t=y/x$ для эквивалентной формы Архимеда → выбираем сетку $k/m$ с $1/m<b-a$ → берём первую точку правее $a$ → проверяем $a<q<b$.
>
>> [!example] Короткое доказательство
>> Аксиома Архимеда не доказывается. Для перехода от формы $n>t$ к исходной берём
>>
>> $$
>> t=\frac yx;
>> \qquad
>> n>\frac yx
>> \Longrightarrow
>> nx>y.
>> $$
>>
>> Для плотности выбираем сетку $k/m$ с шагом $1/m$. Берём
>>
>> $$
>> m>\frac1{b-a},
>> \qquad
>> \frac1m<b-a,
>> $$
>>
>> и первую точку этой сетки правее $a$:
>>
>> $$
>> q=\frac{\lfloor ma\rfloor+1}{m}.
>> $$
>>
>> Из
>>
>> $$
>> ma<\lfloor ma\rfloor+1
>> $$
>>
>> следует $a<q$. Из
>>
>> $$
>> \lfloor ma\rfloor\le ma
>> $$
>>
>> получаем
>>
>> $$
>> q\le a+\frac1m<b.
>> $$
>>
>> Следовательно, $a<q<b$, причём $q\in\mathbb Q$.

> [!note]- Неравенство Бернулли ✓
>
>> [!abstract] Дано
>>
>> $$
>> n\in\mathbb N,
>> \qquad n\ge2,
>> \qquad x>-1.
>> $$
>
>> [!success] Тогда
>>
>> $$
>> (1+x)^n\ge1+nx.
>> $$
>>
>> При $x\ne0$ неравенство строгое.
>
>> [!tip] Маршрут доказательства
>> База $n=2$ → индукционное предположение $P(n)$ → умножение на $1+x>0$ → раскрытие скобок → $nx^2\ge0$.
>
>> [!example] Короткое доказательство
>> Обозначим
>>
>> $$
>> P(n):\quad (1+x)^n\ge1+nx.
>> $$
>>
>> База:
>>
>> $$
>> (1+x)^2=1+2x+x^2\ge1+2x.
>> $$
>>
>> Пусть верно $P(n)$. Так как $x>-1$, то $1+x>0$, поэтому
>>
>> $$
>> (1+x)^{n+1}
>> \ge
>> (1+nx)(1+x)
>> =
>> 1+(n+1)x+nx^2
>> \ge
>> 1+(n+1)x.
>> $$
>>
>> Значит, верно $P(n+1)$; по индукции утверждение доказано. При $x\ne0$ имеем $nx^2>0$, поэтому неравенство строгое.

> [!danger]- 🔴 Теорема Кантора о стягивающихся отрезках ✓
>
>> [!abstract] Дано
>> Последовательность непустых замкнутых отрезков:
>>
>> $$
>> [a_1,b_1]\supset[a_2,b_2]\supset\ldots,
>> \qquad
>> b_n-a_n\to0.
>> $$
>
>> [!success] Тогда
>> Существует ровно одна точка
>>
>> $$
>> c\in\bigcap_{n=1}^{\infty}[a_n,b_n],
>> $$
>>
>> причём
>>
>> $$
>> a_n\to c,
>> \qquad
>> b_n\to c.
>> $$
>
>> [!tip] Маршрут доказательства
>> Аксиома Кантора → выбираем общую точку $c$ → зажатие концов длиной $b_n-a_n$ → $a_n,b_n\to c$ → единственность предела.
>
>> [!example] Короткое доказательство
>> По аксиоме Кантора
>>
>> $$
>> \bigcap_{n=1}^{\infty}[a_n,b_n]\ne\varnothing.
>> $$
>>
>> Выбираем $c$ из этого пересечения. Тогда для каждого $n$
>>
>> $$
>> a_n\le c\le b_n.
>> $$
>>
>> Поэтому
>>
>> $$
>> 0\le c-a_n\le b_n-a_n\to0
>> \quad\Longrightarrow\quad
>> a_n-c=-(c-a_n)\to0
>> \quad\Longrightarrow\quad
>> a_n\to c,
>> $$
>>
>> $$
>> 0\le b_n-c\le b_n-a_n\to0
>> \quad\Longrightarrow\quad
>> b_n\to c.
>> $$
>>
>> Если $d$ тоже лежит во всех отрезках, то тем же рассуждением $a_n\to d$. Но $a_n\to c$, поэтому по единственности предела $d=c$.

> [!note]- Десятичная запись числа ✓
>
>> [!abstract] Дано
>> $x\in[0,1]$.
>
>> [!tip] Маршрут
>> Делим текущий отрезок на $10$ частей → берём часть с $x$ → её номер записываем следующей цифрой → повторяем.
>
>> [!example] Схема
>> Например,
>>
>> $$
>> x\in[0{,}2,0{,}3]\ \to\ 2,\qquad
>> x\in[0{,}28,0{,}29]\ \to\ 8,\qquad
>> x\in[0{,}283,0{,}284]\ \to\ 3.
>> $$
>>
>> Так получаем $x=0{,}283\ldots$.
>
>> [!note] Граничный случай
>> На общей границе двух частей есть два выбора: вправо — дальше нули, влево — дальше девятки:
>>
>> $$
>> 0{,}28=0{,}28000\ldots=0{,}27999\ldots.
>> $$

> [!note]- Теорема о существовании супремума ✓
>
>> [!abstract] Дано
>> $E\subseteq\mathbb R$, $E\ne\varnothing$,
>> и $E$ ограничено сверху.
>
>> [!success] Тогда
>> Существует $M\in\mathbb R$, для которого
>>
>> $$
>> M=\sup E.
>> $$
>
>> [!tip] Маршрут доказательства
>>
>> 1. $a_n$ ещё не потолок множества $E$;
>> $b_n$ уже потолок.
>>
>> 2. Делим $[a_n,b_n]$ пополам и сохраняем
>> половину с теми же ролями.
>>
>> 3. Отрезки сжимаются к точке $M$.
>>
>> 4. $b_n\to M$ делает $M$ верхней границей,
>> а $a_n\to M$ позволяет подойти к $M$ снизу.
>
>> [!example] Короткое доказательство
>> **Старт.** Берём $a_1\in E$.
>> Если $a_1$ — верхняя граница, то
>>
>> $$
>> a_1=\max E=\sup E.
>> $$
>>
>> Иначе берём верхнюю границу $b_1$.
>> Если $b_1\in E$, то
>>
>> $$
>> b_1=\max E=\sup E.
>> $$
>>
>> В оставшемся случае
>>
>> $$
>> a_1<b_1,
>> $$
>>
>> $$
>> a_1\text{ не верхняя граница},
>> \qquad
>> b_1\text{ верхняя граница}.
>> $$
>>
>> Начинаем с отрезка $[a_1,b_1]$.
>>
>> **Шаг.** Пусть уже есть $[a_n,b_n]$ с теми же ролями.
>>
>> Для середины
>>
>> $$
>> d_n=\frac{a_n+b_n}{2}
>> $$
>>
>> сохраняем левую половину, если $d_n$ — верхняя граница,
>> и правую — иначе. Тогда
>>
>> $$
>> a_n\text{ не верхняя граница},
>> \qquad
>> b_n\text{ верхняя граница},
>> $$
>>
>> $$
>> [a_{n+1},b_{n+1}]\subseteq[a_n,b_n],
>> $$
>>
>> $$
>> b_n-a_n=
>> \frac{b_1-a_1}{2^{n-1}}\to0.
>> $$
>>
>> **Предел отрезков.** По Кантору отрезки имеют единственную
>> общую точку $M$, причём
>>
>> $$
>> a_n\to M,
>> \qquad
>> b_n\to M.
>> $$
>>
>> Зафиксируем произвольный $x\in E$. Тогда
>>
>> $$
>> \forall n\in\mathbb N:\quad x\le b_n.
>> $$
>>
>> Из $b_n\to M$ получаем $x\le M$.
>> Поскольку $x$ произвольный,
>>
>> $$
>> \forall x\in E:\quad x\le M.
>> $$
>>
>> Значит, $M$ — верхняя граница.
>>
>> **Минимальность.** Берём произвольное $\varepsilon>0$.
>> Из $a_n\to M$ найдётся $N$, такое что для каждого $n\ge N$:
>>
>> $$
>> M-\varepsilon<a_n.
>> $$
>>
>> Берём любой $n\ge N$. Так как $a_n$ не верхняя граница,
>> найдётся $x\in E$:
>>
>> $$
>> M-\varepsilon<a_n<x\le M.
>> $$
>>
>> Это критерий супремума, значит $M=\sup E$. $\square$

> [!note]- Лемма о свойствах супремума ✓
>
>> [!abstract] Дано
>> Пусть $D,E\subset\overline{\mathbb R}$, $D\subset E$ и
>> $\lambda>0$. Обозначим
>>
>> $$
>> \lambda E=\{\lambda x:x\in E\},
>> \qquad
>> -E=\{-x:x\in E\}.
>> $$
>
>> [!success] Тогда
>>
>> $$
>> \sup D\le\sup E,
>> \qquad
>> \sup(\lambda E)=\lambda\sup E,
>> \qquad
>> \sup(-E)=-\inf E.
>> $$
>
>> [!example] Короткое доказательство
>> **1. Монотонность.** Из $D\subset E$ следует
>>
>> $$
>> \forall x\in D:\quad x\le\sup E.
>> $$
>>
>> Поэтому $\sup E$ — верхняя граница $D$. Так как $\sup D$ —
>> наименьшая верхняя граница $D$,
>>
>> $$
>> \sup D\le\sup E.
>> $$
>>
>> **2. Умножение на $\lambda>0$.** Имеем
>>
>> $$
>> \forall x\in E:\quad
>> x\le\sup E
>> \Longrightarrow
>> \lambda x\le\lambda\sup E.
>> $$
>>
>> Значит, $\lambda\sup E$ — верхняя граница $\lambda E$.
>>
>> Пусть $b$ — произвольная верхняя граница $\lambda E$. Тогда
>>
>> $$
>> \forall x\in E:\quad
>> \lambda x\le b
>> \Longrightarrow
>> x\le\frac b\lambda.
>> $$
>>
>> Следовательно, $\frac b\lambda$ — верхняя граница $E$, поэтому
>>
>> $$
>> \sup E\le\frac b\lambda
>> \Longrightarrow
>> \lambda\sup E\le b.
>> $$
>>
>> Таким образом, $\lambda\sup E$ — наименьшая верхняя грань
>> $\lambda E$. По определению супремума
>>
>> $$
>> \sup(\lambda E)=\lambda\sup E.
>> $$
>>
>> **3. Связь с инфимумом.** Поскольку
>>
>> $$
>> \forall x\in E:\quad \inf E\le x,
>> $$
>>
>> после умножения на $-1$ получаем
>>
>> $$
>> \forall x\in E:\quad -x\le-\inf E.
>> $$
>>
>> Значит, $-\inf E$ — верхняя граница $-E$.
>>
>> Пусть $b$ — произвольная верхняя граница $-E$. Тогда
>>
>> $$
>> \forall x\in E:\quad
>> -x\le b
>> \Longrightarrow
>> -b\le x.
>> $$
>>
>> Следовательно, $-b$ — нижняя граница $E$, поэтому
>>
>> $$
>> -b\le\inf E
>> \Longrightarrow
>> -\inf E\le b.
>> $$
>>
>> Таким образом, $-\inf E$ — наименьшая верхняя грань $-E$.
>> По определению супремума
>>
>> $$
>> \sup(-E)=-\inf E.
>> $$

> [!note]- Теорема о пределе монотонной последовательности ✓
>
>> [!abstract] Дано
>>
>> - $(x_n)$ возрастает и ограничена сверху; или
>> - $(x_n)$ убывает и ограничена снизу.
>
>> [!success] Тогда
>> Если $(x_n)$ возрастает, то
>>
>> $$
>> \lim_{n\to\infty}x_n=\sup_n x_n.
>> $$
>>
>> Если $(x_n)$ убывает, то
>>
>> $$
>> \lim_{n\to\infty}x_n=\inf_n x_n.
>> $$
>
>> [!tip] Маршрут доказательства
>>
>> 1. $b$ — супремум, верхняя граница; хотим доказать $x_n\to b$.
>>
>> 2. $\varepsilon>0$ — любая нужная точность.
>>
>> 3. По супремуму находим $n_0$:
>> $x_{n_0}>b-\varepsilon$.
>>
>> 4. $n_0$ начинает хвост; монотонность и граница $b$
>> удерживают его на расстоянии меньше $\varepsilon$ от $b$.
>>
>> 5. Для убывания так же, но $a$ — инфимум,
>> нижняя граница вместо $b$.
>
>> [!example] Короткое доказательство
>> **Возрастает.** Пусть
>>
>> $$
>> b=\sup\{x_1,x_2,\ldots\}.
>> $$
>>
>> Для любого $\varepsilon>0$ найдётся $n_0$, такое что
>>
>> $$
>> b-\varepsilon<x_{n_0}.
>> $$
>>
>> Тогда для каждого $n\ge n_0$
>>
>> $$
>> b-\varepsilon<x_{n_0}\le x_n\le b.
>> $$
>>
>> Поэтому ??
>>
>> $$
>> x_n\le b,
>> \qquad
>> |x_n-b|=b-x_n<\varepsilon.
>> $$
>>
>> То есть $x_n\to b$.
>>
>> **Убывает.** Если $a=\inf x_n$, то для $n\ge n_0$
>>
>> $$
>> a\le x_n\le x_{n_0}<a+\varepsilon.
>> $$
>>
>> Значит (добавить +-беск), $|x_n-a|<\varepsilon$ и $x_n\to a$. $\square$

> [!note]- Определение числа e, соответствующий замечательный предел ✓
>
>> [!abstract] Дано
>> Для всех $n\in\mathbb N$:
>>
>> $$
>> x_n=\left(1+\frac1n\right)^n,
>> \qquad
>> y_n=\left(1+\frac1n\right)^{n+1}.
>> $$
>
>> [!success] Тогда
>> Существует число $e$, для которого
>>
>> $$
>> \lim_{n\to\infty}\left(1+\frac1n\right)^n
>> =e=
>> \lim_{n\to\infty}\left(1+\frac1n\right)^{n+1}.
>> $$
>
>> [!tip] Маршрут доказательства
>> Отношение соседних $y_n$ → Бернулли → $(y_n)$ убывает
>> → $y_n>0$ → существует предел $L$
>> → выражаем $x_n$ через $y_n$ → оба предела равны $L$
>> → по определению $L=e$.
>
>> [!example] Короткое доказательство
>> **1. Убывание.** Для каждого $n\ge2$:
>>
>> $$
>> \frac{y_{n-1}}{y_n}
>> =
>> \frac{n-1}{n}
>> \left(1+\frac1{n^2-1}\right)^{n+1}.
>> $$
>>
>> По неравенству Бернулли
>>
>> $$
>> \left(1+\frac1{n^2-1}\right)^{n+1}
>> \ge
>> 1+\frac1{n-1}.
>> $$
>>
>> Поэтому
>>
>> $$
>> \frac{y_{n-1}}{y_n}
>> \ge
>> \frac{n-1}{n}
>> \left(1+\frac1{n-1}\right)
>> =1.
>> $$
>>
>> Так как $y_n>0$, для каждого $n\ge2$:
>>
>> $$
>> y_{n-1}\ge y_n.
>> $$
>>
>> Следовательно, $(y_n)$ убывает.
>>
>> **2. Предел $y_n$.** Для всех $n\in\mathbb N$:
>>
>> $$
>> y_n>0.
>> $$
>>
>> Поэтому $(y_n)$ ограничена снизу нулём.
>> По теореме о монотонной последовательности существует
>>
>> $$
>> \exists L\in\mathbb R:
>> \quad y_n\to L.
>> $$
>>
>> **3. Предел $x_n$.**
>>
>> $$
>> x_n=
>> \frac{y_n}{1+\frac1n},
>> \qquad
>> 1+\frac1n\to1.
>> $$
>>
>> Поэтому по теореме о пределе частного
>>
>> $$
>> x_n\to\frac L1=L.
>> $$
>>
>> Общий предел определяют как число $e$:
>>
>> $$
>> e=L.
>> $$
>>
>> $\square$

> [!note]- Лемма о сходимости к нулю "быстро убывающей" последовательности ✓
>
>> [!abstract] Дано
>> Последовательность положительных чисел $(x_n)$ и предел отношения соседних членов:
>>
>> $$
>> x_n>0,
>> \qquad
>> \lim_{n\to\infty}\frac{x_{n+1}}{x_n}=q,
>> \qquad
>> q<1.
>> $$
>
>> [!success] Тогда
>>
>> $$
>> x_n\to0.
>> $$
>
>> [!example] Короткое доказательство
>> Выбираем число $m$ так, что $q<m<1$, и берём
>>
>> $$
>> \varepsilon=m-q>0.
>> $$
>>
>> Тогда начиная с некоторого $N$:
>>
>> $$
>> \left|\frac{x_{n+1}}{x_n}-q\right|<m-q.
>> $$
>>
>> Следовательно,
>>
>> $$
>> \frac{x_{n+1}}{x_n}<m.
>> $$
>>
>> Так как $x_n>0$,
>>
>> $$
>> x_{n+1}<mx_n.
>> $$
>>
>> Фиксируем $k\ge N$. Последовательно применяем оценку для $k,k+1,\ldots$:
>>
>> $$
>> x_{k+p}<m^p x_k.
>> $$
>>
>> Для любого $n\ge k$ полагаем $p=n-k$. Тогда
>>
>> $$
>> 0<x_n<m^{n-k}x_k.
>> $$
>>
>> Так как $0<m<1$, а $x_k$ фиксировано,
>>
>> $$
>> m^{n-k}x_k\to0.
>> $$
>>
>> По теореме о двух городовых $x_n\to0$. $\square$
>
>> [!tip] Следствие
>> Для $a>0$
>>
>> $$
>> \frac{a^n}{n!}\to0.
>> $$
>>
>> При $x_n=\frac{a^n}{n!}$
>>
>> $$
>> \frac{x_{n+1}}{x_n}=\frac{a}{n+1}\to0<1,
>> $$
>>
>> поэтому применима лемма.

## Скалярное произведение и координаты

> [!note]- Неравенство КБШ для конечных числовых наборов ✓
>
>> [!abstract] Дано
>> Два вещественных числовых набора одинаковой длины:
>>
>> $$
>> a=(a_1,\ldots,a_n),
>> \qquad
>> b=(b_1,\ldots,b_n).
>> $$
>
>> [!success] Тогда
>>
>> $$
>> \left(\sum_{i=1}^{n}a_i b_i\right)^2
>> \le
>> \left(\sum_{i=1}^{n}a_i^2\right)
>> \left(\sum_{i=1}^{n}b_i^2\right).
>> $$
>>
>> Эквивалентно:
>>
>> $$
>> \left|\sum_{i=1}^{n}a_i b_i\right|
>> \le
>> \sqrt{\sum_{i=1}^{n}a_i^2}
>> \sqrt{\sum_{i=1}^{n}b_i^2}.
>> $$
>>
>> Равенство достигается тогда и только тогда, когда наборы линейно зависимы.
>
>> [!tip] Маршрут доказательства
>> Сумма квадратов $S$ → тождество Лагранжа → $S\ge0$ → неравенство КБШ → $S=0$ даёт линейную зависимость.
>
>> [!example] Короткое доказательство
>> Записываем сумму квадратов
>>
>> $$
>> S=\sum_{i,k=1}^{n}(a_i b_k-a_k b_i)^2\ge0.
>> $$
>>
>> Раскрываем квадрат и переставляем множители в среднем слагаемом:
>>
>> $$
>> S=
>> \sum_{i,k=1}^{n}a_i^2b_k^2
>> -2\sum_{i,k=1}^{n}a_i b_i a_k b_k
>> +\sum_{i,k=1}^{n}a_k^2b_i^2.
>> $$
>>
>> Сворачиваем двойные суммы:
>>
>> $$
>> \sum_{i,k=1}^{n}a_i^2b_k^2
>> =
>> \sum_{i,k=1}^{n}a_k^2b_i^2
>> =
>> \left(\sum_{i=1}^{n}a_i^2\right)
>> \left(\sum_{i=1}^{n}b_i^2\right),
>> $$
>>
>> $$
>> \sum_{i,k=1}^{n}a_i b_i a_k b_k
>> =
>> \left(\sum_{i=1}^{n}a_i b_i\right)^2.
>> $$
>>
>> Поэтому
>>
>> $$
>> S=
>> 2\left[
>> \left(\sum_{i=1}^{n}a_i^2\right)
>> \left(\sum_{i=1}^{n}b_i^2\right)
>> -
>> \left(\sum_{i=1}^{n}a_i b_i\right)^2
>> \right].
>> $$
>>
>> Из $S\ge0$ делим на $2$ и переносим квадрат суммы вправо:
>>
>> $$
>> \left(\sum_{i=1}^{n}a_i b_i\right)^2
>> \le
>> \left(\sum_{i=1}^{n}a_i^2\right)
>> \left(\sum_{i=1}^{n}b_i^2\right).
>> $$
>>
>> Извлечение квадратного корня даёт форму с модулем.
>>
>> Для равенства необходимо и достаточно, чтобы
>>
>> $$
>> S=0
>> \iff
>> a_i b_k-a_k b_i=0
>> \quad\text{для всех }i,k.
>> $$
>>
>> Если $b\ne0$, выбираем $j$ с $b_j\ne0$. При $k=j$ получаем
>>
>> $$
>> a_i=\frac{a_j}{b_j}b_i
>> \quad\text{для всех }i,
>> $$
>>
>> то есть $a=\lambda b$. Обратно, при $a=\lambda b$ каждое слагаемое в $S$ равно нулю.

> [!note]- Неравенство Коши-Буняковского для скалярного произведения ✓
>
>> [!abstract] Дано
>> $X$ — линейное пространство над
>>
>> $$
>> \mathbb K\in\{\mathbb R,\mathbb C\}
>> $$
>>
>> со скалярным произведением; $x,y\in X$.
>
>> [!success] Тогда
>> $$
>> \boxed{|\langle x,y\rangle|^2
>> \le
>> \langle x,x\rangle\langle y,y\rangle.}
>> $$
>
>> [!example] Маршрут доказательства
>> При $y=0$ обе части равны нулю. Пусть $y\ne0$; тогда
>> $\langle y,y\rangle>0$.
>>
>> Выбираем $\lambda$ так, чтобы $x-\lambda y\perp y$:
>>
>> $$
>> \langle x-\lambda y,y\rangle=0
>> \quad\Longrightarrow\quad
>> \lambda=\frac{\langle x,y\rangle}{\langle y,y\rangle}.
>> $$
>>
>> По положительной определённости
>>
>> $$
>> \begin{aligned}
>> 0
>> &\le\langle x-\lambda y,x-\lambda y\rangle\\
>> &=\langle x,x\rangle
>> -\lambda\langle y,x\rangle
>> -\overline\lambda\langle x,y\rangle
>> +|\lambda|^2\langle y,y\rangle.
>> \end{aligned}
>> $$
>>
>> По эрмитовой симметрии и выбору $\lambda$ каждый из трёх членов
>> с $\lambda$ равен
>>
>> $$
>> \frac{|\langle x,y\rangle|^2}{\langle y,y\rangle}.
>> $$
>>
>> Поэтому
>>
>> $$
>> 0\le
>> \langle x,x\rangle
>> -\frac{|\langle x,y\rangle|^2}{\langle y,y\rangle}.
>> $$
>>
>> Домножаем на $\langle y,y\rangle>0$ и получаем требуемое
>> неравенство. $\square$

> [!note]- Непрерывность скалярного произведения, лемма о покоординатной сходимости ✓
>
>> [!abstract] Дано
>> **1. Непрерывность.** Пусть $X$ — линейное пространство со
>> скалярным произведением и порождённой им нормой
>>
>> $$
>> \|x\|=\sqrt{\langle x,x\rangle}.
>> $$
>>
>> Пусть
>>
>> $$
>> x_n\to x_0,
>> \qquad
>> y_n\to y_0.
>> $$
>>
>> **2. Покоординатная сходимость.** Пусть в $\mathbb R^m$
>>
>> $$
>> x^n=(x_1^n,\ldots,x_m^n),
>> \qquad
>> x^0=(x_1^0,\ldots,x_m^0),
>> $$
>>
>> и используется евклидова норма
>>
>> $$
>> \|x\|=\sqrt{x_1^2+\ldots+x_m^2}.
>> $$
>
>> [!success] Тогда
>> **1. Скалярное произведение непрерывно:**
>>
>> $$
>> \langle x_n,y_n\rangle
>> \to
>> \langle x_0,y_0\rangle.
>> $$
>>
>> **2. Сходимость векторов равносильна покоординатной сходимости:**
>>
>> $$
>> x^n\to x^0
>> \iff
>> x_k^n\to x_k^0
>> \quad\forall k=1,\ldots,m.
>> $$
>
>> [!example] Короткое доказательство
>> **1. Непрерывность скалярного произведения.**
>>
>> Положим
>>
>> $$
>> \Delta_n=
>> \langle x_n,y_n\rangle-\langle x_0,y_0\rangle.
>> $$
>>
>> Добавляя и вычитая $\langle x_n,y_0\rangle$, получаем
>>
>> $$
>> \Delta_n
>> =
>> \langle x_n,y_n-y_0\rangle
>> +
>> \langle x_n-x_0,y_0\rangle.
>> $$
>>
>> По неравенству треугольника и Коши — Буняковского
>>
>> $$
>> |\Delta_n|
>> \le
>> \|x_n\|\,\|y_n-y_0\|
>> +
>> \|x_n-x_0\|\,\|y_0\|.
>> $$
>>
>> По теореме об ограниченности сходящейся последовательности
>> существует $M>0$, такое что
>>
>> $$
>> \forall n\in\mathbb N:\quad \|x_n\|\le M.
>> $$
>>
>> Поэтому
>>
>> $$
>> |\Delta_n|
>> \le
>> M\|y_n-y_0\|
>> +
>> \|y_0\|\,\|x_n-x_0\|
>> \to0.
>> $$
>>
>> Следовательно,
>>
>> $$
>> \langle x_n,y_n\rangle
>> \to
>> \langle x_0,y_0\rangle.
>> $$
>>
>> **2. Покоординатная сходимость.**
>>
>> **Направление $\Rightarrow$.** Дано
>>
>> $$
>> x^n\to x^0.
>> $$
>>
>> Нужно доказать
>>
>> $$
>> x_k^n\to x_k^0
>> \quad\forall k=1,\ldots,m.
>> $$
>>
>> Зафиксируем произвольную координату
>> $k\in\{1,\ldots,m\}$. Поскольку все слагаемые суммы
>> неотрицательны,
>>
>> $$
>> (x_k^n-x_k^0)^2
>> \le
>> \sum_{i=1}^{m}(x_i^n-x_i^0)^2.
>> $$
>>
>> Поэтому
>>
>> $$
>> |x_k^n-x_k^0|
>> \le
>> \|x^n-x^0\|.
>> $$
>>
>> Из $x^n\to x^0$ следует
>>
>> $$
>> \|x^n-x^0\|\to0.
>> $$
>>
>> Поэтому
>>
>> $$
>> 0
>> \le
>> |x_k^n-x_k^0|
>> \le
>> \|x^n-x^0\|
>> \to0.
>> $$
>>
>> По теореме о двух городовых
>>
>> $$
>> |x_k^n-x_k^0|\to0.
>> $$
>>
>> То есть
>>
>> $$
>> x_k^n\to x_k^0.
>> $$
>>
>> Координата $k$ была выбрана произвольно, поэтому вывод верен для
>> всех $k=1,\ldots,m$.
>>
>> **Направление $\Leftarrow$.** Дано
>>
>> $$
>> x_k^n\to x_k^0
>> \quad\forall k=1,\ldots,m.
>> $$
>>
>> Нужно доказать
>>
>> $$
>> x^n\to x^0,
>> $$
>>
>> то есть для произвольного $\varepsilon>0$ найти номер $N$, после
>> которого
>>
>> $$
>> \|x^n-x^0\|<\varepsilon.
>> $$
>>
>> Если для некоторого $\delta>0$ одновременно выполняется
>>
>> $$
>> |x_k^n-x_k^0|<\delta,
>> \qquad k=1,\ldots,m,
>> $$
>>
>> то
>>
>> $$
>> \begin{aligned}
>> \|x^n-x^0\|
>> &=
>> \sqrt{\sum_{k=1}^{m}(x_k^n-x_k^0)^2}
>> \\
>> &<
>> \sqrt{\sum_{k=1}^{m}\delta^2}
>> =
>> \sqrt m\,\delta.
>> \end{aligned}
>> $$
>>
>> Чтобы получить требуемую оценку
>> $\|x^n-x^0\|<\varepsilon$, выбираем
>>
>> $$
>> \delta=\frac{\varepsilon}{\sqrt m}.
>> $$
>>
>> По определению предела каждой координаты существуют номера
>> $N_1,\ldots,N_m$, такие что
>>
>> $$
>> \forall n\ge N_k:\quad
>> |x_k^n-x_k^0|<\delta,
>> \qquad k=1,\ldots,m.
>> $$
>>
>> Берём общий номер
>>
>> $$
>> N=\max\{N_1,\ldots,N_m\}.
>> $$
>>
>> Тогда для каждого $n\ge N$ все координатные оценки выполняются
>> одновременно. Следовательно,
>>
>> $$
>> \|x^n-x^0\|
>> <
>> \sqrt m\,\delta
>> =
>> \varepsilon.
>> $$
>>
>> По определению сходимости
>>
>> $$
>> x^n\to x^0.
>> $$

## Бесконечные пределы и топология

> [!danger]- 🔴 Арифметические свойства пределов последовательностей в  $\overline{\mathbb R}$ ✓
>
>> [!abstract] 1. Дано
>> $(x_n)$ и $(y_n)$ — вещественные последовательности,
>>
>> $$
>> x_n\to a\in\mathbb R,
>> \qquad
>> y_n\to+\infty.
>> $$
>
>> [!success] 1. Тогда
>> $$
>> x_n+y_n\to+\infty.
>> $$
>
>> [!example] 1. Короткое доказательство: конечный предел $+$ $+\infty$
>> Пусть $E\in\mathbb R$ произвольно. Тогда
>>
>> **Оценка $x_n$.** При $\varepsilon=1$:
>>
>> $$
>> x_n\to a
>> \Rightarrow
>> \exists N_1\in\mathbb N\ \forall n\in\mathbb N:
>> \quad n>N_1\Rightarrow x_n>a-1.
>> $$
>>
>> **Уровень для $y_n$.** Положим $B=E-a+1$:
>>
>> $$
>> y_n\to+\infty
>> \Rightarrow
>> \exists N_2\in\mathbb N\ \forall n\in\mathbb N:
>> \quad n>N_2\Rightarrow y_n>E-a+1.
>> $$
>>
>> **Общий хвост.**
>>
>> $$
>> N=\max\{N_1,N_2\},\quad n>N
>> \Rightarrow
>> x_n+y_n>(a-1)+(E-a+1)=E.
>> $$
>>
>> **Закрытие определения.**
>>
>> $$
>> \forall E\in\mathbb R\ \exists N\in\mathbb N\
>> \forall n\in\mathbb N:
>> \quad n>N\Rightarrow x_n+y_n>E,
>> $$
>>
>> то есть $x_n+y_n\to+\infty$.
>
>> [!abstract] 2. Дано
>> $(x_n)$ и $(y_n)$ — вещественные последовательности,
>>
>> $$
>> x_n\to a\in\mathbb R,
>> \qquad
>> y_n\to+\infty.
>> $$
>
>> [!success] 2. Тогда
>> $$
>> \frac{x_n}{y_n}\to0.
>> $$
>
>> [!example] 2. Короткое доказательство: конечный предел, делённый на $+\infty$
>> **Ограниченность $x_n$.**
>>
>> По теореме об ограниченности сходящейся последовательности
>>
>> $$
>> \exists M>0\ \forall n\in\mathbb N:
>> \quad |x_n|\le M.
>> $$
>>
>> **Уровень для $y_n$.**
>>
>> Пусть $\varepsilon>0$ произвольно. При $y_n>0$:
>>
>> $$
>> \left|\frac{x_n}{y_n}\right|
>> \le\frac{M}{y_n}<\varepsilon
>> \quad\Longleftarrow\quad
>> y_n>\frac{M}{\varepsilon}.
>> $$
>>
>> Для $B=M/\varepsilon>0$:
>>
>> $$
>> y_n\to+\infty
>> \Rightarrow
>> \exists N_y\in\mathbb N\ \forall n\in\mathbb N:
>> \quad n>N_y\Rightarrow
>> y_n>\frac{M}{\varepsilon}>0.
>> $$
>>
>> **Оценка дроби.**
>>
>> $$
>> n>N_y
>> \Rightarrow y_n\ne0,
>> \qquad
>> \left|\frac{x_n}{y_n}\right|
>> \le\frac{M}{y_n}
>> <\frac{M}{M/\varepsilon}
>> =\varepsilon.
>> $$
>>
>> **Закрытие определения.**
>>
>> $$
>> \forall\varepsilon>0\ \exists N_y\in\mathbb N\
>> \forall n\in\mathbb N:
>> \quad n>N_y\Rightarrow
>> \left|\frac{x_n}{y_n}\right|<\varepsilon,
>> $$
>>
>> то есть $\dfrac{x_n}{y_n}\to0$.
>
>> [!abstract] 3. Дано
>> $(x_n)$ и $(y_n)$ — вещественные последовательности,
>>
>> $$
>> x_n\to+\infty,
>> \qquad
>> y_n\to a>0.
>> $$
>
>> [!success] 3. Тогда
>> $$
>> x_ny_n\to+\infty.
>> $$
>
>> [!example] 3. Короткое доказательство: $+\infty$ на положительный конечный предел
>> Пусть $E>0$ произвольно.
>>
>> **Нижняя оценка $y_n$.** При $\varepsilon=a/2>0$:
>>
>> $$
>> y_n\to a
>> \Rightarrow
>> \exists N_1\in\mathbb N\ \forall n\in\mathbb N:
>> \quad n>N_1\Rightarrow y_n>\frac a2>0.
>> $$
>>
>> **Уровень для $x_n$.** Для получения $x_ny_n>E$ требуется
>> $x_n>2E/a$. Поэтому
>>
>> $$
>> x_n\to+\infty
>> \Rightarrow
>> \exists N_2\in\mathbb N\ \forall n\in\mathbb N:
>> \quad n>N_2\Rightarrow x_n>\frac{2E}{a}.
>> $$
>>
>> **Общий хвост.**
>>
>> $$
>> N=\max\{N_1,N_2\},
>> \quad n>N
>> \Rightarrow
>> x_ny_n>\frac{2E}{a}\cdot\frac a2=E.
>> $$
>>
>> **Закрытие определения.**
>>
>> $$
>> \forall E>0\ \exists N\in\mathbb N\
>> \forall n\in\mathbb N:
>> \quad n>N\Rightarrow x_ny_n>E,
>> $$
>>
>> то есть $x_ny_n\to+\infty$.
>
>> [!example]- Формы, в которых общего заключения нет
>> $$
>> \infty-\infty,
>> \qquad
>> 0\cdot\infty,
>> \qquad
>> \frac{\infty}{\infty},
>> \qquad
>> \frac00.
>> $$

> [!danger]- 🔴 Теорема о свойствах открытых множеств ✓
>> [!abstract] Дано
>> $(X,\rho)$ — метрическое пространство,
>>
>> $$
>> \{G_\alpha\}_{\alpha\in A}
>> $$
>>
>> — произвольное семейство открытых в $X$ множеств;
>>
>> $$
>> G_1,\ldots,G_n,
>> \qquad
>> n\in\mathbb N,
>> \qquad
>> n\ge1,
>> $$
>>
>> — конечный набор открытых в $X$ множеств.
>
>> [!success] Тогда
>> **1.** Произвольное объединение открыто:
>>
>> $$
>> \bigcup_{\alpha\in A}G_\alpha
>> \quad\text{открыто в }X.
>> $$
>>
>> **2.** Конечное пересечение открыто:
>>
>> $$
>> \bigcap_{i=1}^{n}G_i
>> \quad\text{открыто в }X.
>> $$
>
>> [!example] Короткое доказательство
>> **1. Произвольное объединение.** Зафиксируем
>>
>> $$
>> x\in\bigcup_{\alpha\in A}G_\alpha.
>> $$
>>
>> Тогда
>>
>> $$
>> \exists\alpha_0\in A:
>> \quad
>> x\in G_{\alpha_0}.
>> $$
>>
>> По определению открытого множества
>>
>> $$
>> \exists r>0:
>> \quad
>> B_r(x)\subset G_{\alpha_0}
>> \subset\bigcup_{\alpha\in A}G_\alpha.
>> $$
>>
>> Закрываем кванторы:
>>
>> $$
>> \forall x\in\bigcup_{\alpha\in A}G_\alpha\ 
>> \exists r>0:
>> \quad
>> B_r(x)\subset\bigcup_{\alpha\in A}G_\alpha.
>> $$
>>
>> Следовательно, объединение открыто. При пустом объединении условие
>> выполнено автоматически.
>>
>> **2. Конечное пересечение.** Зафиксируем
>>
>> $$
>> x\in\bigcap_{i=1}^{n}G_i.
>> $$
>>
>> Тогда
>>
>> $$
>> \forall i\in\{1,\ldots,n\}:
>> \quad
>> x\in G_i.
>> $$
>>
>> По определению открытого множества
>>
>> $$
>> \forall i\in\{1,\ldots,n\}\ 
>> \exists r_i>0:
>> \quad
>> B_{r_i}(x)\subset G_i.
>> $$
>>
>> Радиусов конечное число, поэтому
>>
>> $$
>> r=\min\{r_1,\ldots,r_n\}>0.
>> $$
>>
>> Для каждого $i\in\{1,\ldots,n\}$:
>>
>> $$
>> r\le r_i
>> \quad\Longrightarrow\quad
>> B_r(x)\subset B_{r_i}(x)\subset G_i
>> \quad\Longrightarrow\quad
>> B_r(x)\subset\bigcap_{i=1}^{n}G_i.
>> $$
>>
>> Закрываем кванторы:
>>
>> $$
>> \forall x\in\bigcap_{i=1}^{n}G_i\ 
>> \exists r>0:
>> \quad
>> B_r(x)\subset\bigcap_{i=1}^{n}G_i.
>> $$
>>
>> Следовательно, конечное пересечение открыто.
>
>> [!danger]- Контрпример: конечность существенна
>> $$
>> \forall n\in\mathbb N:
>> \quad
>> G_n=\left(-\frac1n,\frac1n\right)
>> \quad\text{открыто}.
>> $$
>>
>> По свойству Архимеда
>>
>> $$
>> \bigl[\forall n\in\mathbb N: 0\in G_n\bigr],
>> \qquad
>> \bigl[\forall x\in\mathbb R\setminus\{0\}\ 
>> \exists n\in\mathbb N:
>> \frac1n<|x|\ \land\ x\notin G_n\bigr].
>> $$
>>
>> Поэтому
>>
>> $$
>> \bigcap_{n=1}^{\infty}G_n=\{0\}.
>> $$
>>
>> Для любого $r>0$:
>>
>> $$
>> \frac r2\in B_r(0),
>> \qquad
>> \frac r2\notin\{0\}
>> \quad\Longrightarrow\quad
>> B_r(0)\not\subset\{0\}.
>> $$
>>
>> Следовательно, $\{0\}$ не открыто, и бесконечное пересечение
>> открытых множеств не обязано быть открытым.
>

> [!note]- Теорема о связи открытых и замкнутых множеств, свойства замкнутых множеств ✓
>
>> [!abstract] Дано
>> $(X,\rho)$ — метрическое пространство,
>>
>> $$
>> D\subseteq X.
>> $$
>>
>> Для свойств замкнутых множеств:
>>
>> $$
>> \forall\alpha\in A:
>> \quad
>> F_\alpha\text{ замкнуто в }X,
>> $$
>>
>> либо
>>
>> $$
>> \forall i\in\{1,\ldots,n\}:
>> \quad
>> F_i\text{ замкнуто в }X.
>> $$
>
>> [!success] Тогда
>>
>> $$
>> D\text{ замкнуто в }X
>> \iff
>> X\setminus D\text{ открыто в }X.
>> $$
>>
>> $$
>> \bigcap_{\alpha\in A}F_\alpha
>> \text{ замкнуто в }X,
>> \qquad
>> \bigcup_{i=1}^{n}F_i
>> \text{ замкнуто в }X.
>> $$
>
>> [!example] Короткое доказательство
>> **1. $D$ замкнуто $\Rightarrow X\setminus D$ открыто.**
>>
>> Зафиксируем
>>
>> $$
>> x\in X\setminus D.
>> $$
>>
>> Предположим, что $x$ не внутренняя точка $X\setminus D$:
>>
>> $$
>> \forall r>0:
>> \quad
>> B_r(x)\not\subseteq X\setminus D
>> \Longrightarrow
>> \exists y\in B_r(x):
>> \quad
>> y\in D.
>> $$
>>
>> Так как $x\notin D$, то $y\ne x$; значит,
>>
>> $$
>> \forall r>0:
>> \quad
>> \dot B_r(x)\cap D\ne\varnothing.
>> $$
>>
>> То есть $x$ — предельная точка $D$. Из замкнутости $D$ следует
>> $x\in D$ — противоречие. Поэтому
>>
>> $$
>> \forall x\in X\setminus D\ \exists r>0:
>> \quad
>> B_r(x)\subseteq X\setminus D.
>> $$
>>
>> **2. $X\setminus D$ открыто $\Rightarrow D$ замкнуто.**
>>
>> Зафиксируем произвольную предельную точку $x$ множества $D$ и
>> предположим $x\notin D$. Тогда
>>
>> $$
>> x\in X\setminus D
>> \Longrightarrow
>> \exists r>0:
>> \quad
>> B_r(x)\subseteq X\setminus D.
>> $$
>>
>> $$
>> \dot B_r(x)\subseteq B_r(x),
>> \qquad
>> B_r(x)\;⊆\;X\setminus D
>> \Longrightarrow
>> \dot B_r(x)\cap D=\varnothing.
>> $$
>>
>> Противоречие с предельностью $x$. Значит, каждая предельная точка
>> принадлежит $D$, то есть $D$ замкнуто.
>>
>> **3. Свойства замкнутых множеств.**
>>
>> $$
>> \forall\alpha\in A:
>> \quad
>> F_\alpha\text{ замкнуто}
>> \Longrightarrow
>> X\setminus F_\alpha\text{ открыто}.
>> $$
>>
>> $$
>> X\setminus\bigcap_{\alpha\in A}F_\alpha
>> =
>> \bigcup_{\alpha\in A}(X\setminus F_\alpha)
>> \text{ открыто}
>> \Longrightarrow
>> \bigcap_{\alpha\in A}F_\alpha
>> \text{ замкнуто}.
>> $$
>>
>> $$
>> X\setminus\bigcup_{i=1}^{n}F_i
>> =
>> \bigcap_{i=1}^{n}(X\setminus F_i)
>> \text{ открыто}
>> \Longrightarrow
>> \bigcup_{i=1}^{n}F_i
>> \text{ замкнуто}.
>> $$
>>
>> Во второй строке используется конечность: конечное пересечение
>> открытых множеств открыто.

> [!note]- Теорема об открытых и замкнутых множествах в пространстве и в подпространстве ✓
>
>> [!abstract] Дано
>> $(X,\rho)$ — метрическое пространство,
>>
>> $$
>> Y\subseteq X,
>> \qquad
>> D\subseteq Y,
>> \qquad
>> \rho_Y=\rho|_{Y\times Y}.
>> $$
>>
>> Для $a\in Y$, $r>0$:
>>
>> $$
>> B_r^Y(a)=B_r^X(a)\cap Y.
>> $$
>
>> [!success] Тогда
>>
>> $$
>> D\text{ открыто в }Y
>> \iff
>> \exists G\subseteq X:
>> \quad
>> G\text{ открыто в }X,
>> \qquad
>> D=G\cap Y.
>> $$
>>
>> $$
>> D\text{ замкнуто в }Y
>> \iff
>> \exists F\subseteq X:
>> \quad
>> F\text{ замкнуто в }X,
>> \qquad
>> D=F\cap Y.
>> $$
>
>> [!example] Короткое доказательство
>> **1. Открытость, $\Rightarrow$.**
>>
>> $$
>> D\text{ открыто в }Y
>> \Longrightarrow
>> \forall a\in D\ \exists r_a>0:
>> \quad
>> B_{r_a}^Y(a)\subseteq D.
>> $$
>>
>> $$
>> G=\bigcup_{a\in D}B_{r_a}^X(a)
>> \text{ открыто в }X.
>> $$
>>
>> $$
>> \begin{aligned}
>> G\cap Y
>> &=\bigcup_{a\in D}\left(B_{r_a}^X(a)\cap Y\right)\\
>> &=\bigcup_{a\in D}B_{r_a}^Y(a).
>> \end{aligned}
>> $$
>>
>> $$
>> \forall a\in D:
>> \quad
>> B_{r_a}^Y(a)\subseteq D
>> \Longrightarrow
>> G\cap Y\subseteq D,
>> $$
>>
>> $$
>> \forall a\in D:
>> \quad
>> a\in B_{r_a}^Y(a)\subseteq G\cap Y
>> \Longrightarrow
>> D\subseteq G\cap Y.
>> $$
>>
>> $$
>> \Longrightarrow
>> D=G\cap Y.
>> $$
>>
>> **2. Открытость, $\Leftarrow$.**
>>
>> $$
>> D=G\cap Y,
>> \qquad
>> G\text{ открыто в }X.
>> $$
>>
>> $$
>> \forall a\in D:
>> \quad
>> a\in G
>> \Longrightarrow
>> \exists r>0:
>> \quad
>> B_r^Y(a)
>> =B_r^X(a)\cap Y
>> \subseteq G\cap Y
>> =D.
>> $$
>>
>> $$
>> \Longrightarrow
>> D\text{ открыто в }Y.
>> $$
>>
>> **3. Замкнутость, $\Rightarrow$.**
>>
>> $$
>> D\text{ замкнуто в }Y
>> \Longrightarrow
>> Y\setminus D\text{ открыто в }Y.
>> $$
>>
>> По пункту 1:
>>
>> $$
>> Y\setminus D=G\cap Y,
>> \qquad
>> G\text{ открыто в }X.
>> $$
>>
>> $$
>> F=X\setminus G
>> \text{ замкнуто в }X,
>> $$
>>
>> $$
>> \begin{aligned}
>> D
>> &=Y\setminus(Y\setminus D)\\
>> &=Y\setminus(G\cap Y)\\
>> &=Y\cap(X\setminus G)
>> =F\cap Y.
>> \end{aligned}
>> $$
>>
>> **4. Замкнутость, $\Leftarrow$.**
>>
>> $$
>> D=F\cap Y,
>> \qquad
>> F\text{ замкнуто в }X.
>> $$
>>
>> $$
>> G=X\setminus F
>> \text{ открыто в }X,
>> $$
>>
>> $$
>> Y\setminus D
>> =Y\setminus(F\cap Y)
>> =Y\cap(X\setminus F)
>> =G\cap Y.
>> $$
>>
>> По пункту 2:
>>
>> $$
>> Y\setminus D\text{ открыто в }Y
>> \Longrightarrow
>> D\text{ замкнуто в }Y.
>> $$

> [!note]- Эквивалентность определений предела: на яз. откр. множеств и на яз.окрестностей ✓
>
>> [!abstract] Дано
>> $(X,\rho_X)$ и $(Y,\rho_Y)$ — метрические пространства,
>>
>> $$
>> D\subseteq X,
>> \quad
>> f:D\to Y,
>> \quad
>> a\text{ — предельная точка }D,
>> \quad
>> L\in Y.
>> $$
>>
>> **Определение 2:**
>>
>> $$
>> \forall U(L)\ \exists V(a):
>> \quad
>> f\bigl((D\cap V(a))\setminus\{a\}\bigr)
>> \subseteq U(L).
>> $$
>>
>> **Определение 4:**
>>
>> $$
>> \begin{gathered}
>> \forall G\subseteq Y:\quad G\text{ открыто},\ L\in G,\\
>> \exists H\subseteq X:\quad H\text{ открыто},\ a\in H,\\
>> f\bigl((D\cap H)\setminus\{a\}\bigr)\subseteq G.
>> \end{gathered}
>> $$
>
>> [!success] Тогда
>> $$
>> \boxed{(2)\Longleftrightarrow(4).}
>> $$
>
>> [!example] Короткое доказательство
>> **$(2)\Rightarrow(4)$.** Берём произвольное открытое $G\ni L$. Существует шар $U(L)\subseteq G$. По определению 2 существует шар $V(a)$, для которого
>>
>> $$
>> f\bigl((D\cap V(a))\setminus\{a\}\bigr)
>> \subseteq U(L)\subseteq G.
>> $$
>>
>> Полагаем $H=V(a)$ и получаем определение 4.
>>
>> **$(4)\Rightarrow(2)$.** Берём произвольный шар $U(L)$ и применяем определение 4 к $G=U(L)$. Получаем открытое $H\ni a$. Выбираем шар $V(a)\subseteq H$. Тогда
>>
>> $$
>> (D\cap V(a))\setminus\{a\}
>> \subseteq
>> (D\cap H)\setminus\{a\},
>> $$
>>
>> поэтому
>>
>> $$
>> f\bigl((D\cap V(a))\setminus\{a\}\bigr)
>> \subseteq U(L).
>> $$
>>
>> Это определение 2. $\square$

> [!note]- Эквивалентность определений предела Гейне и Коши ✓
>
>> [!abstract] Дано
>> $(X,\rho_X)$ и $(Y,\rho_Y)$ — метрические пространства,
>>
>> $$
>> D\subseteq X,
>> \qquad
>> f:D\to Y,
>> \qquad
>> L\in Y.
>> $$
>>
>> $a$ — предельная точка множества $D$:
>>
>> $$
>> a\in D'.
>> $$
>
>> [!success] Тогда
>> Определения предела по Коши и по Гейне эквивалентны:
>>
>> $$
>> \left[
>> \forall\varepsilon>0\ \exists\delta>0\ \forall x\in D:
>> \quad
>> 0<\rho_X(x,a)<\delta
>> \Longrightarrow
>> \rho_Y(f(x),L)<\varepsilon
>> \right]
>> $$
>>
>> $$
>> \Updownarrow
>> $$
>>
>> $$
>> \left[
>> \forall(x_n):
>> \quad
>> \left(
>> \forall n\in\mathbb N:\ x_n\in D\setminus\{a\},
>> \quad
>> x_n\to a
>> \right)
>> \Longrightarrow
>> f(x_n)\to L
>> \right].
>> $$
>
>> [!example] Короткое доказательство
>> **1. Коши $\Longrightarrow$ Гейне.**
>>
>> Зафиксируем произвольную последовательность
>>
>> $$
>> \forall n\in\mathbb N:\ x_n\in D\setminus\{a\},
>> \qquad
>> x_n\to a,
>> $$
>>
>> и произвольное $\varepsilon>0$. По условию Коши
>>
>> $$
>> \exists\delta>0\ \forall x\in D:
>> \quad
>> 0<\rho_X(x,a)<\delta
>> \Longrightarrow
>> \rho_Y(f(x),L)<\varepsilon.
>> $$
>>
>> Из $x_n\to a$ для выбранного $\delta>0$:
>>
>> $$
>> \exists N\in\mathbb N\ \forall n\in\mathbb N:
>> \quad
>> n\ge N
>> \Longrightarrow
>> \rho_X(x_n,a)<\delta.
>> $$
>>
>> Кроме того,
>>
>> $$
>> \forall n\in\mathbb N:
>> \quad
>> x_n\in D\setminus\{a\}
>> \Longrightarrow
>> \left[
>> x_n\in D
>> \quad\land\quad
>> \rho_X(x_n,a)>0
>> \right].
>> $$
>>
>> $$
>> \forall n\in\mathbb N:
>> \quad
>> n\ge N
>> \Longrightarrow
>> 0<\rho_X(x_n,a)<\delta
>> \Longrightarrow
>> \rho_Y(f(x_n),L)<\varepsilon.
>> $$
>>
>> Следовательно,
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\ \forall n\in\mathbb N:
>> \quad
>> n\ge N
>> \Longrightarrow
>> \rho_Y(f(x_n),L)<\varepsilon,
>> $$
>>
>> то есть $f(x_n)\to L$.
>>
>> **2. Гейне $\Longrightarrow$ Коши.**
>>
>> Предположим, что условие Коши неверно:
>>
>> $$
>> \exists\varepsilon_0>0\ \forall\delta>0\ \exists x\in D:
>> \quad
>> 0<\rho_X(x,a)<\delta,
>> \qquad
>> \rho_Y(f(x),L)\ge\varepsilon_0.
>> $$
>>
>> Для каждого $n\in\mathbb N$ положим $\delta_n=1/n$ и выберем
>> соответствующую точку $x_n\in D$. Тогда
>>
>> $$
>> \forall n\in\mathbb N:
>> \quad
>> 0<\rho_X(x_n,a)<\frac1n,
>> \qquad
>> \rho_Y(f(x_n),L)\ge\varepsilon_0.
>> $$
>>
>> По теореме о двух городовых
>>
>> $$
>> 0\le\rho_X(x_n,a)<\frac1n
>> \Longrightarrow
>> x_n\to a.
>> $$
>>
>> Кроме того, $x_n\in D\setminus\{a\}$, поэтому по условию Гейне
>>
>> $$
>> f(x_n)\to L
>> \Longrightarrow
>> \exists N\in\mathbb N\ \forall n\in\mathbb N:
>> \quad
>> n\ge N
>> \Longrightarrow
>> \rho_Y(f(x_n),L)<\varepsilon_0.
>> $$
>>
>> Это противоречит
>>
>> $$
>> \forall n\in\mathbb N:
>> \quad
>> \rho_Y(f(x_n),L)\ge\varepsilon_0.
>> $$
>>
>> Следовательно, условие Коши выполнено.

> [!note]- Единственность предела, локальная ограниченность отображения, имеющего предел, теорема о стабилизации знака ✓
>
>> [!abstract] Единственность предела — дано
>> $(X,\rho_X)$ и $(Y,\rho_Y)$ — метрические пространства,
>>
>> $$
>> D\subseteq X,
>> \quad f:D\to Y,
>> \quad a\text{ — предельная точка }D,
>> \quad
>> \lim_{x\to a}f(x)=L,
>> \quad
>> \lim_{x\to a}f(x)=M.
>> $$
>
>> [!success] Единственность предела — тогда
>> $$L=M.$$
>
>> [!example] Единственность предела — короткое доказательство
>> Так как $a$ — предельная точка $D$, существует последовательность
>>
>> $$
>> x_n\in D\setminus\{a\},
>> \qquad
>> x_n\to a.
>> $$
>>
>> По теореме Гейне
>>
>> $$
>> f(x_n)\to L,
>> \qquad
>> f(x_n)\to M.
>> $$
>>
>> Одна последовательность имеет два предела. По единственности предела последовательности
>>
>> $$
>> L=M.
>> $$
>
>> [!abstract] Локальная ограниченность — дано
>> $(X,\rho_X)$ и $(Y,\rho_Y)$ — метрические пространства,
>>
>> $$
>> D\subseteq X,
>> \quad f:D\to Y,
>> \quad a\text{ — предельная точка }D,
>> \quad
>> \lim_{x\to a}f(x)=L\in Y.
>> $$
>
>> [!success] Локальная ограниченность — тогда
>> Существуют окрестность $U(a)$ и $R>0$, для которых
>>
>> $$
>> \forall x\in D\cap U(a):
>> \quad
>> \rho_Y(f(x),L)<R.
>> $$
>
>> [!example] Локальная ограниченность — короткое доказательство
>> Выбираем $V(L)=B_1^Y(L)$. По определению предела существует $U(a)$, такая что
>>
>> $$
>> \forall x\in(D\cap U(a))\setminus\{a\}:
>> \quad
>> \rho_Y(f(x),L)<1.
>> $$
>>
>> Если $a\notin D$, шар $B_1^Y(L)$ ограничивает все значения на $D\cap U(a)$. Если $a\in D$, берём
>>
>> $$
>> R=1+\rho_Y(f(a),L).
>> $$
>>
>> Тогда $R\ge1$: для $x\ne a$ имеем $\rho_Y(f(x),L)<1\le R$, а для $x=a$ имеем $\rho_Y(f(a),L)<R$. В обоих случаях
>>
>> $$
>> \forall x\in D\cap U(a):
>> \quad
>> \rho_Y(f(x),L)<R.
>> $$
>
>> [!abstract] Стабилизация знака — дано
>> $(X,\rho_X)$ и $(Y,\rho_Y)$ — метрические пространства,
>>
>> $$
>> D\subseteq X,
>> \quad f:D\to Y,
>> \quad a\text{ — предельная точка }D,
>> \quad
>> \lim_{x\to a}f(x)=L,
>> \quad L\ne M.
>> $$
>
>> [!success] Стабилизация знака — тогда
>> $$
>> \exists U(a)\ \forall x\in(D\cap U(a))\setminus\{a\}:
>> \quad
>> f(x)\ne M.
>> $$
>
>> [!example] Стабилизация знака — короткое доказательство
>> Берём
>>
>> $$
>> r=\frac{\rho_Y(L,M)}2>0.
>> $$
>>
>> В шар $B_r^Y(L)$ входят точки на расстоянии меньше $r$ от $L$. Но $\rho_Y(L,M)=2r>r$, поэтому $M\notin B_r^Y(L)$. По определению предела существует $U(a)$, такая что
>>
>> $$
>> \forall x\in(D\cap U(a))\setminus\{a\}:
>> \quad
>> f(x)\in B_r^Y(L),
>> $$
>>
>> поэтому $f(x)\ne M$.
>
>> [!tip] Следствие
>> Если $f:D\to\mathbb R$ и $\lim_{x\to a}f(x)=L>0$, то выбираем
>>
>> $$
>> B_{L/2}(L)=\left(\frac L2,\frac{3L}2\right)\subset(0,+\infty).
>> $$
>>
>> По определению предела существует $U(a)$, для которой
>>
>> $$
>> \forall x\in(D\cap U(a))\setminus\{a\}:
>> \quad
>> f(x)>\frac L2>0.
>> $$
>>
>> При $L<0$ аналогично получаем $f(x)<0$ в некоторой проколотой окрестности.

> [!note]- Арифметические свойства пределов отображений. Формулировка для R с чертой ✓
>
>> [!abstract] Дано
>> Для конечных пределов пусть $(X,\rho_X)$ — метрическое пространство, $(Y,\|\cdot\|)$ — нормированное векторное пространство,
>>
>> $$
>> D\subseteq X,
>> \quad
>> a\text{ — предельная точка }D,
>> \quad
>> f,g:D\to Y,
>> \quad
>> \lambda:D\to\mathbb R,
>> $$
>>
>> $$
>> f(x)\to L\in Y,
>> \qquad
>> g(x)\to M\in Y,
>> \qquad
>> \lambda(x)\to\alpha\in\mathbb R.
>> $$
>>
>> Для пределов в расширенной прямой рассматриваются числовые функции $f,g:D\to\mathbb R$ и пределы
>>
>> $$
>> f(x)\to L,
>> \qquad
>> g(x)\to M,
>> \qquad
>> L,M\in\overline{\mathbb R}.
>> $$
>>
>> Расширенная прямая рассматривается с метрикой через арктангенс, поэтому применима теорема Гейне. Обозначения $\sigma,\tau\in\{+1,-1\}$ задают знаки бесконечностей; $0^+$ и $0^-$ обозначают стремление к нулю с сохранением соответственно положительного и отрицательного знака.
>
>> [!success] Тогда
>> Для конечных пределов
>>
>> $$
>> f+g\to L+M,
>> \qquad
>> \lambda f\to\alpha L,
>> \qquad
>> \|f\|\to\|L\|.
>> $$
>>
>> Для числовых функций дополнительно
>>
>> $$
>> \frac fg\to\frac LM
>> \qquad(M\ne0).
>> $$
>
>> [!note]- Таблица допустимых операций с бесконечными пределами
>> Для $\sigma,\tau\in\{+1,-1\}$:
>>
>> | Условия | Результат |
>> | --- | --- |
>> | $L\in\mathbb R$, $g\to\sigma\infty$ | $f+g\to\sigma\infty$ |
>> | $f\to\sigma\infty$, $M\in\mathbb R$ | $f+g\to\sigma\infty$ |
>> | $f\to\sigma\infty$, $g\to\sigma\infty$ | $f+g\to\sigma\infty$ |
>> | $L\ne0$ конечен, $g\to\sigma\infty$ | $fg\to\operatorname{sgn}(L)\sigma\infty$ |
>> | $f\to\sigma\infty$, $M\ne0$ конечен | $fg\to\sigma\operatorname{sgn}(M)\infty$ |
>> | $f\to\sigma\infty$, $g\to\tau\infty$ | $fg\to\sigma\tau\infty$ |
>> | $L\in\mathbb R$, $g\to\sigma\infty$ | $f/g\to0$ |
>> | $f\to\sigma\infty$, $M\ne0$ конечен | $f/g\to\sigma\operatorname{sgn}(M)\infty$ |
>> | $L\ne0$ конечен, $g\to0^+$ | $f/g\to\operatorname{sgn}(L)\infty$ |
>> | $L\ne0$ конечен, $g\to0^-$ | $f/g\to-\operatorname{sgn}(L)\infty$ |
>> | $f\to\sigma\infty$, $g\to0^+$ | $f/g\to\sigma\infty$ |
>> | $f\to\sigma\infty$, $g\to0^-$ | $f/g\to-\sigma\infty$ |
>
>> [!example] Короткое доказательство
>> Докажем типовой случай:
>>
>> $$
>> f(x)\to L\in\mathbb R,
>> \qquad
>> g(x)\to+\infty.
>> $$
>>
>> Берём произвольную последовательность
>>
>> $$
>> x_n\in D\setminus\{a\},
>> \qquad
>> x_n\to a.
>> $$
>>
>> По Гейне
>>
>> $$
>> f(x_n)\to L,
>> \qquad
>> g(x_n)\to+\infty.
>> $$
>>
>> По арифметике пределов последовательностей в $\overline{\mathbb R}$
>>
>> $$
>> f(x_n)+g(x_n)\to+\infty.
>> $$
>>
>> Последовательность $(x_n)$ произвольна, поэтому по Гейне в обратную сторону
>>
>> $$
>> f(x)+g(x)\to+\infty.
>> $$
>>
>> Остальные допустимые свойства доказываются той же цепочкой с учётом знаков и определённости операции:
>>
>> $$
>> x_n\to a
>> \Longrightarrow
>> f(x_n),g(x_n)
>> \Longrightarrow
>> \text{арифметика последовательностей}
>> \Longrightarrow
>> \text{Гейне}.
>> $$
>
>> [!note]- Неопределённые формы
>> $$
>> \infty-\infty,
>> \qquad
>> 0\cdot\infty,
>> \qquad
>> \frac00,
>> \qquad
>> \frac\infty\infty.
>> $$
>>
>> Арифметическая теорема не определяет их результат. Например,
>>
>> $$
>> x-x=0,
>> \qquad
>> 2x-x\to+\infty
>> \quad(x\to+\infty),
>> $$
>>
>> $$
>> x\cdot\frac1x=1,
>> \qquad
>> x\cdot\frac1{\sqrt x}\to0
>> \quad(x\to0+),
>> $$
>>
>> $$
>> \frac{x}{x}=1,
>> \qquad
>> \frac{x^2}{x}\to0
>> \quad(x\to0+),
>> $$
>>
>> $$
>> \frac{x}{x}=1,
>> \qquad
>> \frac{x}{x^2}\to0
>> \quad(x\to+\infty).
>> $$

> [!question]- ❓ Теорема о пределе монотонной функции
> ⏳ Краткая версия пока не готова.
