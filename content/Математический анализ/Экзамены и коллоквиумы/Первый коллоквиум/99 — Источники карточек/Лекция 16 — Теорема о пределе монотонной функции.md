## Теорема о пределе монотонной функции

> [!abstract] Дано
> $D\subseteq\mathbb R$, $f:D\to\mathbb R$;
>
> $$
> D_-=D\cap(-\infty,a),
> $$
>
> $a$ — предельная точка $D_-$:
>
> $$
> \forall\delta>0\ \exists x\in D:\quad a-\delta<x<a.
> $$

> [!success] Тогда
> Если $f$ возрастает на $D$, то существует левосторонний предел в $\overline{\mathbb R}$ и
>
> $$
> \lim_{x\to a-0}f(x)=\sup_{x\in D_-}f(x).
> $$
>
> Если $f$ убывает на $D$, то существует левосторонний предел в $\overline{\mathbb R}$ и
>
> $$
> \lim_{x\to a-0}f(x)=\inf_{x\in D_-}f(x).
> $$

> [!example] Полное доказательство
> **1. Возрастающая функция: конечный супремум.** Пусть
>
> $$
> f\text{ возрастает на }D,
> \qquad
> A=\sup_{x\in D_-}f(x)\in\mathbb R.
> $$
>
> Пусть $\varepsilon>0$. По свойству супремума существует $x_1\in D_-$, для которого
>
> $$
> A-\varepsilon<f(x_1)\le A.
> $$
>
> Для каждого $x\in D$:
>
> $$
> x_1<x<a
> \Longrightarrow
> f(x_1)\le f(x)\le A.
> $$
>
> Следовательно,
>
> $$
> A-\varepsilon<f(x_1)\le f(x)\le A
> \Longrightarrow
> A-\varepsilon<f(x)<A+\varepsilon
> \Longleftrightarrow
> |f(x)-A|<\varepsilon.
> $$
>
> По определению левостороннего предела требуется подобрать $\delta>0$ так, чтобы
>
> $$
> \forall x\in D:\quad
> a-\delta<x<a
> \Longrightarrow
> |f(x)-A|<\varepsilon.
> $$
>
> Требуемая оценка уже доказана для всех $x\in D$, удовлетворяющих $x_1<x<a$. Поэтому достаточно совместить левые границы интервалов:
>
> $$
> a-\delta=x_1.
> $$
>
> Решая это равенство относительно $\delta$, получаем
>
> $$
> \delta=a-x_1>0,
> $$
>
> поскольку $x_1<a$. При таком выборе
>
> $$
> a-\delta<x<a
> \Longleftrightarrow
> x_1<x<a,
> $$
>
> поэтому
>
> $$
> \forall\varepsilon>0\ \exists\delta>0\ \forall x\in D\cap(a-\delta,a):
> \quad |f(x)-A|<\varepsilon.
> $$
>
> По определению левостороннего предела по Коши
>
> $$
> \lim_{x\to a-0}f(x)=A.
> $$
>
>> [!note]- Дополнение: возрастающая функция, супремум $+\infty$
>> Пусть
>>
>> $$
>> \sup_{x\in D_-}f(x)=+\infty.
>> $$
>>
>> Зафиксируем произвольное $M\in\mathbb R$. По неограниченности сверху
>>
>> $$
>> \exists x_1\in D_-:\quad f(x_1)>M.
>> $$
>>
>> Из возрастания:
>>
>> $$
>> \forall x\in D:\quad
>> x_1<x<a
>> \Longrightarrow
>> f(x)\ge f(x_1)>M.
>> $$
>>
>> По определению предела $+\infty$ требуется подобрать $\delta>0$ так, чтобы
>>
>> $$
>> \forall x\in D:\quad
>> a-\delta<x<a
>> \Longrightarrow
>> f(x)>M.
>> $$
>>
>> Достаточно потребовать
>>
>> $$
>> a-\delta=x_1,
>> \qquad
>> \delta=a-x_1>0.
>> $$
>>
>> Тогда
>>
>> $$
>> \forall M\in\mathbb R\ \exists\delta>0\ \forall x\in D:\quad
>> a-\delta<x<a
>> \Longrightarrow
>> f(x)>M.
>> $$
>>
>> Следовательно,
>>
>> $$
>> \lim_{x\to a-0}f(x)=+\infty.
>> $$
>
>> [!note]- Дополнение: убывающая функция, конечный инфимум
>> Пусть $f$ убывает и
>>
>> $$
>> A=\inf_{x\in D_-}f(x)\in\mathbb R.
>> $$
>>
>> Для любого $\varepsilon>0$ по свойству инфимума
>>
>> $$
>> \exists x_1\in D_-:\quad
>> A\le f(x_1)<A+\varepsilon.
>> $$
>>
>> При $x\in D$, $x_1<x<a$ из убывания и свойства нижней грани
>>
>> $$
>> A\le f(x)\le f(x_1)<A+\varepsilon,
>> $$
>>
>> поэтому
>>
>> $$
>> |f(x)-A|<\varepsilon.
>> $$
>>
>> Для выполнения определения Коши выбираем границу из условия
>>
>> $$
>> a-\delta=x_1,
>> \qquad
>> \delta=a-x_1>0.
>> $$
>>
>> Тогда
>>
>> $$
>> \forall\varepsilon>0\ \exists\delta>0\ \forall x\in D:\quad
>> a-\delta<x<a
>> \Longrightarrow
>> |f(x)-A|<\varepsilon.
>> $$
>>
>> Следовательно,
>>
>> $$
>> \lim_{x\to a-0}f(x)=A.
>> $$
>
>> [!note]- Дополнение: убывающая функция, инфимум $-\infty$
>> Пусть
>>
>> $$
>> \inf_{x\in D_-}f(x)=-\infty.
>> $$
>>
>> Для произвольного $M\in\mathbb R$ существует $x_1\in D_-$:
>>
>> $$
>> f(x_1)<M.
>> $$
>>
>> При $x\in D$, $x_1<x<a$ из убывания
>>
>> $$
>> f(x)\le f(x_1)<M.
>> $$
>>
>> Выбираем
>>
>> $$
>> a-\delta=x_1,
>> \qquad
>> \delta=a-x_1>0.
>> $$
>>
>> Тогда
>>
>> $$
>> \forall M\in\mathbb R\ \exists\delta>0\ \forall x\in D:\quad
>> a-\delta<x<a
>> \Longrightarrow
>> f(x)<M.
>> $$
>>
>> Следовательно,
>>
>> $$
>> \lim_{x\to a-0}f(x)=-\infty.
>> $$
>
>> [!note]- Дополнение: правосторонние пределы
>> Пусть
>>
>> $$
>> D_+=D\cap(a,+\infty),
>> $$
>>
>> а $a$ — предельная точка $D_+$. Аналогичные формулировки:
>>
>> | Монотонность | Предел слева | Предел справа |
>> |---|---|---|
>> | $f$ возрастает | $\displaystyle\sup_{x\in D_-}f(x)$ | $\displaystyle\inf_{x\in D_+}f(x)$ |
>> | $f$ убывает | $\displaystyle\inf_{x\in D_-}f(x)$ | $\displaystyle\sup_{x\in D_+}f(x)$ |
>>
>> При $x\to a+0$ движение к $a$ происходит справа налево, поэтому для возрастающей функции используется инфимум, а для убывающей — супремум. Отдельного доказательства правосторонних формулировок в лекции нет.
