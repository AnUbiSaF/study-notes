> [!danger]- 🔴 Арифметические свойства пределов последовательностей в нормированном пространстве ✓
>
>> [!abstract] Дано
>> $(X,\|\cdot\|)$ — нормированное пространство над $K$; при этом
>> $$
>> x_n\to x_0,
>> \qquad
>> y_n\to y_0,
>> \qquad
>> \lambda_n\to\lambda_0,
>> $$
>> где $x_n,y_n,x_0,y_0\in X$, а $\lambda_n,\lambda_0\in K$.
>
>> [!success] Тогда
>> $$
>> x_n+y_n\to x_0+y_0,
>> \qquad
>> x_n-y_n\to x_0-y_0,
>> $$
>> $$
>> \lambda_nx_n\to\lambda_0x_0,
>> \qquad
>> \|x_n\|\to\|x_0\|.
>> $$
>
>> [!tip] Маршрут доказательства
>> Во всех четырёх пунктах: взять произвольное $\varepsilon>0$ →
>> применить определения исходных пределов с указанными точностями →
>> выбрать общий номер → зафиксировать произвольное $n$ после него →
>> получить оценку → явно закрыть кванторы целевого определения.
>>
>> Сумма и разность: вычесть предполагаемый предел → неравенство
>> треугольника → $\varepsilon/2$ для каждого слагаемого.
>>
>> Умножение: вставить $\lambda_nx_0$ → ограничить $(\lambda_n)$ → каждую часть сделать меньше $\varepsilon/2$.
>>
>> Норма: применить обратное неравенство треугольника.
>
> ### 1. Сумма
>
>> [!example] Полное доказательство
>> Применяем определения $x_n\to x_0$ и $y_n\to y_0$ с точностью
>> $\varepsilon/2$:
>>
>> $$
>> \varepsilon>0\ \Longrightarrow\
>> \begin{cases}
>> \exists N_x\in\mathbb N\ \forall n\in\mathbb N:\
>> n>N_x\Rightarrow\|x_n-x_0\|<\dfrac{\varepsilon}{2},\\[2mm]
>> \exists N_y\in\mathbb N\ \forall n\in\mathbb N:\
>> n>N_y\Rightarrow\|y_n-y_0\|<\dfrac{\varepsilon}{2}.
>> \end{cases}
>> $$
>>
>> $$
>> N=\max\{N_x,N_y\}.
>> $$
>>
>> Тогда
>>
>> $$
>> \begin{aligned}
>> \forall n>N:\quad
>> \|(x_n+y_n)-(x_0+y_0)\|
>> &\le\|x_n-x_0\|+\|y_n-y_0\|\\
>> &<\frac{\varepsilon}{2}+\frac{\varepsilon}{2}
>> =\varepsilon.
>> \end{aligned}
>> $$
>>
>> Значит,
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\ \forall n\in\mathbb N:
>> \quad n>N\Rightarrow
>> \|(x_n+y_n)-(x_0+y_0)\|<\varepsilon,
>> $$
>>
>> то есть
>>
>> $$
>> x_n+y_n\to x_0+y_0.
>> $$
>
> ### 2. Разность
>
>> [!example] Полное доказательство
>> Применяем определения $x_n\to x_0$ и $y_n\to y_0$ с точностью
>> $\varepsilon/2$:
>>
>> $$
>> \varepsilon>0\ \Longrightarrow\
>> \begin{cases}
>> \exists N_x\in\mathbb N\ \forall n\in\mathbb N:\
>> n>N_x\Rightarrow\|x_n-x_0\|<\dfrac{\varepsilon}{2},\\[2mm]
>> \exists N_y\in\mathbb N\ \forall n\in\mathbb N:\
>> n>N_y\Rightarrow\|y_n-y_0\|<\dfrac{\varepsilon}{2}.
>> \end{cases}
>> $$
>>
>> $$
>> N=\max\{N_x,N_y\}.
>> $$
>>
>> Используем $\|-v\|=\|v\|$:
>>
>> $$
>> \begin{aligned}
>> \forall n>N:\quad
>> \|(x_n-y_n)-(x_0-y_0)\|
>> &\le\|x_n-x_0\|+\|-(y_n-y_0)\|\\
>> &=\|x_n-x_0\|+\|y_n-y_0\|\\
>> &<\varepsilon.
>> \end{aligned}
>> $$
>>
>> Значит,
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\ \forall n\in\mathbb N:
>> \quad n>N\Rightarrow
>> \|(x_n-y_n)-(x_0-y_0)\|<\varepsilon,
>> $$
>>
>> то есть
>>
>> $$
>> x_n-y_n\to x_0-y_0.
>> $$
>
> ### 3. Умножение скаляра на вектор
>
>> [!example] Полное доказательство
>> По теореме об ограниченности сходящейся последовательности
>> $(\lambda_n)$ существует $C\ge0$:
>>
>> $$
>> \forall n\in\mathbb N:\quad |\lambda_n|\le C.
>> $$
>>
>> Положим
>>
>> $$
>> M=\max\{1,C\}.
>> $$
>>
>> Тогда $M\ge1$ и
>>
>> $$
>> \forall n\in\mathbb N:\quad |\lambda_n|\le M.
>> $$
>>
>> Добавим и вычтем $\lambda_nx_0$:
>>
>> $$
>> \begin{aligned}
>> \lambda_nx_n-\lambda_0x_0
>> &=\lambda_n(x_n-x_0)+(\lambda_n-\lambda_0)x_0,\\
>> \|\lambda_nx_n-\lambda_0x_0\|
>> &\le M\|x_n-x_0\|+|\lambda_n-\lambda_0|\,\|x_0\|.
>> \end{aligned}
>> $$
>>
>> Распределим $\varepsilon$ между двумя слагаемыми оценки:
>>
>> $$
>> M\delta_x<\frac{\varepsilon}{2},
>> \qquad
>> \|x_0\|\delta_\lambda<\frac{\varepsilon}{2}.
>> $$
>>
>> Выберем
>>
>> $$
>> \delta_x=\frac{\varepsilon}{2M},
>> \qquad
>> \delta_\lambda=
>> \frac{\varepsilon}{2(\|x_0\|+1)}.
>> $$
>>
>> Тогда
>>
>> $$
>> M\delta_x=\frac{\varepsilon}{2},
>> \qquad
>> \|x_0\|\delta_\lambda
>> =\frac{\varepsilon\|x_0\|}{2(\|x_0\|+1)}
>> <\frac{\varepsilon}{2}.
>> $$
>>
>> Применяем определения $x_n\to x_0$ и $\lambda_n\to\lambda_0$
>> с точностями $\delta_x$ и $\delta_\lambda$:
>>
>> $$
>> \varepsilon>0\ \Longrightarrow\
>> \begin{cases}
>> \exists N_x\in\mathbb N\ \forall n\in\mathbb N:\
>> n>N_x\Rightarrow\|x_n-x_0\|<\delta_x,\\[2mm]
>> \exists N_\lambda\in\mathbb N\ \forall n\in\mathbb N:\
>> n>N_\lambda\Rightarrow
>> |\lambda_n-\lambda_0|
>> <\delta_\lambda.
>> \end{cases}
>> $$
>>
>> $$
>> N=\max\{N_x,N_\lambda\}.
>> $$
>>
>> Число $\|x_0\|+1>0$ нужно только для того, чтобы не разбирать
>> отдельно случай $x_0=0$.
>>
>> $$
>> \begin{aligned}
>> \forall n>N:\quad
>> \|\lambda_nx_n-\lambda_0x_0\|
>> &\le M\|x_n-x_0\|+|\lambda_n-\lambda_0|\,\|x_0\|\\
>> &<M\delta_x+\|x_0\|\delta_\lambda\\
>> &<\frac{\varepsilon}{2}+\frac{\varepsilon}{2}
>> =\varepsilon.
>> \end{aligned}
>> $$
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\ \forall n\in\mathbb N:
>> \quad n>N\Rightarrow
>> \|\lambda_nx_n-\lambda_0x_0\|<\varepsilon,
>> $$
>>
>> то есть
>>
>> $$
>> \lambda_nx_n\to\lambda_0x_0.
>> $$
>
> ### 4. Предел нормы
>
>> [!example] Полное доказательство
>> По обратному неравенству треугольника
>>
>> $$
>> \bigl|\|x_n\|-\|x_0\|\bigr|
>> \le\|x_n-x_0\|.
>> $$
>>
>> Применяем определение $x_n\to x_0$ с точностью $\varepsilon$:
>>
>> $$
>> \varepsilon>0\Rightarrow
>> \exists N\in\mathbb N\ \forall n\in\mathbb N:\quad
>> n>N\Rightarrow\|x_n-x_0\|<\varepsilon.
>> $$
>>
>> $$
>> \forall n>N:\quad
>> \bigl|\|x_n\|-\|x_0\|\bigr|
>> \le\|x_n-x_0\|<\varepsilon.
>> $$
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\ \forall n\in\mathbb N:
>> \quad n>N\Rightarrow
>> \bigl|\|x_n\|-\|x_0\|\bigr|<\varepsilon,
>> $$
>>
>> то есть
>> $$
>> \|x_n\|\to\|x_0\|.\quad\square
>> $$
>
> Источник: [[Математический анализ/Лекции/Лекция 06 — Нормы, метрики и пределы#6. Арифметика пределов|лекция 06, §6]].

> [!danger]- 🔴 Арифметические свойства пределов последовательностей в  $\mathbb R$ ✓
>
>> [!abstract] Дано
>> Даны две сходящиеся вещественные последовательности:
>>
>> $$
>> x_n\to x_0,
>> \qquad
>> y_n\to y_0,
>> \qquad
>> x_0,y_0\in\mathbb R,
>> \qquad
>> \forall n\in\mathbb N:\ x_n,y_n\in\mathbb R.
>> $$
>
>> [!success] Тогда
>> Предел произведения равен произведению пределов:
>>
>> $$
>> x_ny_n\to x_0y_0.
>> $$
>>
>> Модуль предела равен пределу модулей:
>>
>> $$
>> |x_n|\to|x_0|.
>> $$
>>
>> Если предел знаменателя не равен нулю, то начиная с некоторого
>> номера знаменатели ненулевые, а предел частного равен частному
>> пределов:
>>
>> $$
>> y_0\ne0
>> \quad\Longrightarrow\quad
>> \begin{cases}
>> \exists N_0\in\mathbb N\ \forall n\in\mathbb N:
>> n>N_0\Rightarrow y_n\ne0,\\[2mm]
>> \dfrac{x_n}{y_n}\to\dfrac{x_0}{y_0}.
>> \end{cases}
>> $$
>
>> [!tip] Маршрут доказательства
>> **Произведение:**
>>
>> $$
>> x_n\to x_0
>> \to (x_n)\text{ ограничена}
>> \to
>> |x_ny_n-x_0y_0|
>> \le |x_n|\,|y_n-y_0|+|y_0|\,|x_n-x_0|.
>> $$
>>
>> **Модуль:**
>>
>> $$
>> \bigl||x_n|-|x_0|\bigr|
>> \le |x_n-x_0|.
>> $$
>>
>> **Частное:**
>>
>> $$
>> y_n\to y_0\ne0
>> \to |y_n|>\frac{|y_0|}{2}
>> \to
>> \left|\frac1{y_n}-\frac1{y_0}\right|
>> \le\frac2{|y_0|^2}|y_n-y_0|
>> \xrightarrow{\text{теорема о двух милиционерах}}
>> \frac1{y_n}\to\frac1{y_0}
>> \to
>> \frac{x_n}{y_n}\to\frac{x_0}{y_0}.
>> $$
>
>> [!example] 1. Полное доказательство предела произведения
>> По теореме об ограниченности сходящейся последовательности
>> $(x_n)$ ограничена:
>>
>> $$
>> \exists M>0\
>> \forall n\in\mathbb N:
>> \quad |x_n|\le M.
>> $$
>>
>> Добавим и вычтем $x_ny_0$:
>>
>> $$
>> \begin{aligned}
>> x_ny_n-x_0y_0
>> &=
>> x_ny_n-x_ny_0+x_ny_0-x_0y_0\\
>> &=
>> x_n(y_n-y_0)+y_0(x_n-x_0).
>> \end{aligned}
>> $$
>>
>> Для каждого $n\in\mathbb N$:
>>
>> $$
>> \begin{aligned}
>> |x_ny_n-x_0y_0|
>> &=
>> \bigl|x_n(y_n-y_0)+y_0(x_n-x_0)\bigr|\\
>> &\le
>> |x_n|\,|y_n-y_0|
>> +|y_0|\,|x_n-x_0|\\
>> &\le
>> M|y_n-y_0|
>> +|y_0|\,|x_n-x_0|.
>> \end{aligned}
>> $$
>>
>> Пусть $\varepsilon>0$. Делим ошибку на две части:
>>
>> $$
>> M\delta_y\le\frac{\varepsilon}{2},
>> \qquad
>> |y_0|\delta_x<\frac{\varepsilon}{2}.
>> $$
>>
>> Отсюда выбираем
>>
>> $$
>> \delta_y=\frac{\varepsilon}{2M},
>> \qquad
>> \delta_x=\frac{\varepsilon}{2(|y_0|+1)}.
>> $$
>>
>> Тогда
>>
>> $$
>> M\delta_y=\frac{\varepsilon}{2},
>> \qquad
>> |y_0|\delta_x
>> =
>> \frac{\varepsilon}{2}
>> \frac{|y_0|}{|y_0|+1}
>> <\frac{\varepsilon}{2}.
>> $$
>>
>> Добавка $1$ исключает отдельный случай $y_0=0$.
>>
>> По определениям $x_n\to x_0$ и $y_n\to y_0$:
>>
>> $$
>> \begin{cases}
>> \exists N_x\in\mathbb N\ \forall n\in\mathbb N:
>> n>N_x\Rightarrow |x_n-x_0|<\delta_x,\\[2mm]
>> \exists N_y\in\mathbb N\ \forall n\in\mathbb N:
>> n>N_y\Rightarrow |y_n-y_0|<\delta_y.
>> \end{cases}
>> $$
>>
>> $$
>> N=\max\{N_x,N_y\}.
>> $$
>>
>> Для каждого $n>N$ одновременно выполняются обе оценки пределов,
>> а также $|x_n|\le M$. Поэтому
>>
>> $$
>> \begin{aligned}
>> |x_ny_n-x_0y_0|
>> &\le
>> M|y_n-y_0|+|y_0|\,|x_n-x_0|\\
>> &<
>> M\delta_y+|y_0|\delta_x\\
>> &<
>> \frac{\varepsilon}{2}+\frac{\varepsilon}{2}
>> =\varepsilon.
>> \end{aligned}
>> $$
>>
>> Следовательно,
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\
>> \forall n\in\mathbb N:
>> \quad
>> n>N\Rightarrow
>> |x_ny_n-x_0y_0|<\varepsilon,
>> $$
>>
>> то есть
>>
>> $$
>> x_ny_n\to x_0y_0.
>> $$
>
>> [!example] 2. Полное доказательство предела модуля
>> По обратному неравенству треугольника:
>>
>> $$
>> \bigl||x_n|-|x_0|\bigr|
>> \le |x_n-x_0|.
>> $$
>>
>> Пусть $\varepsilon>0$. Из $x_n\to x_0$:
>>
>> $$
>> \exists N\in\mathbb N\ \forall n\in\mathbb N:
>> \quad
>> n>N\Rightarrow |x_n-x_0|<\varepsilon.
>> $$
>>
>> Поэтому для каждого $n>N$
>>
>> $$
>> \bigl||x_n|-|x_0|\bigr|
>> \le |x_n-x_0|
>> <\varepsilon.
>> $$
>>
>> Следовательно,
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\
>> \forall n\in\mathbb N:
>> \quad
>> n>N\Rightarrow
>> \bigl||x_n|-|x_0|\bigr|<\varepsilon,
>> $$
>>
>> то есть
>>
>> $$
>> |x_n|\to|x_0|.
>> $$
>
>> [!example] 3. Полное доказательство предела частного
>> Пусть $y_0\ne0$. По определению $y_n\to y_0$:
>>
>> $$
>> \forall\varepsilon>0\ \exists N_\varepsilon\in\mathbb N\
>> \forall n\in\mathbb N:
>> \quad
>> n>N_\varepsilon
>> \Rightarrow
>> |y_n-y_0|<\varepsilon.
>> $$
>>
>> Положим
>>
>> $$
>> \varepsilon=\frac{|y_0|}{2}>0.
>> $$
>>
>> Тогда
>>
>> $$
>> \exists N_0\in\mathbb N\ \forall n\in\mathbb N:
>> \quad
>> n>N_0
>> \Rightarrow
>> |y_n-y_0|<\frac{|y_0|}{2}.
>> $$
>>
>> Для каждого $n>N_0$ записываем
>>
>> $$
>> y_0=(y_0-y_n)+y_n.
>> $$
>>
>> По неравенству треугольника
>>
>> $$
>> \begin{aligned}
>> |y_0|
>> &=|(y_0-y_n)+y_n|\\
>> &\le |y_0-y_n|+|y_n|
>> =|y_n-y_0|+|y_n|.
>> \end{aligned}
>> $$
>>
>> Переносим $|y_n-y_0|$ в левую часть:
>>
>> $$
>> |y_n|
>> \ge |y_0|-|y_n-y_0|
>> >\frac{|y_0|}{2}
>> >0.
>> $$
>>
>> Поэтому
>>
>> $$
>> \forall n\in\mathbb N:
>> \quad n>N_0\Rightarrow y_n\ne0.
>> $$
>>
>> Представим частное как произведение:
>>
>> $$
>> \frac{x_n}{y_n}=x_n\cdot\frac1{y_n}.
>> $$
>>
>> Предел $x_n$ известен, а предел произведения доказан в первом
>> пункте. Поэтому осталось доказать
>>
>> $$
>> \frac1{y_n}\to\frac1{y_0}.
>> $$
>>
>> Для каждого $n>N_0$ сначала оцениваем знаменатель:
>>
>> $$
>> |y_n|>\frac{|y_0|}{2}
>> \Rightarrow
>> |y_n|\,|y_0|>\frac{|y_0|^2}{2}
>> \Rightarrow
>> \frac1{|y_n|\,|y_0|}
>> <\frac2{|y_0|^2}.
>> $$
>>
>> Теперь вычисляем ошибку:
>>
>> $$
>> \begin{aligned}
>> \left|\frac1{y_n}-\frac1{y_0}\right|
>> &=
>> \left|\frac{y_0-y_n}{y_ny_0}\right|\\
>> &=
>> \frac{|y_n-y_0|}{|y_n|\,|y_0|}\\
>> &\le
>> \frac2{|y_0|^2}|y_n-y_0|.
>> \end{aligned}
>> $$
>>
>> Из $y_n\to y_0$ по определению предела
>>
>> $$
>> |y_n-y_0|\to0,
>> \qquad
>> \frac2{|y_0|^2}|y_n-y_0|\to0.
>> $$
>>
>> Следовательно,
>>
>> $$
>> 0
>> \le
>> \left|\frac1{y_n}-\frac1{y_0}\right|
>> \le
>> \frac2{|y_0|^2}|y_n-y_0|
>> \to0.
>> $$
>>
>> По теореме о двух милиционерах
>>
>> $$
>> \left|\frac1{y_n}-\frac1{y_0}\right|\to0,
>> $$
>>
>> то есть
>>
>> $$
>> \frac1{y_n}\to\frac1{y_0}.
>> $$
>>
>> Если среди первых $y_n$ есть нули, соответствующие первые члены
>> $(1/y_n)$ задаются произвольно: конечный начальный фрагмент
>> не влияет на предел.
>>
>> Применяем уже доказанный в первом пункте предел произведения:
>>
>> $$
>> \frac{x_n}{y_n}
>> =
>> x_n\cdot\frac1{y_n}
>> \to
>> x_0\cdot\frac1{y_0}
>> =
>> \frac{x_0}{y_0}.
>> \quad\square
>> $$
>

## Скалярное произведение и координаты

> [!note]- Неравенство КБШ для конечных числовых наборов ✓
> ![[Лекция 05 — Неравенство КБШ для конечных числовых наборов]]

> [!question]- ❓ Неравенство Коши-Буняковского для скалярного произведения
>
>> [!abstract] Дано
>> $X$ — линейное пространство над полем
>>
>> $$
>> \mathbb K\in\{\mathbb R,\mathbb C\}
>> $$
>>
>> со скалярным произведением $\langle\cdot,\cdot\rangle$;
>>
>> $$
>> x,y\in X.
>> $$
>
>> [!success] Тогда
>> Выполняется неравенство Коши — Буняковского:
>>
>> $$
>> \boxed{|\langle x,y\rangle|^2
>> \le
>> \langle x,x\rangle\langle y,y\rangle.}
>> $$
>
>> [!example] Полное доказательство
>> > [!note]- Комплексные числа и правила, нужные ниже
>> > Если
>> >
>> > $$
>> > z=a+bi,
>> > $$
>> >
>> > то
>> >
>> > $$
>> > \overline z=a-bi,
>> > \qquad
>> > |z|^2=z\overline z=a^2+b^2.
>> > $$
>> >
>> > Для скалярного произведения:
>> >
>> > $$
>> > \langle \alpha u,v\rangle=\alpha\langle u,v\rangle,
>> > \qquad
>> > \langle u,\alpha v\rangle=\overline\alpha\langle u,v\rangle,
>> > $$
>> >
>> > $$
>> > \langle v,u\rangle=\overline{\langle u,v\rangle}.
>> > $$
>> >
>> > Над $\mathbb R$ сопряжение ничего не меняет:
>> >
>> > $$
>> > \overline z=z.
>> > $$
>>
>> При $y=0$ обе части равны нулю. Пусть
>>
>> $$
>> y\ne0.
>> $$
>>
>> Тогда по положительной определённости
>>
>> $$
>> \langle y,y\rangle>0.
>> $$
>>
>> Вычтем из $x$ вектор вида $\lambda y$ и потребуем, чтобы остаток
>> был перпендикулярен $y$:
>>
>> $$
>> \langle x-\lambda y,y\rangle=0.
>> $$
>>
>> По линейности в первом аргументе
>>
>> $$
>> \langle x,y\rangle-\lambda\langle y,y\rangle=0.
>> $$
>>
>> Поэтому выбираем
>>
>> $$
>> \lambda
>> =\frac{\langle x,y\rangle}{\langle y,y\rangle}
>> \in\mathbb K.
>> $$
>>
>> Число $\langle y,y\rangle$ вещественно и положительно, поэтому
>>
>> $$
>> \overline{\langle y,y\rangle}=\langle y,y\rangle.
>> $$
>>
>> Для вектора $x-\lambda y$ положительная определённость даёт
>>
>> $$
>> 0\le
>> \langle x-\lambda y,x-\lambda y\rangle.
>> $$
>>
>> Раскрываем скалярное произведение. При раскрытии второго аргумента
>> коэффициент сопрягается:
>>
>> $$
>> \begin{aligned}
>> \langle x-\lambda y,x-\lambda y\rangle
>> &={}
>> \langle x,x\rangle
>> -\lambda\langle y,x\rangle
>> -\overline\lambda\langle x,y\rangle
>> +|\lambda|^2\langle y,y\rangle.
>> \end{aligned}
>> $$
>>
>> Теперь отдельно считаем первый член с $\lambda$. По эрмитовой
>> симметрии
>>
>> $$
>> \begin{aligned}
>> \lambda\langle y,x\rangle
>> &=\frac{\langle x,y\rangle}{\langle y,y\rangle}
>> \overline{\langle x,y\rangle}\\
>> &=\frac{|\langle x,y\rangle|^2}{\langle y,y\rangle}.
>> \end{aligned}
>> $$
>>
>> Для второго члена сначала сопрягаем выбранное $\lambda$:
>>
>> $$
>> \overline\lambda
>> =\frac{\overline{\langle x,y\rangle}}{\langle y,y\rangle}.
>> $$
>>
>> Поэтому
>> $$
>> \begin{aligned}
>> \overline\lambda\langle x,y\rangle
>> &=\frac{\overline{\langle x,y\rangle}}
>> {\langle y,y\rangle}\langle x,y\rangle\\
>> &=\frac{|\langle x,y\rangle|^2}{\langle y,y\rangle}.
>> \end{aligned}
>> $$
>>
>> Наконец,
>>
>>
>> $$
>> \begin{aligned}
>> |\lambda|^2\langle y,y\rangle
>> &=
>> \left|
>> \frac{\langle x,y\rangle}{\langle y,y\rangle}
>> \right|^2\langle y,y\rangle\\
>> &=\frac{|\langle x,y\rangle|^2}{\langle y,y\rangle^2}
>> \langle y,y\rangle\\
>> &=\frac{|\langle x,y\rangle|^2}{\langle y,y\rangle}.
>> \end{aligned}
>> $$
>> Значит,
>>
>> $$
>> \begin{aligned}
>> 0
>> &\le
>> \langle x,x\rangle
>> -\frac{|\langle x,y\rangle|^2}{\langle y,y\rangle}
>> -\frac{|\langle x,y\rangle|^2}{\langle y,y\rangle}
>> +\frac{|\langle x,y\rangle|^2}{\langle y,y\rangle}\\
>> &=\langle x,x\rangle
>> -\frac{|\langle x,y\rangle|^2}{\langle y,y\rangle}.
>> \end{aligned}
>> $$
>>
>> Домножаем на положительное число $\langle y,y\rangle$:
>>
>> $$
>> |\langle x,y\rangle|^2
>> \le
>> \langle x,x\rangle\langle y,y\rangle.
>> \qquad\square
>> $$
>

## Бесконечные пределы и топология

> [!danger]- 🔴 Арифметические свойства пределов последовательностей в  $\overline{\mathbb R}$ ✓
>
>> [!abstract] Дано
>> $$
>> \overline{\mathbb R}=\mathbb R\cup\{-\infty,+\infty\},
>> \qquad
>> -\infty<x<+\infty
>> \quad\forall x\in\mathbb R.
>> $$
>>
>> Конечные элементы $\overline{\mathbb R}$ — вещественные числа;
>> $+\infty$ и $-\infty$ — формальные элементы. Поэтому операции
>> с ними определены не во всех случаях.
>
>> [!success] Тогда
>> $$
>> x_n\to a\in\mathbb R,
>> \qquad
>> y_n\to+\infty
>> \quad\Longrightarrow\quad
>> x_n+y_n\to+\infty,
>> \qquad
>> \frac{x_n}{y_n}\to0.
>> $$
>>
>> $$
>> x_n\to+\infty,
>> \qquad
>> y_n\to a>0
>> \quad\Longrightarrow\quad
>> x_ny_n\to+\infty.
>> $$
>
>> [!note]- Справка: операции в $\overline{\mathbb R}$ и неопределённые формы
>> Для $a\in\mathbb R$:
>>
>> $$
>> a+(\pm\infty)=\pm\infty,
>> \qquad
>> (+\infty)+(+\infty)=+\infty,
>> \qquad
>> (-\infty)+(-\infty)=-\infty.
>> $$
>>
>> $$
>> (+\infty)+(-\infty)
>> \quad\text{не определено}.
>> $$
>>
>> При $a\ne0$:
>>
>> $$
>> (+\infty)\cdot a=
>> \begin{cases}
>> +\infty,&a>0,\\
>> -\infty,&a<0,
>> \end{cases}
>> \qquad
>> (-\infty)\cdot a=
>> \begin{cases}
>> -\infty,&a>0,\\
>> +\infty,&a<0.
>> \end{cases}
>> $$
>>
>> $$
>> (\sigma\infty)(\tau\infty)=\sigma\tau\infty,
>> \qquad
>> \sigma,\tau\in\{+1,-1\}.
>> $$
>>
>> $$
>> 0\cdot(\pm\infty)
>> \quad\text{не определено}.
>> $$
>>
>> Поэтому $\overline{\mathbb R}$ не является полем. Если операция
>> над пределами не определена, одного знания пределов частей
>> недостаточно:
>>
>> $$
>> \infty-\infty,
>> \qquad
>> 0\cdot\infty,
>> \qquad
>> \frac{\infty}{\infty},
>> \qquad
>> \frac{0}{0}
>> $$
>>
>> — неопределённые формы.
>
>> [!note]- Почему формы неопределенны: контрпримеры
>> $$
>> \infty-\infty:
>> \qquad
>> n-n=0,
>> \qquad
>> 2n-n\to+\infty,
>> \qquad
>> n-2n\to-\infty,
>> \qquad
>> (n+5)-n=5.
>> $$
>>
>> $$
>> 0\cdot\infty:
>> \qquad
>> \frac1n\cdot n=1,
>> \qquad
>> \frac1{n^2}\cdot n\to0,
>> \qquad
>> \frac1{\sqrt n}\cdot n\to+\infty.
>> $$
>>
>> $$
>> \frac{\infty}{\infty}:
>> \qquad
>> \frac nn=1,
>> \qquad
>> \frac n{n^2}\to0,
>> \qquad
>> \frac{n^2}{n}\to+\infty.
>> $$
>>
>> $$
>> \frac{0}{0}:
>> \qquad
>> \frac{1/n}{1/n}=1,
>> \qquad
>> \frac{1/n^2}{1/n}\to0,
>> \qquad
>> \frac{1/n}{1/n^2}\to+\infty.
>> $$
>
>> [!example] 1. Полное доказательство: конечный предел $+$ $+\infty$
>> Пусть
>>
>> $$
>> x_n\to a\in\mathbb R,
>> \qquad
>> y_n\to+\infty.
>> $$
>>
>> Цель по определению $x_n+y_n\to+\infty$:
>>
>> $$
>> \forall E\in\mathbb R\ \exists N\in\mathbb N\ 
>> \forall n\in\mathbb N:
>> \quad n>N\Rightarrow x_n+y_n>E.
>> $$
>>
>> Фиксируем произвольное $E\in\mathbb R$.
>>
>> По определению $x_n\to a$:
>>
>> $$
>> \forall\varepsilon>0\ \exists N_\varepsilon\in\mathbb N\ 
>> \forall n\in\mathbb N:
>> \quad n>N_\varepsilon\Rightarrow |x_n-a|<\varepsilon.
>> $$
>>
>> Положим $\varepsilon=1$. Тогда существует $N_1\in\mathbb N$:
>>
>> $$
>> \forall n\in\mathbb N:
>> \quad n>N_1\Rightarrow |x_n-a|<1
>> \Rightarrow -1<x_n-a
>> \Rightarrow x_n>a-1.
>> $$
>>
>> Выберем конкретный уровень
>>
>> $$
>> B=E-(a-1)=E-a+1\in\mathbb R.
>> $$
>>
>> Поскольку $y_n\to+\infty$, по определению для этого $B$
>> существует $N_2\in\mathbb N$:
>>
>> $$
>> \forall n\in\mathbb N:
>> \quad n>N_2\Rightarrow y_n>B=E-a+1.
>> $$
>>
>> $$
>> N=\max\{N_1,N_2\}.
>> $$
>>
>> Тогда для каждого $n\in\mathbb N$, $n>N$:
>>
>> $$
>> x_n+y_n
>> >(a-1)+(E-a+1)
>> =E.
>> $$
>>
>> Так как $E\in\mathbb R$ было произвольным,
>>
>> $$
>> \forall E\in\mathbb R\ \exists N\in\mathbb N\
>> \forall n\in\mathbb N:
>> \quad n>N\Rightarrow x_n+y_n>E,
>> $$
>>
>> то есть
>>
>> $$
>> x_n+y_n\to+\infty.
>> $$
>
>> [!example] 2. Полное доказательство: конечный предел, делённый на $+\infty$
>> Пусть
>>
>> $$
>> x_n\to a\in\mathbb R,
>> \qquad
>> y_n\to+\infty.
>> $$
>>
>> Цель по определению $\dfrac{x_n}{y_n}\to0$:
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\
>> \forall n\in\mathbb N:
>> \quad n>N\Rightarrow
>> \left|\frac{x_n}{y_n}\right|<\varepsilon.
>> $$
>>
>> По теореме об ограниченности сходящейся последовательности
>> существует $M>0$:
>>
>> $$
>> \exists M>0\ \forall n\in\mathbb N:
>> \quad |x_n|\le M.
>> $$
>>
>> Фиксируем произвольное $\varepsilon>0$.
>>
>> Если $y_n>0$, то из $|x_n|\le M$ получаем
>>
>> $$
>> \left|\frac{x_n}{y_n}\right|
>> =\frac{|x_n|}{|y_n|}
>> =\frac{|x_n|}{y_n}
>> \le\frac{M}{y_n}.
>> $$
>>
>> Чтобы правая часть была меньше $\varepsilon$, требуется
>>
>> $$
>> \frac{M}{y_n}<\varepsilon
>> \quad\Longleftrightarrow\quad
>> y_n>\frac{M}{\varepsilon}.
>> $$
>>
>> Поэтому выбираем уровень
>>
>> $$
>> B=\frac{M}{\varepsilon}>0.
>> $$
>>
>> Поскольку $y_n\to+\infty$, по определению для этого $B$
>> существует $N\in\mathbb N$:
>>
>> $$
>> \forall n\in\mathbb N:
>> \quad n>N\Rightarrow y_n>B=\frac{M}{\varepsilon}>0.
>> $$
>>
>> Поэтому при каждом $n>N$ имеем $y_n>0$, а значит $y_n\ne0$, и
>>
>> $$
>> \left|\frac{x_n}{y_n}\right|
>> =\frac{|x_n|}{|y_n|}
>> =\frac{|x_n|}{y_n}
>> \le\frac{M}{y_n}
>> <\frac{M}{M/\varepsilon}
>> =\varepsilon.
>> $$
>>
>> Так как $\varepsilon>0$ было произвольным,
>>
>> $$
>> \forall\varepsilon>0\ \exists N\in\mathbb N\
>> \forall n\in\mathbb N:
>> \quad n>N\Rightarrow
>> \left|\frac{x_n}{y_n}\right|<\varepsilon.
>> $$
>>
>> Следовательно,
>>
>> $$
>> \frac{x_n}{y_n}\to0.
>> $$
>
>> [!example] 3. Полное доказательство: $+\infty$ на положительный конечный предел
>> Пусть
>>
>> $$
>> x_n\to+\infty,
>> \qquad
>> y_n\to a>0.
>> $$
>>
>> Цель по эквивалентной форме определения
>> $x_ny_n\to+\infty$:
>>
>> $$
>> \forall E>0\ \exists N\in\mathbb N\ 
>> \forall n\in\mathbb N:
>> \quad n>N\Rightarrow x_ny_n>E.
>> $$
>>
>> Фиксируем произвольное $E>0$.
>>
>> Сначала получим положительную нижнюю оценку для $y_n$.
>> Поскольку $a>0$, положим
>>
>> $$
>> \varepsilon=\frac a2>0
>> $$
>>
>> в определении $y_n\to a$. Тогда существует $N_1\in\mathbb N$:
>>
>> $$
>> \forall n\in\mathbb N:
>> \quad
>> n>N_1\Rightarrow |y_n-a|<\frac a2.
>> $$
>>
>> Поэтому
>>
>> $$
>> -\frac a2<y_n-a<\frac a2
>> \quad\Longrightarrow\quad
>> \frac a2<y_n<\frac{3a}{2}.
>> $$
>>
>> Теперь для получения $x_ny_n>E$ достаточно обеспечить
>>
>> $$
>> x_n>\frac{2E}{a}>0,
>> $$
>>
>> поскольку тогда
>>
>> $$
>> x_ny_n
>> >x_n\cdot\frac a2
>> >\frac{2E}{a}\cdot\frac a2
>> =E.
>> $$
>>
>> Так как $x_n\to+\infty$, для уровня
>> $\dfrac{2E}{a}\in\mathbb R$ существует $N_2\in\mathbb N$:
>>
>> $$
>> \exists N_2\in\mathbb N\ \forall n\in\mathbb N:
>> \quad
>> n>N_2\Rightarrow x_n>\frac{2E}{a}.
>> $$
>>
>> $$
>> N=\max\{N_1,N_2\}.
>> $$
>>
>> Для каждого $n\in\mathbb N$, $n>N$, обе оценки выполняются
>> одновременно, поэтому
>>
>> $$
>> x_ny_n
>> >
>> \frac{2E}{a}\cdot\frac a2
>> =E.
>> $$
>>
>> Так как $E>0$ было произвольным,
>>
>> $$
>> \forall E>0\ \exists N\in\mathbb N\ \forall n\in\mathbb N:
>> \quad
>> n>N\Rightarrow x_ny_n>E.
>> $$
>>
>> следовательно, по эквивалентной форме определения
>>
>> $$
>> x_ny_n\to+\infty.
>> \quad\square
>> $$
>
>> [!example]- Формы, в которых общего заключения нет
>> $$
>> \sigma,\tau\in\{+1,-1\}.
>> $$
>>
>> $$
>> \underbrace{
>> \boxed{
>> \begin{gathered}
>> x_n\to\sigma\infty,\quad y_n\to\sigma\infty\\
>> \nRightarrow\ \lim\limits_{n\to\infty}(x_n-y_n)
>> \end{gathered}}
>> }_{\infty-\infty}
>> \qquad
>> \underbrace{
>> \boxed{
>> \begin{gathered}
>> x_n\to0,\quad y_n\to\sigma\infty\\
>> \nRightarrow\ \lim\limits_{n\to\infty}(x_ny_n)
>> \end{gathered}}
>> }_{0\cdot\infty}
>> $$
>>
>> $$
>> \underbrace{
>> \boxed{
>> \begin{gathered}
>> x_n\to\sigma\infty,\quad y_n\to\tau\infty\\
>> \nRightarrow\ \lim\limits_{n\to\infty}\dfrac{x_n}{y_n}
>> \end{gathered}}
>> }_{\infty/\infty}
>> \qquad
>> \underbrace{
>> \boxed{
>> \begin{gathered}
>> x_n\to0,\quad y_n\to0\\
>> \nRightarrow\ \lim\limits_{n\to\infty}\dfrac{x_n}{y_n}
>> \end{gathered}}
>> }_{0/0}
>> $$
>
>> [!tip] Общая схема
>> $$
>> \begin{array}{c}
>> \text{конечный предел: фиксировать }\varepsilon>0;\\
>> \text{бесконечный предел: фиксировать уровень }E;\\
>> \downarrow\\
>> \text{получить одностороннюю оценку одного множителя;}\\
>> \downarrow\\
>> \text{решить целевое неравенство для второго;}\\
>> \downarrow\\
>> N=\max\{N_1,N_2\};\\
>> \downarrow\\
>> \text{объединить оценки с учётом знаков.}
>> \end{array}
>> $$
