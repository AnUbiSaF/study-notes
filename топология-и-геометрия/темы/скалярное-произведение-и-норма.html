Скалярное произведение

9. Скалярное произведение

Пусть V — вещественное векторное пространство.

Скалярное произведение — отображение

⟨⋅,⋅⟩:V×V→R.

То есть паре векторов u,v сопоставляется число

⟨u,v⟩.

Свойства

Для любых u,v,w∈V и λ∈R:

  1. Неотрицательность:
⟨v,v⟩≥0.
  1. Невырожденность:
⟨v,v⟩=0⟺v=0.
  1. Симметрия:
⟨u,v⟩=⟨v,u⟩.
  1. Линейность:
⟨u+λv,w⟩=⟨u,w⟩+λ⟨v,w⟩.

10. Неравенство Коши — Буняковского — Шварца

Для любых u,v∈V

⟨u,v⟩2≤⟨u,u⟩⟨v,v⟩​

Доказательство

Для любого λ∈R

0≤⟨u+λv,u+λv⟩.

Раскрываем:

0≤⟨u,u⟩+2λ⟨u,v⟩+λ2⟨v,v⟩.

Получили квадратный трёхчлен относительно λ, неотрицательный при всех λ.

Поэтому его дискриминант не положителен:

D≤0.

Считаем:

D=4⟨u,v⟩2−4⟨u,u⟩⟨v,v⟩.

Следовательно,

4⟨u,v⟩2−4⟨u,u⟩⟨v,v⟩≤0.

Делим на 4:

⟨u,v⟩2≤⟨u,u⟩⟨v,v⟩​

Норма и евклидово пространство

11. Норма

Норма, порождённая скалярным произведением:

∥v∥=⟨v,v⟩​​

Следовательно,

⟨v,v⟩=∥v∥2​

Свойства нормы

  1. Неотрицательность:
∥v∥≥0.
  1. Определённость:
∥v∥=0⟺v=0.
  1. Абсолютная однородность:
∥λv∥=∣λ∣∥v∥.
  1. Неравенство треугольника:
∥u+v∥≤∥u∥+∥v∥​

12. КБШ через норму

Из КБШ

⟨u,v⟩2≤⟨u,u⟩⟨v,v⟩

извлекаем квадратный корень:

∣⟨u,v⟩∣≤⟨u,u⟩​⟨v,v⟩​.

Следовательно,

∣⟨u,v⟩∣≤∥u∥∥v∥​

Warning

Слева появляется модуль:

⟨u,v⟩2​=∣⟨u,v⟩∣.

13. Доказательство неравенства треугольника

Начинаем с

∥u+v∥2=⟨u+v,u+v⟩.

Раскрываем:

∥u+v∥2=∥u∥2+2⟨u,v⟩+∥v∥2.

Используем

⟨u,v⟩≤∣⟨u,v⟩∣≤∥u∥∥v∥.

Первое неравенство — обычное свойство модуля, второе — КБШ.

Поэтому

∥u+v∥2≤∥u∥2+2∥u∥∥v∥+∥v∥2.

Правая часть:

∥u∥2+2∥u∥∥v∥+∥v∥2=(∥u∥+∥v∥)2.

Значит

∥u+v∥2≤(∥u∥+∥v∥)2.

Обе стороны неотрицательны, поэтому

∥u+v∥≤∥u∥+∥v∥​

14. Евклидово пространство

Пусть i,j,k — ортонормированный базис:

⟨i,i⟩=⟨j,j⟩=⟨k,k⟩=1,

а

⟨i,j⟩=⟨i,k⟩=⟨j,k⟩=0.

Пусть

v=αi+βj+γk, w=δi+εj+τk.

Тогда

⟨v,w⟩​=αδ⟨i,i⟩+αε⟨i,j⟩+ατ⟨i,k⟩+βδ⟨j,i⟩+βε⟨j,j⟩+βτ⟨j,k⟩+γδ⟨k,i⟩+γε⟨k,j⟩+γτ⟨k,k⟩.​

Все перекрёстные члены равны нулю, поэтому

⟨v,w⟩=αδ+βε+γτ​

Для нормы:

∥v∥=α2+β2+γ2​​

Закон параллелограмма

15. Закон параллелограмма

Для любых u,v

∥u+v∥2+∥u−v∥2=2∥u∥2+2∥v∥2​

Доказательство

∥u+v∥2=∥u∥2+2⟨u,v⟩+∥v∥2, ∥u−v∥2=∥u∥2−2⟨u,v⟩+∥v∥2.

Складываем:

∥u+v∥2+∥u−v∥2=2∥u∥2+2∥v∥2​

16. Обратное утверждение

Пусть на векторном пространстве задана норма ∥⋅∥.

Если для любых u,v выполняется закон параллелограмма

∥u+v∥2+∥u−v∥2=2∥u∥2+2∥v∥2,

то эта норма порождена некоторым скалярным произведением.

То есть существует скалярное произведение ⟨⋅,⋅⟩, для которого

∥v∥=⟨v,v⟩​.

Note

В письменном конспекте этой лекции зафиксирована формулировка утверждения. Доказательство здесь не приводилось.

Восстановление скалярного произведения из нормы

1. Теорема о норме и скалярном произведении

Теорема (для вещественного векторного пространства V). Норма ∥⋅∥ порождается некоторым скалярным произведением тогда и только тогда, когда выполнено тождество параллелограмма:

∀u,v∈V:∥u+v∥2+∥u−v∥2=2∥u∥2+2∥v∥2.

Направление «скалярное произведение ⇒ тождество параллелограмма» доказано в лекции 7: раскрываются квадраты норм через скалярное произведение, смешанные слагаемые сокращаются.

Докажем обратное направление: если норма удовлетворяет тождеству параллелограмма, можно построить скалярное произведение, порождающее именно эту норму.

1.1. Определяем кандидата на скалярное произведение

Пусть дана только норма, удовлетворяющая тождеству параллелограмма. Определим функцию двух векторов:

F(u,v):=2∥u+v∥2−∥u∥2−∥v∥2​.​

Почему именно такая формула?

Если бы скалярное произведение уже существовало, то ∥u+v∥2=∥u∥2+2⟨u,v⟩+∥v∥2. Выражение для F подсказано этим равенством. Однако сейчас мы не предполагаем, что скалярное произведение существует, и не используем его свойства для F без доказательства. До окончания проверки аксиом пишем только F(u,v).

Из тождества параллелограмма также следует эквивалентная запись:

F(u,v)=2∥u∥2+∥v∥2−∥u−v∥2​=4∥u+v∥2−∥u−v∥2​.

Проверка второй формы. Из ∥u+v∥2+∥u−v∥2=2∥u∥2+2∥v∥2 получаем ∥u∥2+∥v∥2=(∥u+v∥2+∥u−v∥2)/2. Подставляя это в определение F, получаем последнюю дробь.

1.2. Неотрицательность и невырожденность

Для любого u∈V:

F(u,u)​=2∥u+u∥2−∥u∥2−∥u∥2​=2∥2u∥2−2∥u∥2​=24∥u∥2−2∥u∥2​=∥u∥2​.​

Здесь ∥2u∥=2∥u∥ по однородности нормы. Следовательно,

F(u,u)≥0,F(u,u)=0⟺u=0.

1.3. Симметрия

F(v,u)​=2∥v+u∥2−∥v∥2−∥u∥2​=2∥u+v∥2−(∥u∥2+∥v∥2)​=F(u,v).​

Использована коммутативность сложения векторов и чисел; два вычитаемых слагаемых переставлять можно, поскольку они входят с одинаковым знаком «минус».

1.4. Вспомогательное равенство: F(2u,w)=2F(u,w)

По определению:

F(2u,w)=2∥2u+w∥2−4∥u∥2−∥w∥2​.

Откуда берётся подстановка в тождество параллелограмма? Нужно преобразовать ∥2u+w∥2. Ищем векторы a,b, для которых a+b=2u+w, а второе выражение a−b будет простым. Выбираем

a=u+w,b=u.

Тогда a+b=2u+w, a−b=w, и тождество даёт:

∥2u+w∥2+∥w∥2=2∥u+w∥2+2∥u∥2.

Отсюда

∥2u+w∥2=2∥u+w∥2+2∥u∥2−∥w∥2.

Подставляем:

F(2u,w)​=22∥u+w∥2+2∥u∥2−∥w∥2−4∥u∥2−∥w∥2​=22∥u+w∥2−2∥u∥2−2∥w∥2​=∥u+w∥2−∥u∥2−∥w∥2=2F(u,w)​.​

Пока доказано только для коэффициента 2, не для произвольного числа.

1.5. Аддитивность по первому аргументу

Нужно доказать:

F(x+y,w)=F(x,w)+F(y,w).​

Шаг 1. Получим вспомогательное равенство. По определению F:

​F(u+v,w)+F(u−v,w)=2∥u+v+w∥2+∥u−v+w∥2−∥u+v∥2−∥u−v∥2−2∥w∥2​.​

Обозначим для удобства две пары квадратов:

A=∥u+v+w∥2+∥u−v+w∥2, B=∥u+v∥2+∥u−v∥2.

Откуда берётся формула для A? Ищем a,b так, чтобы a+b=u+v+w, a−b=u−v+w. Решая эту систему сложением и вычитанием, получаем:

2a=2u+2w⇒a=u+w,2b=2v⇒b=v.

Тождество параллелограмма для a=u+w, b=v даёт:

A=2∥u+w∥2+2∥v∥2.​

Откуда берётся формула для B? Здесь уже непосредственно a=u, b=v:

B=2∥u∥2+2∥v∥2.​

Подставляем оба выражения:

F(u+v,w)+F(u−v,w)​=2A−B−2∥w∥2​=22∥u+w∥2+2∥v∥2−2∥u∥2−2∥v∥2−2∥w∥2​=∥u+w∥2−∥u∥2−∥w∥2=2F(u,w)​.​

Шаг 2. Выводим нужную аддитивность. Имеем:

F(u+v,w)+F(u−v,w)=2F(u,w).(*)

Хотим, чтобы слева появились F(x,w)+F(y,w). Не угадываем замену, а решаем систему:

{u+v=x,u−v=y.​

Сложение уравнений даёт 2u=x+y, вычитание второго из первого даёт 2v=x−y. Поэтому

u=2x+y​,v=2x−y​.​

Подставляем в (∗):

F(x,w)+F(y,w)=2F(2x+y​,w).

Но уже доказано F(2z,w)=2F(z,w). При z=(x+y)/2:

2F(2x+y​,w)=F(x+y,w).

Следовательно,

F(x+y,w)=F(x,w)+F(y,w).​

Аддитивность доказана.

1.6. Однородность для целых чисел

Нужно получить F(nu,w)=nF(u,w) для всех n∈Z.

Натуральные n. По определению умножения вектора на натуральное число и по аддитивности:

F(nu,w)​=F(n разu+⋯+u​​,w)=n разF(u,w)+⋯+F(u,w)​​=nF(u,w).​

Это общее рассуждение для произвольного натурального n, а не проверка нескольких примеров.

Ноль. Из F(0+0,w)=F(0,w)+F(0,w) следует F(0,w)=2F(0,w), откуда

F(0,w)=0.

Противоположный вектор. Из u+(−u)=0 и аддитивности:

0=F(0,w)=F(u,w)+F(−u,w),

то есть F(−u,w)=−F(u,w).

Отрицательные целые n. Любое такое число имеет вид n=−m, m∈N:

F(nu,w)=F(−(mu),w)=−F(mu,w)=−mF(u,w)=nF(u,w).

Итак,

∀n∈Z:F(nu,w)=nF(u,w).​

1.7. Однородность для рациональных чисел

Пусть q=m/n, где m∈Z, n∈N (поэтому n=0). Положим z=(m/n)u, тогда nz=mu. Поскольку целочисленная однородность уже доказана,

nF(z,w)​=F(nz,w)=F(mu,w)=mF(u,w).​

Делим на n и возвращаем z=(m/n)u:

F(qu,w)=qF(u,w),∀q∈Q.​

Смысл

Рациональный множитель — дробь m/n. Мы свели её к уже доказанному умножению на целые m и n.

2. Непрерывность и переход к вещественным коэффициентам

Для иррационального коэффициента (например, 2​) нельзя напрямую применить доказательство для дробей. Приблизим вещественное число рациональными, но сначала обоснуем переход к пределу.

2.1. Что означает непрерывность

Определение. Функция g:R→R непрерывна в точке t0​, если

∀ε>0 ∃δ>0 ∀t∈R:∣t−t0​∣<δ⇒∣g(t)−g(t0​)∣<ε.​

Эквивалентно (для функций, определённых в окрестности t0​):

t→t0​lim​g(t)=g(t0​).​

Различие: предел показывает, к чему стремится g(t) при t→t0​ (при t=t0​), а g(t0​) — значение непосредственно в точке. Для непрерывности они должны совпасть.

2.2. Обратное неравенство треугольника

Для любых векторов a,b:

∣∥a∥−∥b∥∣≤∥a−b∥.​

Вывод из обычного неравенства треугольника:

∥a∥=∥(a−b)+b∥≤∥a−b∥+∥b∥⇒∥a∥−∥b∥≤∥a−b∥.

Меняя a и b местами:

∥b∥−∥a∥≤∥b−a∥=∥a−b∥.

Объединяем обе оценки и получаем неравенство с модулем.

2.3. Непрерывность t↦∥tu∥

Зафиксируем u∈V и t0​∈R. Для g(t)=∥tu∥:

∣g(t)−g(t0​)∣​=∣∥tu∥−∥t0​u∥∣≤∥tu−t0​u∥=∥(t−t0​)u∥=∣t−t0​∣∥u∥.​

Если u=0, для любого ε>0 явно выбираем

δ=∥u∥ε​>0.​

Тогда ∣t−t0​∣<δ влечёт

∣g(t)−g(t0​)∣≤∣t−t0​∣∥u∥<δ∥u∥=ε.

Если u=0, то g(t)=0 при всех t, то есть функция постоянная и непрерывная (можно выбрать любое δ>0).

Таким образом, t↦∥tu∥ непрерывна во всякой точке t0​.

2.4. Непрерывность t↦∥tu+w∥

Зафиксируем также w∈V. Для h(t)=∥tu+w∥:

∣h(t)−h(t0​)∣​=∣∥tu+w∥−∥t0​u+w∥∣≤∥(tu+w)−(t0​u+w)∥=∥(t−t0​)u∥=∣t−t0​∣∥u∥.​

При u=0 снова подходит δ=ε/∥u∥; при u=0 функция постоянна. Следовательно, h непрерывна.

2.5. Непрерывность t↦F(tu,w)

По определению:

F(tu,w)=2∥tu+w∥2−∥tu∥2−∥w∥2​.

Обе функции t↦∥tu+w∥ и t↦∥tu∥ непрерывны. Их квадраты непрерывны; разность непрерывных функций и деление на ненулевую константу сохраняют непрерывность. ∥w∥2 — постоянная. Значит,

t↦F(tu,w) непрерывна.​

2.6. Однородность для всех вещественных чисел

Пусть λ∈R — произвольное число. Существует последовательность рациональных чисел qk​∈Q такая, что qk​→λ.

Для каждого k по уже доказанной рациональной однородности:

F(qk​u,w)=qk​F(u,w).

Теперь переход к пределу разрешён: функция t↦F(tu,w) непрерывна, поэтому

k→∞lim​F(qk​u,w)=F(λu,w).

Справа F(u,w) — фиксированное число, поэтому

k→∞lim​qk​F(u,w)=λF(u,w).

Следовательно,

∀λ∈R:F(λu,w)=λF(u,w).​

2.7. Итог доказательства теоремы

Мы проверили для F:

  1. F(u,u)=∥u∥2≥0 и F(u,u)=0⟺u=0;
  2. F(u,v)=F(v,u);
  3. F(u+v,w)=F(u,w)+F(v,w);
  4. F(λu,w)=λF(u,w) для всех λ∈R.

Линейность по второму аргументу следует из симметрии и линейности по первому, например:

F(u,v+z)=F(v+z,u)=F(v,u)+F(z,u)=F(u,v)+F(u,z).

Следовательно, F — скалярное произведение. Только теперь вводим обозначение F(u,v)=⟨u,v⟩.

Построенное скалярное произведение порождает исходную норму:

⟨u,u⟩​=F(u,u)​=∥u∥2​=∥u∥.

Итог теоремы

Скалярное произведение ⇒ норма — доказано в лекции 7. Норма + тождество параллелограмма ⇒ скалярное произведение — доказано здесь. В обоих направлениях речь об одной и той же норме.
